# 术语表

术语表是手册和面板用词的对照表。每个术语列出英文界面的名字和含义。

## 基础术语

| 中文       | 英文界面        | 含义                                                       |
| ---------- | --------------- | ---------------------------------------------------------- |
| 中枢       | Hub             | 安装在一台一直开机的电脑上的主程序                         |
| 面板       | Panel           | 中枢的网页管理界面，你在这里安装应用、管理设备             |
| 客户端     | Clients         | 安装在手机和笔记本上的程序，用来打开应用                   |
| 被控端     | Agents          | 安装在要运行应用的电脑上的程序，中枢通过它管理这个系统     |
| 模块       | Modules         | 面板对应用的叫法                                           |
| **机器页** | machine page    | 每个系统自己的页面，你在这个页面上安装应用                 |
| 保险库     | vault           | 中枢保存密钥和密码的加密文件                               |
| 虚拟网     | Virtual network | NetBird 或 EasyTier 建立的私有网络                         |
| 运行账户   | 界面不显示      | 运行这个应用的系统账户，访客使用的也是这个账户             |
| 智能路由   | 界面不显示      | 客户端同时尝试每一条线路，并使用最先连接成功的那一条的功能 |

## 安装和凭据

| 中文       | 英文界面             | 含义                                                                    |
| ---------- | -------------------- | ----------------------------------------------------------------------- |
| 微子·中枢  | Neutrino             | 产品全名                                                                |
| 设置向导   | setup wizard         | 安装中枢后第一次打开的页面                                              |
| 保险库口令 | Vault passphrase     | 打开保险库的口令，恢复备份时也要使用                                    |
| 凭据       | Credentials          | 保存在保险库里的 SSH 密钥、登录信息和令牌                               |
| 中枢生成的 | Generated by the hub | 凭据页的一节，里面有 SMB 密码、远程桌面密码和 SSH 密钥                  |
| 中枢密钥   | hub key              | 设备用它验证中枢，它的公钥在加入链接里。密钥不符时显示 **中枢密钥不符** |

## 网络

| 中文       | 英文界面        | 含义                                          |
| ---------- | --------------- | --------------------------------------------- |
| 形态、模式 | Shape、Mode     | 中枢所在的电脑在网络里的角色                  |
| 服务器     | Server          | 不转发流量的模式，三个系统都有                |
| 路由器     | Router          | 接管网口并提供一个网络的模式，只在 Linux 上有 |
| 单臂路由   | One-arm router  | 只使用一根网线的路由器模式                    |
| 旁路网关   | Side gateway    | 为把这台电脑设为网关的设备转发流量的模式      |
| 开放范围   | Exposure        | 决定哪些网段的主机能连接中枢自身端口的设置    |
| 连接端口   | Connection port | 设备连接中枢使用的端口，默认是 8443，可以修改 |
| 代理       | Proxy           | 按规则把流量转发到出口服务器的功能            |
| 出口服务器 | Exit nodes      | 代理转发流量的目标服务器                      |

## 外部访问

| 中文                 | 英文界面                  | 含义                                                 |
| -------------------- | ------------------------- | ---------------------------------------------------- |
| 外部访问             | Access                    | 你不在同一个局域网时连接中枢的方式，面板上有六张卡片 |
| 直连                 | Direct                    | 经过公网地址和路由器的端口转发，直接连接中枢的方式   |
| SSH 中继             | SSH relay                 | 经过你自己服务器上的一个公网端口连接中枢的方式       |
| SakuraFrp、OpenFrp   | SakuraFrp、OpenFrp        | 两个第三方隧道服务，为连接端口提供一个公网地址       |
| 隧道                 | Tunnel                    | 服务商提供的一条转发线路                             |
| 控制台               | Console                   | NetBird 或 EasyTier 官方的网页管理界面               |
| setup key            | setup key                 | NetBird 控制台生成的加入密钥                         |
| 引导节点             | Bootstrap peers           | EasyTier 手动模式下，已经在虚拟网里的系统的地址      |
| 子网路由、局域网路由 | Subnet routes、LAN routes | 让设备经过虚拟网访问没有安装被控端的设备的路由       |

## 系统和应用

| 中文          | 英文界面           | 含义                                                     |
| ------------- | ------------------ | -------------------------------------------------------- |
| 可用账户      | Available accounts | 这个系统上中枢可以使用的系统账户                         |
| 添加模块      | Add module         | 系统页面上的弹窗，勾选后只添加一个标签，不会安装         |
| 应用          | Apps               | 系统上发布的一个程序，客户端和服务页都使用这个名字       |
| 入口          | Entries            | 一个应用的网页或者端口                                   |
| 声明应用      | Declare app        | 服务页的弹窗，用来添加已有的网页、端口或者共享           |
| 运行设置      | Run settings       | 容器所属的账户，以及虚拟机使用的 CPU、内存和磁盘         |
| Podman 虚拟机 | Podman machine     | Windows、macOS 上一个账户的 Linux 虚拟机，容器运行在里面 |
| 主目录共享    | Home shares        | 每个账户一个，共享这个账户的主目录                       |
| 文件夹共享    | Folder shares      | 共享任意路径，并选择哪些账户能使用                       |
| 持久          | Persistent         | 关闭窗口后，终端会话继续运行                             |

## 设备和分享

| 中文           | 英文界面            | 含义                                                |
| -------------- | ------------------- | --------------------------------------------------- |
| 用链接添加     | Add by link         | 被控端页的按钮，为系统生成一条加入链接              |
| 用 SSH 添加    | Add over SSH        | 被控端页的按钮，中枢经 SSH 为 Linux 系统安装被控端  |
| 新建客户端链接 | New client link     | 客户端页的按钮，每个链接加入一台设备，30 分钟内有效 |
| 权限           | Permissions         | 客户端能使用的内容，每种权限一个开关                |
| 默认权限       | Default permissions | 没有单独设置权限的客户端使用的权限                  |
| 应用分享       | App shares          | 把一个应用分享给没有客户端的人的功能                |
| 有效期         | Expires             | 应用分享的时长：1 天、7 天、30 天、直到撤销         |
| 站点           | Site                | 分享页所在的网站，也可以是你自行部署的站点          |
| 撤销           | Revoke              | 立即结束一个应用分享                                |
| 转发           | forward             | 客户端在本机打开一个端口，连接到系统上的入口        |
