# 客户端

客户端是你用来连接中枢的程序，包括桌面客户端和手机 App。你在面板的 **客户端** 页生成加入链接、设置每台设备的权限，以及重命名、停用或删除设备。

<Facts systems="Linux,Windows,macOS" editions="国际版,国内版" since="0.2.0" />

在设备上安装客户端的步骤见[安装客户端](/access/install_client)，把设备加入中枢的步骤见[加入中枢](/access/join)。

## 页面内容

打开面板，在左侧栏点 **客户端**。这个页面有两栏：

- **客户端：** 每台加入中枢的设备占一行。
- **应用分享：** 每条分享占一行，做法见[应用分享](/share/web_share)。

![客户端页，上面是客户端一栏，下面是应用分享一栏](/guide/zh/hub_clients_01_page.webp)

设备加入后，这一行会显示下面这些内容。

![客户端一栏里在线的一行](/guide/zh/access_join_05_joined.webp)

| 列           | 内容                                                                           |
| ------------ | ------------------------------------------------------------------------------ |
| **名称**     | 你给这台设备起的名字                                                           |
| **主机名**   | 这台设备的主机名                                                               |
| **平台**     | 这台设备的系统                                                                 |
| **版本**     | 客户端的版本                                                                   |
| **状态**     | 这台设备的连接状态，比如 **在线**、**已停用** 或 **从未连接**                  |
| **最后出现** | 这台设备最后一次连接中枢的时间，在线时显示 **在线**，没有连接过时显示 **从未** |

你生成链接后，设备还没有加入时，这一行显示 **等待加入（还剩 N 分钟）**，只有 **权限** 和删除两个操作。链接过期后，这一行会自动消失。

![客户端一栏里等待加入的一行](/guide/zh/access_join_04_waiting.webp)

## 权限种类

如果设备属于别人，你要在发出链接之前修改权限，只打开对方需要的功能。

每种权限只有打开和关闭两种状态。权限打开后，这台设备可以直接使用对应的功能，不用再输入密码。新设备默认跟随 **默认权限**，其中只有 **免密码进入中枢面板** 是关闭的。

| 权限                   | 打开后，这台设备能做什么                                                                             |
| ---------------------- | ---------------------------------------------------------------------------------------------------- |
| **虚拟网**             | 加入中枢发布的 NetBird 或 EasyTier                                                                   |
| **免密码进入中枢面板** | 中枢这一行多一个 **面板** 按钮，按下后直接登录。这台设备能修改面板里的一切，所以只给你自己的设备打开 |
| **网页**               | 打开应用的网页                                                                                       |
| **端口**               | 把应用的端口转发到这台设备的本机地址，供这台设备上的程序连接                                         |
| **AI 网关**            | 使用中枢的 AI 网关，手机没有这个功能                                                                 |
| **文件**               | 打开各个系统上的共享                                                                                 |
| **终端**               | 以系统上启用的账户打开终端、运行命令                                                                 |
| **SSH**                | 让电脑上的 ssh、scp、git 连接各个系统，手机没有这个功能                                              |
| **远程桌面**           | 连接各个系统共享的桌面                                                                               |

权限修改后立即生效。收回权限时，中枢立即关闭这个权限覆盖的连接。

## 修改一台设备的权限

1. 在 **客户端** 一栏找到这台设备，按这一行的 **权限**。这一行下面会展开一张表。**跟随默认** 打开时，其他开关都是灰色的，所以你要先关闭它。

   ![这一行的权限按钮标红](/guide/zh/access_join_06_permission_button.webp "按 权限")
   ![权限表，跟随默认开关标红](/guide/zh/access_join_07_follow.webp "关闭 跟随默认")

1. 打开或关闭你要修改的权限，比如 **免密码进入中枢面板**，再按 **应用权限**。设备上的内容会立即按新权限更新，这一行也会显示 **自定权限**。

   ![跟随默认关闭后的权限表，免密码进入中枢面板开关标红](/guide/zh/access_join_08_custom.webp "修改权限")
   ![应用权限按钮标红](/guide/zh/access_join_11_apply.webp "按 应用权限")

如果你要恢复默认，打开这张表，重新打开 **跟随默认**，再按 **应用权限**。

## 限制到部分系统或部分应用

一种权限默认对所有系统都打开。要缩小范围，有两种做法：按系统限制和按应用限制。

### 按系统限制

按这种权限右边的 **所有被控端**，再勾选允许的系统。一个都不勾选时，表示允许所有系统。

![权限表，网页权限右边的选择按钮标红](/guide/zh/access_join_16_filter_button.webp "按 所有被控端")
![网页权限展开后的系统列表](/guide/zh/access_join_09_filter.webp "勾选系统")

### 按应用限制

打开最下面的 **逐个应用选择**。每种权限下面会列出每个应用、共享、桌面和系统，各有一个开关。这里的开关优先于所属权限的开关。一个应用属于两种权限时，会在两种权限下各出现一次，这两个开关是同一个。

![逐个应用选择打开后，每个应用一个开关](/guide/zh/access_join_10_fine.webp)

如果你只想允许一个应用，关闭 **跟随默认**，关闭所有权限，打开 **逐个应用选择**，再只打开这个应用的开关。要取消某个应用单独的设置，按它旁边的 **跟随所属权限**。修改后都要按 **应用权限**。

## 修改默认权限

按 **客户端** 一栏右上角的 **默认权限**。弹窗里的开关和上面相同。按 **应用权限** 后，所有跟随默认的设备都会使用新的权限。

![客户端一栏，默认权限按钮标红](/guide/zh/access_join_17_default_button.webp "按 默认权限")
![默认权限弹窗](/guide/zh/access_join_12_default.webp "修改后按 应用权限")

## 每一行的按钮

每一行右边有 **重命名**、**权限**、**停用** 和 **删除**。**权限** 的用法见[修改一台设备的权限](#修改一台设备的权限)。

### 重命名

按 **重命名** 后，名称变成输入框，修改后按 **保存**。这只修改面板上显示的名称。

![名称变成输入框](/guide/zh/access_join_15_rename.webp)

### 停用

按 **停用** 后，这台设备的客户端里，中枢这一行显示 **已停用**，并提示 **中枢已把本机停用。**这台设备暂时不能使用任何功能，它打开的连接立即关闭。按 **启用** 后恢复。设备丢失时，先停用这台设备，确认找不回后再删除它。

![这一行的停用按钮标红](/guide/zh/access_join_13_disable.webp)

### 删除

按这一行的 **删除**，再在弹窗里按 **删除**。这台设备离开中枢，它的网关密钥也会吊销。这台设备要用新链接才能重新加入。设备还在等待加入时，删除会让它的链接立即失效。

![删除的确认弹窗](/guide/zh/access_join_14_delete.webp)
