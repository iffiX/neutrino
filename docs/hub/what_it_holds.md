# 数据和外连

中枢把密钥和密码加密保存在你自己的电脑上，并主动连接下面列出的外部地址。下面的内容都不需要你操作。

你的文件、Gitea 仓库和容器的卷保留在各自的电脑上，不进入中枢。中枢不记录分享访客的身份和地址。

## 保存的数据

| 数据                                                              | 保存方式                         | 谁能读取                                                        |
| ----------------------------------------------------------------- | -------------------------------- | --------------------------------------------------------------- |
| **凭据** 页的 **SSH 密钥**、**登录信息**、**令牌**                | 保存在保险库，保存后不再显示     | 运行中的中枢；这台电脑的管理员                                  |
| **中枢生成的** 一节：**SMB 密码**、**远程桌面密码**、**SSH 密钥** | 保存在保险库，每个系统一组       | 密码能在这一节 **显示**，每次显示都记录日志；SSH 密钥只显示指纹 |
| 第三方的密钥：SakuraFrp、OpenFrp、NetBird、EasyTier               | 保存在配置目录，用保险库密钥加密 | 运行中的中枢；这台电脑的管理员                                  |
| 面板密码                                                          | 只保存校验值                     | 无法读取                                                        |
| 客户端、被控端                                                    | 令牌只保存校验值，另外保存公钥   | 无法读取                                                        |
| 加入链接、分享链接                                                | 只保存校验值                     | 面板无法再次显示                                                |
| AI 订阅的登录文件                                                 | 保存在状态目录，不包含在备份里   | 这台电脑的管理员                                                |

![凭据页的中枢生成的一节，密码遮住](/guide/zh/hub_what_it_holds_05_generated.webp)

保险库用向导里设置的 **保险库口令** 加密。如果你要更换口令，运行 `sudo nhub vault rekey`。

这台电脑保存一个工作密钥，所以中枢运行时不用输入口令。只有管理员能读取这个密钥，在 Linux 和 macOS 上是 root，在 Windows 上是 SYSTEM 和管理员。

在 EasyTier 控制台模式下，令牌写在进程的启动命令里，这台电脑的本地账户都能读取。

中枢密钥加密后保存在备份里，所以换电脑恢复后，设备不用重新加入。

这些内容保存在下面两个目录里。

| 目录 | Linux                   | macOS                                              | Windows                              |
| ---- | ----------------------- | -------------------------------------------------- | ------------------------------------ |
| 配置 | `/etc/neutrino/hub`     | `/Library/Application Support/Neutrino/hub/config` | `C:\ProgramData\Neutrino\hub\config` |
| 状态 | `/var/lib/neutrino/hub` | `/Library/Application Support/Neutrino/hub/state`  | `C:\ProgramData\Neutrino\hub\state`  |

## 中枢发起的连接

中枢自身发起的连接如下。

| 时机                                                                       | 连接目标                                                                                                              |
| -------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 检查和安装更新时                                                           | GitHub、CNB                                                                                                           |
| 每天读取一次各应用的版本列表时；某个应用还没有版本列表时，一小时后再读一次 | 各应用的发布方，多数是 api.github.com                                                                                 |
| 安装应用、更换版本，文件先下载到中枢时                                     | 发布方和镜像：GitHub、nodejs.org、npmmirror、USTC 镜像、微软、dl.gitea.com、release.liuyun.io，每次下载选择最快的来源 |
| 为另一种系统的被控端获取安装包时                                           | GitHub、CNB                                                                                                           |
| **容器** 列出镜像的标签时                                                  | Docker Hub                                                                                                            |
| 运行 NetBird、EasyTier、SSH 中继时                                         | NetBird 的管理服务器；EasyTier 控制台或你填写的引导节点；你的 VPS                                                     |
| 登录或刷新 SakuraFrp、OpenFrp 时                                           | api.natfrp.com；api.openfrp.net、access.openfrp.net；列表里的每台服务器（用来测量延迟）                               |
| 开启 SakuraFrp 或 OpenFrp，并选择一条隧道后                                | 这条隧道所在的服务器                                                                                                  |
| AI 网关转发请求时                                                          | 你添加的提供方，或订阅账号所属的服务                                                                                  |
| 开启代理后                                                                 | 你的出口；参照地址，默认是 www.msftconnecttest.com；按 **更新 geodata** 时连接 GitHub                                 |

## 不由中枢发起的连接

部分文件由安装应用的系统直接下载，来源是 npm 源、容器镜像站、PyPI 和 CTAN 镜像。

访客打开分享链接时，浏览器从分享站点加载页面，再连接你的连接端口。

系统的 DNS 和时间同步由操作系统负责。

上面的表只列出微子·中枢自身的连接。安装包附带的程序和各应用还连接哪些地址，见它们各自的说明。
