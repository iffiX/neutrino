# 代理

代理是按规则把选定设备和目标的流量转发到出口服务器的功能。其余流量经过这台电脑自己的线路。

<Facts systems="Linux,Windows,macOS" editions="国际版" since="0.1.0" />

国内版不具备此功能。外部访问不需要代理，见[外部访问：选择一种方式](/access/ways_in)。出口服务器要你自己准备，中枢不提供。

## 添加出口

1. 在面板左侧栏点 **代理**，再按 **添加节点**。

   ![代理页，左侧栏的代理标红](/guide/zh/hub_proxy_01_page.webp "点 代理")
   ![添加出口的按钮标红](/guide/zh/hub_proxy_02_add_button.webp "按添加出口的按钮")

1. 在 **分享链接** 里原样粘贴服务商提供的链接，链接以 `ss://` 或 `vless://` 开头。然后按 **添加**。

   ![分享链接已粘贴，添加按钮标红](/guide/zh/hub_proxy_03_add_form.webp)

1. 下面会多出一张卡片。这时它还没有生效，按 **应用节点** 后才会载入。黄色提示说明，这个操作会重启代理，经过代理的连接都会断开。

   中枢随后自动测量每个出口，卡片上显示 **连接** 和 **请求** 两个时间、评分和应答率。评分最高的出口标有 **当前出口**，流量经过这个出口。如果你要马上测试，按卡片上的 **测试** 或上面的 **全部测试**。

   ![新的卡片和黄色提示，应用按钮标红](/guide/zh/hub_proxy_04_card.webp "载入这张卡片")
   ![卡片标有当前出口](/guide/zh/hub_proxy_09_card_selected.webp "评分最高的出口标有 当前出口")

**探测地址（probe URL）**、**参照地址（reference URL）**、**探测间隔（秒）** 通常不用修改。

## 选择经过代理的流量

**分流** 一节的开关决定哪些流量经过出口。中枢不开放代理端口，所以设备和程序都不用填写代理地址，也不能只让一个程序经过出口。

![代理页的分流一节，上面是几个开关](/guide/zh/hub_proxy_05_route_switches.webp)

| 开关                              | 作用范围                                                              |
| --------------------------------- | --------------------------------------------------------------------- |
| **让局域网流量走代理**            | 中枢服务的网络里的设备。服务器模式下没有这个开关                      |
| **让虚拟网流量走代理**            | 把中枢设为出口的虚拟网成员，你要在 NetBird 或 EasyTier 的控制台里设置 |
| **让 微子·中枢 自己的流量走代理** | 中枢所在的电脑。它的更新和软件安装也经过出口，出口不可用时一起中断    |

在 macOS 和 Windows 上，后两项一起生效。修改后，按这一节最下面的 **应用分流**。

## 设置直连目标

**GeoIP 分流** 打开时，命中直连列表的目标直接连接，其余目标经过出口。按 **更新 geodata** 可以更新判断用的两个数据文件。

![代理页的 GeoIP 分流区域，更新 geodata 按钮标红](/guide/zh/hub_proxy_06_geoip.webp)

下面的列表可以修改，每行一条。在输入框里填写后，按旁边的 **添加**。

- **直连域名** 填写 `geosite:cn`、`domain:example.com`、`keyword:baidu` 这样的规则。
- **直连 IP** 填写 `geoip:cn`、`geoip:private`、`10.0.0.0/8` 这样的规则。
- **远程解析器（走代理的域名）** 至少要有一行。
- **直连解析器（绕过代理的域名）** 留空时使用 **网络** 页的解析器。

修改后按 **应用分流**。

![规则已填写，添加按钮标红](/guide/zh/hub_proxy_10_lists.webp "填好后按 添加")
![分流一节的底部，应用分流按钮标红](/guide/zh/hub_proxy_07_route_apply.webp "修改后按 应用分流")

## 所有出口不可用时

默认情况下，所有出口都无法连接时，经过代理的流量全部失败，局域网的域名解析也失败，总览页上会出现一条红色提示。

如果你要让这些流量改为经过这台电脑自己的线路，打开 **分流** 里的 **出口节点都不应答时直接放行**，再按 **应用分流**。这时流量用这台电脑自己的地址访问目标，总览页的提示变成黄色。

![代理页的分流一节，直接放行的开关标红](/guide/zh/hub_proxy_11_fallback.webp)

## 验证代理

在经过代理的设备上运行下面的命令。如果显示的是出口的地址，代理就已生效。

```bash
curl ifconfig.me
```
