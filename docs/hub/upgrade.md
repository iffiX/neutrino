# 从 0.5 升级

你把 0.5 升级到 0.6 时，配置和保险库都会保留。

0.5 的设备无法连接 0.6 的中枢，中枢也不会升级它们，所以你要在每个系统和每个客户端上分别升级。开始之前要先备份。升级步骤如下。

1. 在 **设置** 页按 **下载备份**，记好保险库口令。
1. 再运行一次安装命令，升级中枢。
1. 在其他系统上安装新的被控端，用新链接加入。
1. 在客户端上安装新版本，按 **离开**，再用新链接加入。

## 各部分的变化

| 位置                      | 自动发生的变化                           | 你要做的事                          |
| ------------------------- | ---------------------------------------- | ----------------------------------- |
| 中枢                      | 配置和保险库照常读取                     | 安装 0.6 的中枢                     |
| 中枢所在系统的被控端      | 面板启动时更新到 0.6，并自动重新加入中枢 | 不用做什么                          |
| 其他系统                  | 没有变化，一直离线                       | 安装 0.6 的被控端，用新链接加入     |
| 电脑和 Android 上的客户端 | 没有变化，无法连接                       | 安装 0.6，按 **离开**，用新链接加入 |
| 浏览器里的面板            | 原来的登录失效                           | 再输入一次面板密码                  |

## 第一步：备份

打开 0.5 的面板，在 **设置** 页的 **配置存档** 一节按 **下载备份**。记好保险库口令，恢复时要用到它。

![0.5 面板的配置存档一节，下载备份按钮标红](/guide/zh/hub_upgrade_01_backup_05.webp)

## 第二步：升级中枢

在中枢所在的电脑上运行安装命令。你要使用和原来相同版本的命令：国际版使用 GitHub，国内版使用 CNB。

::: code-group

```bash [Linux、macOS]
curl -fsSL https://github.com/iffiX/neutrino/releases/latest/download/install.sh | sh
```

```powershell [Windows]
irm https://github.com/iffiX/neutrino/releases/latest/download/install.ps1 | iex
```

```bash [国内版 Linux、macOS]
curl -fsSL https://cnb.cool/iffi-X/neutrino/-/git/raw/main/packaging/install/install.sh | sh
```

```powershell [国内版 Windows]
irm https://cnb.cool/iffi-X/neutrino/-/git/raw/main/packaging/install/install.ps1 | iex
```

:::

终端最后显示 `The hub was upgraded`，后面是面板的地址。打开这个地址，再输入一次面板密码。

0.6 要求 macOS 13，更旧的 macOS 要先升级系统。如果 Ubuntu 22.04 上的 0.5.2 中枢已经无法访问互联网，升级后重启一次。

中枢所在系统的被控端会在面板启动后自动更新并重新加入中枢，被控端页上原来那一行的名称和模块都保留，不用生成链接。

## 第三步：其他系统

下面的步骤在每个系统上都要做一次。每个系统用一条链接，链接 30 分钟内有效。

1. 运行被控端的安装命令，新版本会直接安装在旧版本上。命令见[被控端](/hub/agents)。
1. 在面板上按 **用链接添加**，让 **名称** 留空，再按 **生成链接**。
1. 在那台电脑上运行 `sudo nagent join '<链接>'`，提示是否替换时回答 `y`。

这个系统会恢复到原来那一行，名字、图标、凭据和应用设置都保留。重装过系统的电脑算作新系统，面板会多出一行，你要按旧的那一行的 **忘记** 删除它。

在 Linux 上，你也可以在系统页面的 **被控端本身** 一节按 **重新安装**，中枢经 SSH 安装被控端并加入。

## 第四步：客户端

1. 把 0.6 直接安装在旧版本上，见[安装客户端](/access/install_client)。
1. 这时中枢这一行显示来自 0.5，只有 **离开** 能按。按 **离开**，再按一次确认。

   ![客户端的中枢页，这一行显示来自 0.5，离开按钮标红](/guide/zh/hub_upgrade_03_client_05_row.webp)

1. 在面板的 **客户端** 页按 **新建客户端链接**，填写 **名称**，再按 **生成链接**。
1. 在电脑上粘贴链接，在手机上扫码。每个链接只能加入一台设备，步骤见[加入中枢](/access/join)。

如果 **客户端** 页多出旧的一行，按 **删除** 删除它。0.5 没有 iOS 版，所以你要按新安装的步骤设置 iPhone。

## 升级后的变化

面板和命令有这些变化：

- **设备** 页现在叫 **被控端**。
- 面板不再有 **终端**、**文件**、**模块** 三页。终端和文件移到了客户端，模块在每个系统的页面上。
- **声明服务** 改名为 **声明应用**。
- 每种权限只有打开和关闭两档。原来带终端的权限会自动加上 **SSH**。
- 账户会自动移到每个系统页面的 **可用账户**，AI 工具的开关也改成按账户设置。
- ZFS 模块已删除。
- SOCKS 端口已删除。如果程序原来设置到这个端口，你要修改它的网络设置。流量是否经过出口，现在只由 **分流** 决定，见[代理](/hub/proxy)。
- `nclient join` 现在是 `nclient hub join`。

应用和共享有这些变化：

- 客户端使用的地址已更改。你要从 **应用** 页重新打开 VS Code、code-server 和 CloudCLI。
- 升级后，被控端第一次应用时会删除 0.5 创建的共享和 Samba 登录，共享的文件夹和里面的文件不动。要继续共享，在中枢上为账户重新打开文件共享，或重新添加文件夹共享。
- 微子·中枢会删除文件共享以前建的 SMB 用户（`neutrino-账户名`），再按新配置建成 `neutrino_账户名`，你不用操作。
