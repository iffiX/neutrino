# AI 网关

AI 网关是所有 AI 工具共用的一个端点。你把 API 密钥和 AI 订阅添加到中枢一次，每台电脑的 AI 工具都能使用，用量和花费也在一处查看。

<Facts systems="Linux,Windows,macOS" editions="国际版,国内版" since="0.1.0" />

AI 网关随中枢一起安装，已经在运行。你添加密钥或订阅，再让工具连接 AI 网关，工具就不用各自保存密钥。AI 网关只替换模型来源，不安装工具。Claude Code 这些工具要你自己安装。Hermes WebUI、Ayakaleaf、AstrBot 和思源笔记也用账户的开关接入 AI 网关，见[加入了中枢的系统](#加入了中枢的系统)。

## 添加 API 密钥

你要把密钥保存到 **凭据** 页，再到 **AI** 页创建一个提供方并选择这个密钥。

1. 在面板左侧栏点 **凭据**，在 **令牌** 一栏按 **添加令牌**。在 **名称** 里填写一个名字，在 **值** 里粘贴服务商提供的密钥，再按 **保存令牌**。保存后，密钥不再显示。

   ![凭据页，添加令牌按钮标红](/guide/zh/hub_ai_gateway_01_credentials.webp "按 添加令牌")
   ![新建令牌的表单，保存令牌按钮标红](/guide/zh/hub_ai_gateway_02_token_form.webp "填好后按 保存令牌")

1. 在左侧栏点 **AI**，在 **提供方** 一栏按 **添加提供方**。

   ![AI 页，添加提供方按钮标红](/guide/zh/hub_ai_gateway_03_page.webp)

1. 表单最上面是 **服务商**，在列表里选择你的服务商，比如 **DeepSeek**。表单会自动填好 **名称**、**Base URL** 和 **模型别名**。

   ![服务商的列表展开，DeepSeek 这一行标红](/guide/zh/hub_ai_gateway_20_provider_vendor.webp "选择服务商")

1. 在 **API 令牌** 里选择刚才保存的令牌，再按 **保存提供方**。

   ![API 令牌的选择框展开，刚保存的令牌标红](/guide/zh/hub_ai_gateway_04_provider_token.webp "选择刚保存的令牌")
   ![填好的提供方表单，保存提供方按钮标红](/guide/zh/hub_ai_gateway_05_provider_form.webp "按 保存提供方")

1. 列表会多出一行，下面的黄色提示说明网关会重启，进行中的请求会失败。按 **应用提供方**，改动这时才生效。几秒后刷新页面，页面最上面的 **活动** 显示 **运行中**、**有应答** 和 **正在服务 2 个模型** 时，密钥就添加好了。

   ![提供方列表和黄色提示，应用提供方按钮标红](/guide/zh/hub_ai_gateway_06_provider_list.webp "按 应用提供方")
   ![活动一栏显示正在服务 2 个模型](/guide/zh/hub_ai_gateway_09_page_serving.webp "显示 正在服务 2 个模型")

**服务商** 列表里有 DeepSeek、Kimi、智谱 GLM、通义千问、豆包、MiniMax、OpenRouter、硅基流动、Mistral 和 xAI。有的服务商分中国大陆和国际两个地址，或者另有 Coding Plan，这时表单多出 **套餐和地区**，选你买的那一种，地址和模型名会跟着换。

![套餐和地区的列表展开，API（中国大陆）这一行标红](/guide/zh/hub_ai_gateway_21_provider_endpoint.webp)

服务商的模型名随中枢的版本更新。服务商出了新模型，你可以自己在 **模型别名** 里加一行。列表里没有的服务商选 **自定义**，再自己填写这几项：

- **类型**：按接口选择，可以选 **Anthropic**、**OpenAI**、**Gemini** 或 **OpenAI 兼容**。
- **Base URL**：服务商的接口地址，用官方地址时留空。
- **模型别名**：每行写一个模型名，至少写一个，留空时网关不提供任何模型。

## 添加订阅

如果你有 AI 订阅，用账号登录一次就可以使用，不需要密钥。

1. 在 **AI** 页的 **账号** 一栏按 **登录**，再在弹窗里选择一个服务商。

   ![AI 页，账号一栏的登录按钮标红](/guide/zh/hub_ai_gateway_18_accounts.webp "按 登录")
   ![登录订阅的弹窗，列出可选的服务商](/guide/zh/hub_ai_gateway_08_sign_in.webp "选择服务商")

1. 弹窗会显示一个地址。按 **复制**，在浏览器里打开地址，登录并同意。如果弹窗显示了验证码，就在这个地址输入验证码。

1. 登录后，浏览器可能显示页面无法打开，这是正常现象。复制地址栏的内容，粘贴到 **地址栏或验证码**，再按 **完成登录**。**账号** 一栏多出一行时，订阅就添加好了。

   ![使用 Claude 登录的弹窗，有地址和输入框](/guide/zh/hub_ai_gateway_17_sign_in_step.webp)

## 账号的额度

**账号** 一栏里，窗口够宽时每个账号占一行，窗口窄时每个账号是一张卡片。每个额度窗口画成一个圆环，中间是已经用掉的百分比，下面是窗口和重置时间：Claude 和 ChatGPT 的账号有 **5 小时** 和 **7 天**，Kimi 另有 **本月**。用到 80% 时圆环变黄，用满时变红。ChatGPT 的账号后面还显示套餐和到期日。

![账号一栏，一个账号的两个额度圆环，刷新按钮标红](/guide/zh/hub_ai_gateway_23_account_quota.webp)

Claude 和 ChatGPT 的圆环跟着这个账号的请求更新，右边的 **更新于** 说明数字是多久以前的。按 **刷新**，中枢马上向服务商读一次额度。Kimi 和 Antigravity 的账号按过 **刷新** 才有圆环，xAI 的账号没有 **刷新**，也没有圆环。

账号的额度用完时，状态显示 **受限至** 和一个时间，这段时间里网关改用其他账号和提供方，见[服务顺序](#服务顺序)。

如果你暂时不想用某个账号，按 **暂停**，网关立刻停止使用它，状态显示 **已暂停**。按 **恢复** 就能接着用，不用重新登录。按 **删除** 后，要重新登录才能再用这个账号。

![一个已暂停的账号，恢复按钮标红](/guide/zh/hub_ai_gateway_24_account_paused.webp)

## 服务顺序

工具请求一个模型时，网关先用能提供这个模型的账号和系统上的 Ollama，它们之间轮流使用。它们都受限或都没有这个模型时，网关按 **提供方** 列表从上到下使用 API 密钥。上面一个回答请求太多、超时、拒绝或服务器出错时，网关在同一个请求里改用下一个，最多再换 3 次。

![提供方列表，上面的提示说明先用账号，行首的拖动标记标红](/guide/zh/hub_ai_gateway_22_providers_order.webp)

拖动行首可以调整提供方的顺序，每行的开关可以暂时停用这个提供方。修改后都要按 **应用提供方**。

失败的账号或提供方要停一段时间，网关才会再用它：

| 服务商的回答                   | 停用多久                                                                          |
| ------------------------------ | --------------------------------------------------------------------------------- |
| 请求太多（429）                | 回答里写了等待时间就按它，至少 10 秒；没写时 1 秒，连续失败每次翻倍，最长 30 分钟 |
| Claude、ChatGPT 账号的额度用完 | 到这个额度窗口重置                                                                |
| 服务器出错（5xx）、超时        | 1 分钟                                                                            |
| 密钥无效、余额不足、拒绝访问   | 30 分钟                                                                           |
| 没有这个模型（404）            | 12 小时                                                                           |

## 系统上的 Ollama

装了 [Ollama](/deploy/ollama) 的系统在线、Ollama 在运行并且至少有一个模型时，中枢自动把它加入 AI 网关，你不用添加密钥。这时 **AI** 页的提供方列表里多一行，名称是 **来自 my-computer 的 Ollama**，这一行只能查看。按这一行的 **管理**，会打开这个系统上 Ollama 的模型列表。

![AI 页的提供方列表，来自 my-computer 的 Ollama 这一行标红](/guide/zh/hub_ai_gateway_30_ollama_row.webp)

网关里这些模型的名称和 Ollama 里的名称相同，前面不加系统名。两个系统上有同名的模型时，网关轮流使用这两个系统。只能生成向量、不能对话的嵌入模型不加入网关。系统离线、Ollama 停止或卸载、或者 Ollama 里没有模型时，这一行会消失，网关也不再提供这些模型。

## 让工具使用 AI 网关

设置方法取决于这台电脑上安装的程序。

### 只安装了客户端的电脑

在这种电脑上，你要在客户端窗口里打开开关。

1. 打开客户端，进入 **AI** 页，按 **AI 工具使用此网关**。开关变绿，这一行显示 **工具已指向中枢**。Claude Code、Codex、Gemini 和 OpenCode 从现在起都经过网关。客户端要保持运行，工具才能连接网关。关闭开关后，工具恢复原来的设置。

   ![客户端的 AI 页，AI 工具使用此网关标红](/guide/zh/access_desktop_05_ai.webp "按 AI 工具使用此网关")
   ![开关已打开，配置按钮标红](/guide/zh/access_desktop_06_ai_on.webp "开关变绿")

1. 如果你要指定模型，按 **配置**，为每个工具选择模型，再按 **保存**。

   ![AI 工具配置弹窗](/guide/zh/access_desktop_07_ai_config.webp)

手机没有 **AI** 页。

### 加入了中枢的系统

在这种系统上，你要在它的页面上打开开关，这个开关按账户设置。

1. 在面板左侧栏下半部分点这个系统的名字，再在 **可用账户** 里按账户那一行的 **编辑**。

   ![系统页面，账户那一行的编辑按钮标红](/guide/zh/hub_ai_gateway_19_account_edit.webp)

1. 打开 **AI 工具使用中枢网关**，需要时为每个工具选择模型，再按 **保存**。这个账户那一行显示 **使用中枢的 AI 网关** 时，设置就生效了。

   ![账户表单，AI 工具使用中枢网关开关标红](/guide/zh/hub_ai_gateway_13_account_switch.webp "打开开关")
   ![模型选择框展开，一个模型标红](/guide/zh/hub_ai_gateway_14_account_model.webp "选择模型")

这个开关对 CloudCLI、Codeg 和这个账户的思源笔记也有效，在 VS Code 和 code-server 终端里打开的工具也使用网关。Hermes WebUI、Ayakaleaf 和 AstrBot 每个系统只有一份，它们跟随默认账户的这个开关。网关还没有可用模型时，这个开关无法打开。移除账户或者系统离开中枢时，工具恢复原来的设置。

如果这台电脑也加入了中枢，客户端的开关显示为灰色，这时使用面板上的这个开关。

## 默认模型

默认模型是没有选择模型时使用的模型，AI 工具、Ayakaleaf、Hermes WebUI、AstrBot 和思源笔记都会用它。在 **AI** 页的 **接入** 一栏，从 **默认模型** 里选择一个，再按 **应用接入配置**。没有选择时，使用网关提供的模型里按名称排在最前的那个。

## 模型

**AI** 页的 **模型** 一栏列出网关提供的每个模型，先是云端模型，再是 Ollama 的模型。每行显示模型名、**来源** 和 **上下文**，来源是提供这个模型的账号和提供方。右边有 **配置** 和 **详情**，Ollama 的模型只有 **详情**。

![AI 页的模型一栏，一个云端模型的配置按钮标红](/guide/zh/hub_ai_gateway_40_models.webp)

### 上下文长度

上下文长度是模型一次请求最多能处理的 token 数，包括提示、对话和回答。中枢为网关提供的每个模型算出一个长度，写进 OpenCode、Codex 和 Claude Code，以及 Hermes WebUI、思源笔记和 AstrBot。这些工具在对话超过这个长度之前压缩对话。Claude Code 使用的模型名称以 `claude-` 开头时，中枢不写入长度。Ayakaleaf 不使用长度。

云端模型的长度默认取自中枢自带的模型表，表里没有时取网关的模型目录，都没有时是 200000。套餐不同，长度可能不同，表里写的是最小套餐的长度。

Ollama 模型的长度是 **设置** 和 **模型上限** 里较小的那个，几个系统上有同一个模型时，取最小的，离线的系统也算在内。它在这个系统的 Ollama 标签上修改，见 [Ollama](/deploy/ollama#设置)。

Hermes WebUI 不能使用上下文长度小于 64000 的模型，选这样的模型时，Hermes 会提示消息没有发送。

### 价格

价格是每百万 tokens 的费用，分输入和输出。中枢的价格来自 models.dev，每天读一次并保存在本地，安装包里也带一份，没有网络时也有价格。价格按提供方的 Base URL 对应到服务商，所以 **自定义** 的提供方没有价格，显示 **无价格**，你可以在 **配置** 里自己填写。Ollama 的模型不算钱，没有价格。

models.dev 的价格都是美元，中国大陆服务商的人民币价格按它的汇率折成美元。如果你按人民币付费，在 **配置** 里把币种改成 **人民币**，再填写服务商页面上的价格。

### 修改一个模型

1. 在模型那一行按 **配置**。
1. 弹窗里可以修改 **上下文长度（token）**，可以填 4096 到 10000000。下面是 **输入价格**、**输出价格** 和 **币种**，价格的单位是每百万 tokens。改过上下文长度时，旁边出现 **恢复为** 和默认长度；改过价格时，价格下面出现一行 **恢复为** 和默认的两个价格。按 **恢复为** 会填回默认值。
1. 按 **保存**。新的价格从下一个请求开始计算，已经算过的花费不变。各系统的 AI 工具下次启动时使用新的长度，正在运行的工具继续使用原来的长度。

   ![配置弹窗，上下文长度和两个价格，保存按钮标红](/guide/zh/hub_ai_gateway_41_model_configure.webp)

### 一个模型的详情

按一行的 **详情**，弹窗顶部用大字显示这个模型在 **活动** 所选时间范围里的请求、Tokens 和费用。下面每个来源占一个小框，显示它的请求、Tokens 和费用，云端来源还显示它的输入价格和输出价格。

Ollama 模型的详情里，每个系统占一个小框，显示 **设置** 和 **模型上限**，和模型长度相同的那个是亮的。按系统名会打开这个系统的 Ollama 标签。

![一个模型的详情弹窗，上面是总用量，下面是每个来源](/guide/zh/hub_ai_gateway_43_model_details.webp)

## 为其他工具生成密钥

有的工具要你手动填写地址和密钥，这时可以单独生成一个密钥。这个密钥供中枢所在电脑上的工具使用，或者供经 SSH 端口转发连接这台电脑的工具使用。网关不对局域网开放，所以地址是 `http://127.0.0.1:<端口>`，端口显示在 **网关端口** 一节。

1. 在 **AI** 页的 **接入** 一栏按 **生成密钥**。**端点** 就是要填写到工具里的地址。

   ![接入一栏，生成密钥按钮标红](/guide/zh/hub_ai_gateway_10_access.webp)

1. 填写一个名字，再按 **生成**。然后按 **复制密钥**，把它和 **端点** 一起填写到工具里。这一屏收起后不再显示完整密钥。

   ![填好名字，生成按钮标红](/guide/zh/hub_ai_gateway_11_key_name.webp "填写名字，按 生成")
   ![新生成的密钥](/guide/zh/hub_ai_gateway_12_key_once.webp "按 复制密钥")

如果你不再使用这个密钥，按这一行的垃圾桶图标，再在弹窗里按 **吊销**。使用这个密钥的工具会立刻无法连接网关。

![密钥那一行，吊销图标标红](/guide/zh/hub_ai_gateway_15_key_row.webp "按垃圾桶图标")
![吊销的确认弹窗](/guide/zh/hub_ai_gateway_16_revoke.webp "按 吊销")

如果你不想让某个客户端使用网关，在 **客户端** 页关闭它的 **AI 网关** 权限，步骤见[客户端](/hub/clients)。

## 查看用量和花费

**AI** 页最上面的 **活动** 一栏显示 **今日请求**、**今日 tokens** 和 **今日费用**，用了订阅账号时还显示 **今日 API 价值**。按 **日志** 可以查看网关的日志。

![活动一栏，今日费用和下面的用量表](/guide/zh/hub_ai_gateway_07_activity.webp)

下面的用量表可以按 **天**、**周**、**月**、**年** 切换时间范围，再按 **提供方**、**密钥** 或 **模型** 切换表格。每张表的最后一列是 **费用**。

![用量表切换到模型，费用一列标红](/guide/zh/hub_ai_gateway_45_usage_models.webp)

花费按每个请求实际用的 tokens 和当时的价格算，缓存读写也按各自的价格算。费用这样显示：

- 人民币和美元分开显示，不互相换算，比如 **$3.10 + ¥12.40**。
- 订阅账号和 Coding Plan 已经付过费，它们的请求不算进费用，另外显示 **API 价值**，也就是用 API 密钥时要花多少。
- 找不到价格的请求显示 **无价格**，不算成 0。
- 系统上的 Ollama 不算钱，没有费用。

[总览](/hub/dashboard)页的 **AI 用量** 也显示请求和 token，还能单独查看一个密钥。
