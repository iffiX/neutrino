# A remote editor

VS Code runs on the computer under your account, and the phone or the laptop opens it in a browser to edit the computer's projects.

Before you start, finish the [first step](../quick-start.md), and turn the phone's Wi-Fi back on.

## Start VS Code

1. On the panel's **Modules** page, select your computer under **Which machine**.
1. Select the **VS Code** tab. If the tab is missing, select **+** at the end of the tabs and tick **VS Code**.
1. Select **Open and accept the terms**. Microsoft's license terms open in a new browser tab.
1. Select **Install**.
1. Select **Configure**.
1. Under **Instances**, select **Add instance**.
1. Type your account name on the computer in **Account**.
1. On Windows, pick your Windows login under **Windows login for** your account.
1. Select **Apply VS Code**.

The instance's row reads **running**, and the editor works on the files of your account.

![The VS Code tab with one instance](/guide/en/vscode_panel.webp)

On Linux and macOS, the **code-server** tab installs another browser editor with the same steps, as [code-server](../agent/modules/code_server.md) describes. When the row reads **not running** with a code under it, [Troubleshooting](../reference/troubleshooting.md) has the fix.

## Open it

1. In the app or the laptop's client window, open **Web**.
1. On the **VS Code** row with your account in parentheses, select **Open**.

![The VS Code row on the client's Web page](/guide/en/client_web_vscode.webp)

The browser shows the editor. From its **File** menu, open a project folder on the computer.

## Open it again from outside

1. Turn off Wi-Fi on the phone.
1. In the app, on **Web**, select **Open** on the same row.

The editor opens again in the phone's browser, this time over NetBird.
