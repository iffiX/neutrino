# nagent commands

`nagent` controls the agent on a managed machine running Linux, Windows or macOS. The table lists its subcommands in the order `nagent --help` prints them.

## Privileges

Every subcommand runs as root on Linux and macOS, and in a terminal opened as administrator on Windows. Run without that, a subcommand prints its reason and the line to run instead, then exits with status 2. Only `nagent --version` runs under any account.

## Subcommands

The **Asks first** column marks the subcommands that ask one `[y/N]` question before they act; `--yes` answers it, and a `no` prints `nothing changed` and exits with status 1. With no terminal on stdin and no `--yes`, nothing is asked: one line on stderr names `--yes`, and the answer is a no.

| Command                    | Arguments and flags                                                                                                           | Asks first                             | What it does                                                                                                                                                                                                                                                                                                                                                                                                                           |
| -------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nagent join <link>`       | `<link>` is the `neutrino://enroll/` link from the hub's **Devices** page; omitted, the command reads it at a prompt. `--yes` | only when the machine is already bound | Joins the hub the link names, writes the binding, and starts the agent's service when it is not running.                                                                                                                                                                                                                                                                                                                               |
| `nagent leave`             | `--yes`                                                                                                                       | yes                                    | Leaves the hub and removes the binding. The service keeps running, and the machine can join again with a new link. On an unbound machine it exits with status 1 without asking.                                                                                                                                                                                                                                                        |
| `nagent status`            |                                                                                                                               | no                                     | Prints the version, the hub this machine is bound to, the address it last connected through, the service's state, and whether the hub answered. Exits with status 0 when the machine is bound and the hub answered, and 1 otherwise.                                                                                                                                                                                                   |
| `nagent sync`              |                                                                                                                               | no                                     | Sends this machine's report to the hub now, so the hub pushes its state when the two differ. Exits with status 1 when the service is not running.                                                                                                                                                                                                                                                                                      |
| `nagent start`             | `--yes`                                                                                                                       | yes                                    | Starts the agent's service through systemd, the Windows service control manager or launchd, and prints its state. The binding is unchanged.                                                                                                                                                                                                                                                                                            |
| `nagent stop`              | `--yes`                                                                                                                       | yes                                    | Stops the agent's service. It starts again at the next boot, and the binding is kept; the hub shows the machine offline until the service runs again.                                                                                                                                                                                                                                                                                  |
| `nagent run`               |                                                                                                                               | no                                     | Runs the agent in the foreground. It is the entry the systemd unit and the macOS LaunchDaemon run; `start` and `stop` control the service.                                                                                                                                                                                                                                                                                             |
| `nagent service run`       |                                                                                                                               | no                                     | Runs the agent as the Windows service. It is the entry the service control manager runs; started from a terminal, it exits with status 1.                                                                                                                                                                                                                                                                                              |
| `nagent service uninstall` | `--yes`                                                                                                                       | yes                                    | Stops the agent and takes away what its modules added: their systemd units, launchd jobs, scheduled tasks and firewall rules, and the file share's fence. Shares, accounts and the modules' data stay. Removing the agent's package runs it on Linux and Windows. On macOS it also removes the agent itself, RustDesk and the package's receipt, and keeps the binding and the state, so an install afterwards finds the shares again. |

## Global flags

| Flag        | Where       | What it does                          |
| ----------- | ----------- | ------------------------------------- |
| `--version` | `nagent`    | Prints the package version and exits. |
| `-h`        | every level | Prints that level's help and exits.   |

`nagent` with no subcommand, and `nagent service` with no action, print their help and exit with status 2.
