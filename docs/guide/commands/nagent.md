# nagent commands

`nagent` controls the agent on a managed machine running Linux, Windows or macOS. The table lists its subcommands in the order `nagent --help` prints them.

## Privileges

A subcommand needs root on Linux and macOS, and a terminal opened as administrator on Windows. Run without that, it prints its reason and the line to run instead, then exits with status 2.

The exceptions are `--version`, `-h` and `nagent answer`, which run under any account. `nagent step-down` runs under any account too, and the system rejects its drop to another account unless it runs as root.

## Subcommands

The **Asks first** column marks the subcommands that ask one `[y/N]` question before they act. `--yes` answers it, and a `no` prints `nothing changed` and exits with status 1. With no terminal on standard input and no `--yes`, the subcommand prints one line naming `--yes` and takes the answer as no.

| Command                    | Arguments and flags                                                                                                               | Asks first                             | What it does                                                                                                                                                                                                                                                                                                                                                                                                                            |
| -------------------------- | --------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nagent join <link>`       | `<link>` is the `neutrino://enroll/` link from the hub's **Devices** page; omitted, the command reads it at a prompt. `--yes`     | only when the machine is already bound | Joins the hub the link names, writes the binding, and starts the agent's service when it is stopped.                                                                                                                                                                                                                                                                                                                                    |
| `nagent leave`             | `--yes`                                                                                                                           | yes                                    | Leaves the hub and removes the binding. The service keeps running, and the machine can join again with a new link. On an unbound machine it exits with status 1 without the question.                                                                                                                                                                                                                                                   |
| `nagent status`            |                                                                                                                                   | no                                     | Prints the version, the hub this machine is bound to, the address it last connected through, the service's state, and whether the hub accepted the last `hello`. Exits with status 0 when the machine is bound and the hub accepted it, and 1 otherwise.                                                                                                                                                                                |
| `nagent sync`              |                                                                                                                                   | no                                     | Sends this machine's report to the hub now, so the hub pushes the machine's wanted state when the two differ. Exits with status 1 when the service is stopped.                                                                                                                                                                                                                                                                          |
| `nagent start`             | `--yes`                                                                                                                           | yes                                    | Starts the agent's service through systemd, the Windows service control manager or launchd, and prints its state. The binding stays as it is.                                                                                                                                                                                                                                                                                           |
| `nagent stop`              | `--yes`                                                                                                                           | yes                                    | Stops the agent's service. It starts again at the next boot, and the binding is kept; the hub shows the machine offline until the service runs again.                                                                                                                                                                                                                                                                                   |
| `nagent run`               |                                                                                                                                   | no                                     | Runs the agent in the foreground. It is the entry the systemd unit and the macOS LaunchDaemon run; `start` and `stop` control the service.                                                                                                                                                                                                                                                                                              |
| `nagent service run`       |                                                                                                                                   | no                                     | Runs the agent as the Windows service. It is the entry the service control manager runs; started from a terminal, it exits with status 1.                                                                                                                                                                                                                                                                                               |
| `nagent service uninstall` | `--yes`                                                                                                                           | yes                                    | Stops the agent and removes what its modules added: their systemd units, launchd jobs, scheduled tasks and firewall rules, and the file share's fence. Shares, accounts and the modules' data stay. Removing the agent's package runs this command on Linux and Windows. On macOS it also removes the agent itself, RustDesk and the package's receipt, and keeps the binding and the state, so a later install finds the shares again. |
| `nagent answer`            | `--prompt <text>` is the question's text; `--answer <keys>` is what to type before Enter; `--` then the program and its arguments | no                                     | Runs the program on a pseudo console of its own, types the answer after the prompt appears, prints what the console drew, and exits with the program's exit code. The agent runs it on Windows inside an account's scheduled task, when it switches that account's AI tools from the hub's gateway back to their own configuration. Nobody runs it by hand.                                                                             |
| `nagent step-down`         | `--uid <uid>` and `--gid <gid>` name the account; `--` then the program, by its full path, and its arguments                      | no                                     | Drops to the account's group and user and replaces itself with the program. The agent runs it on macOS under `launchctl asuser`, to start a program in an account's session. Exits with status 126 when the drop or the start fails. Nobody runs it by hand.                                                                                                                                                                            |

## Global flags

| Flag        | Where       | What it does                          |
| ----------- | ----------- | ------------------------------------- |
| `--version` | `nagent`    | Prints the package version and exits. |
| `-h`        | every level | Prints that level's help and exits.   |

`nagent` with no subcommand, and `nagent service` with no action, print their help and exit with status 2. `nagent answer` and `nagent step-down` with no program also exit with status 2.
