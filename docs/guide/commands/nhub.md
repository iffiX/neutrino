# nhub commands

`nhub` is the hub's command line, installed with the hub package on the hub box. The table lists its subcommands in the order `nhub --help` prints them.

## Subcommands

The **Root** column says whether the subcommand needs root. The **Asks first** column marks the subcommands that ask one `[y/N]` question before they act; `--yes` answers it, and a `no` exits with status 1 and changes nothing. With no terminal on stdin and no `--yes`, nothing is asked: one line on stderr names `--yes`, and the status is 1.

| Command             | Arguments and flags                                                                                                                                                                                           | Root | Asks first | What it does                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---- | ---------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nhub setup`        | `--stdin` reads every answer as one JSON object from standard input; `--json <path>` reads them from a file; the two exclude each other                                                                       | yes  | no         | Sets this box up, once, through the browser wizard or the terminal's screens. One of the questions is whether the panel speaks HTTPS.                                                                                                                                                                                                                                                                                                 |
| `nhub run`          | `--host`, `--port`, `--reload`, `--interface`; one of `--only-web`, `--only-xray`, `--only-cliproxyapi`, `--only-dnsmasq`, `--only-supplicant`, `--only-dhcpcd`, `--only-router`                              | no   | no         | Runs one hub process in the foreground. It is the entry every `neutrino_hub_*` unit runs; `start` and `stop` control the units.                                                                                                                                                                                                                                                                                                       |
| `nhub start`        | `--interface`; `--yes`; one of `--only-router`, `--only-xray`, `--only-dnsmasq`, `--only-cliproxyapi`, `--only-web`, `--only-supplicant`, `--only-dhcpcd`                                                     | yes  | yes        | Starts every enabled unit of the hub, routing state first and panel last, or the one service named. A unit already running is left as it is. `--only-supplicant` and `--only-dhcpcd` need `--interface`.                                                                                                                                                                                                                              |
| `nhub stop`         | `--interface`; one of `--only-web`, `--only-cliproxyapi`, `--only-dnsmasq`, `--only-xray`, `--only-router`, `--only-supplicant`, `--only-dhcpcd`                                                              | yes  | no         | Stops what the hub runs on this box, panel first and routing state last, or the one service named. The optional modules keep running, and every unit starts again at the next boot.                                                                                                                                                                                                                                                   |
| `nhub apply`        | `--only <component>` for `router`, `xray`, `dnsmasq`, `cliproxyapi` or `overlay`, repeatable; `--dry-run` prints the rendered files and changes nothing; `--skip-apply` writes the files and restarts nothing | yes  | no         | Renders every generated configuration from `config/`, validates it and applies it, in the order the panel's own converge step uses.                                                                                                                                                                                                                                                                                                   |
| `nhub unlock`       |                                                                                                                                                                                                               | yes  | no         | Clears the panel's login lockout and every fail2ban SSH ban.                                                                                                                                                                                                                                                                                                                                                                          |
| `nhub reset`        | `all`, `network` or `password`; `--stdin` reads the new password from standard input                                                                                                                          | yes  | no         | `password` stores a new panel password and signs every session out. `all` hands the network back, returns every file in `config/` to its example, and deletes the keys, tokens and certificates the box collected, then stops the hub's services. `network` hands the network back, the resolver included, and changes no file in `config/`; removing the package runs it. With no target it lists the three and exits with status 2. |
| `nhub update`       | `--yes`; `--package <file>` installs that package file instead of the newest release                                                                                                                          | yes  | yes        | Installs the newest release through the `neutrino_hub_update` unit, which holds a health gate and puts the previous version back on failure, then prints how it ended. Below 300 MiB of available memory the unit stops the panel and the AI gateway before unpacking. After the new version passes the gate, the unit reinstalls the box's own agent.                                                                                |
| `nhub vault rekey`  | `--stdin` reads the new passphrase from standard input                                                                                                                                                        | yes  | no         | Wraps the vault's data key under a new master passphrase. Nothing sealed is encrypted again.                                                                                                                                                                                                                                                                                                                                          |
| `nhub scan-secrets` | `--staged`, `--history`, `--no-entropy`, `--no-vendor`, `--quiet`                                                                                                                                             | no   | no         | Checks the working tree, the staged files or every commit for credentials. A development command.                                                                                                                                                                                                                                                                                                                                     |

## Global flags

| Flag        | Where                         | What it does                                                                                                 |
| ----------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------ |
| `--version` | `nhub`                        | Prints the package version and exits.                                                                        |
| `--dev`     | `nhub`, before the subcommand | Runs against `hub_dev_root/` in a working copy and lifts the root check. A packaged hub exits with an error. |
| `-h`        | every level                   | Prints that level's help and exits.                                                                          |

## Exit statuses

| Status | When                                                                                                                                                     |
| ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 0      | The subcommand finished, or found nothing to do.                                                                                                         |
| 1      | The answer to `[y/N]` was no, or a step failed.                                                                                                          |
| 2      | A subcommand that needs root ran without it and printed the `sudo` line; `nhub` ran with no subcommand; `nhub update` cannot run from this installation. |
| 130    | Ctrl-C stopped the subcommand.                                                                                                                           |
