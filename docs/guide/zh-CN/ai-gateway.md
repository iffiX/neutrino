# AI 网关

AI 网关是中枢上的一个端点，你名下每台机器的 AI 工具都指向它，由谁来应答在这一页上切。网关本身是 CLIProxyAPI，随中枢一起发布，默认端口 8317。

这一页只管路由，不替你挑模型。账号和 API 密钥合成一个池子供给，具体走哪个由网关自己挑。密钥按客户端发放并计量，新生成的密钥只显示一次，翻不回去。客户端配置框里的「保存」只是暂存，机器上什么都没变，按了「应用」才落地。改网关端口会让所有指向旧端口的机器断掉，直到它们各自的端点也改过来。网关旁边挂 Ollama 这件事还没做，别照着找。

## 提供方

提供方是网关转发过去的端点，每一个配一把存好的令牌。列表的顺序就是供给顺序，第一个启用的先应答。

**1. 打开「AI」页。**

预期：页面顶上是活动一栏，下面是提供方。一个都没有时写还没有提供方，提示 API 端点和令牌只配一次，不用再往每台机器上粘。

**2. 点「添加提供方」，填名称、类别、Base URL、API 令牌和模型别名。**

预期：类别有四种，Anthropic 走 `/v1/messages`，OpenAI 走 `/v1/responses`，Gemini 走 generateContent，OpenAI 兼容走 `/chat/completions`。类别看的是这个端点说哪种协议，不是背后是谁家的模型，DeepSeek 的 `/anthropic` 端点算 Anthropic。Base URL 留空就用该服务的默认地址。

模型别名一行一个，真名在前，工具需要看到另一个名字时在后面加 `= 别名`；设备被告知去要的是第一行那个。令牌从保险库里挑，不用再输一遍。

**3. 点「保存提供方」，再点「应用提供方」。**

预期：提示是「保存供给顺序和启用状态，然后重载网关。」，旁边写着网关会重启，正在途中的请求会失败。网关跑着旧配置时，这里会写它正在提供较旧的配置，应用一下就会重载。

![AI 页的提供方](/guide/zh/ai_providers.webp)

## 用设备码登录账号

**1. 在「账号」里点「登录」，选一个订阅。**

预期：要么给你一个设备码，提示「打开这个地址并在那里输入代码。」；要么给你一个地址，登录之后浏览器会停在一个打不开的页面上，把那个地址栏里的东西粘回「地址栏内容或代码」。

**2. 在对方那边走完流程，回来点「完成登录」。**

预期：账号出现在列表里，和 API 提供方合成一个池子供给。设备码有有效期，过期了会写「已过期」，重来一次即可。这个网关不提供订阅登录的地方，会直接写明。

![AI 页的账号](/guide/zh/ai_accounts.webp)

## 客户端密钥

**1. 看「接入」一栏顶上的端点地址。**

预期：没改过端口的话是 `http://<hub>:8317`。

**2. 点「生成密钥」，名字按那台机器取。**

预期：密钥显示一次，提示把它连同上面的端点一起粘到工具里。

![AI 页的接入与密钥](/guide/zh/ai_keys.webp)

接进来的客户端，中枢会自动发一把以它命名的密钥，所以这个按钮是给那些不跑客户端的机器用的。

::: warning
吊销一把密钥，拿着它的东西会立刻连不上网关，要换一把新的才能回来。

那把密钥属于某个客户端时，中枢会当场给它换一把新的，不用你再去那台机器上操作。

:::

## 用量

**看用量那一格。**

预期：按提供方和按密钥分别列出最近三十天的用量，活动一栏里另有今天的请求数和 token 数。网关还没上报时那里写用量不可用。

![AI 页的用量](/guide/zh/ai_usage.webp)

## 在客户端上：配置，然后应用

**1. 在客户端窗口的 AI 面板上点「配置」。**

预期：弹出「AI 工具配置」，三个标题按顺序排：Claude Code、Codex、Gemini。Claude Code 有默认模型、Opus 档位、Sonnet 档位、Haiku 档位四个位置，Codex 有模型和推理强度（`minimal`、`low`、`medium`、`high`），Gemini 有模型。每个模型框留空就是「(网关默认)」。

![客户端的 AI 工具配置框](/guide/zh/client_ai_config.webp)

**2. 选好模型，点「保存」。**

预期：对话框关掉，AI 面板被标成待应用。这台机器上的工具还没有任何变化。

**3. 把「启用」打开，点「应用」。**

预期：按钮先写「正在切换工具…」，完事之后开关旁边那行字是「工具已指向 hub」。中枢还没发过密钥时，这里会拒绝，说 hub 还没有给你密钥。

![客户端的 AI 面板，已指向 hub](/guide/zh/client_ai_panel.webp)

终端里是同一件事：

```bash
nclient service ai apply hub --claude-default '' --codex-effort medium
```

预期：三个工具各自的配置文件里，端点都换成了网关。

## 把工具放回去

**把「启用」关掉，点「应用」。**

预期：开关旁边那行字变回「工具保持原样」，三个工具各自原来的配置被还回去。

终端里是同一件事：

```bash
nclient service ai apply off
```

预期：工具下一次启动读到的是它们自己原来的配置，和装微子之前一样。
