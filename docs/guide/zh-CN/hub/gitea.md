# Gitea

Gitea 模块在一台被控端机器上运行私有 git 服务器，客户端一键打开。它的 **接入**（Access）和 **管理员**（Administrator）两节，在[模块](./modules.md)页的 **Gitea** 标签下点 **配置**（Configure）之后展开。

hub 只配置自己装的那个 Gitea。手工装的 Gitea 只上报端口，账号和设置仍归它的主人。

## 访问

| 字段                              | 含义                                       |
| --------------------------------- | ------------------------------------------ |
| **端口**（Port）                  | Gitea 监听的端口                           |
| **Root URL**                      | 克隆地址的前缀；留空则用这台机器的地址拼出 |
| **开放注册**（Open registration） | 是否允许任何人自己注册账号                 |

改完点 **应用接入设置**（Apply access），被控端重写 `app.ini` 并重启 Gitea。**打开 Gitea**（Open Gitea）在新标签页里打开它。

## 管理员

服务启动后，**管理员** 一节写着 **创建第一个管理员。** 填 **用户名**、**密码** 和可选的 **邮箱**，点 **创建管理员**（Create administrator）。服务还没起来时按钮不可用，按钮旁写着先启动服务。之后这一节只剩 **重置密码**（Reset password）：填新密码点保存。

## 发布结果

Gitea 的地址成为 **服务**（Services）页 **网页**（Web）组里的一行，来源写着由这台机器上的 gitea 模块发布。客户端的 **网页** 面板里，这一行有 **打开**（Open），在默认浏览器里打开它。
