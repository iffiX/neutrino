# 终端

**终端**（Terminals）页在任一在线被控端上打开 root shell，多个标签并排。

![终端页](/guide/zh/terminals.webp)

1. 打开 **终端**（Terminals）页。
1. 在 **选择机器**（Which machine）里选一台在线的被控端。
1. 点 **新终端**（New terminal）。

新标签里的 shell 以 root 身份运行在那台机器上。按键直接送到机器，Escape 也一样；点标签上的 × 关闭这个终端。切到面板别的页面时会话保持，回来后接着用。写着 **这个会话已经关闭** 时，那台机器停止了应答。设备抽屉里的 **终端**（Terminal）按钮打开同一页并选好那台机器。
