# AI

hub 自带一个 AI 网关 CLIProxyAPI，默认端口 8317，把你的 API 密钥和订阅账号放到同一个端点后面。在 **AI** 页里，提供方和账号各加一次，每个客户端拿到一把自己的密钥来用它们。

## 添加提供方

提供方是网关转发到的 API 端点，每个配一把存在[凭据](./credentials.md)页的令牌。先到那里存好令牌。

1. 在 **提供方**（Providers）里选择 **添加提供方**（Add provider）。
1. 填 **名称**（Name），选 **类型**（Kind）。
1. 可选：用中转时填 **Base URL**；留空则用服务自带的地址。
1. 选 **API 令牌**（API token）。
1. 在 **模型别名**（Model aliases）里一行一个模型，真实名称在前。要让工具看到别的名字，在后面加 `= 别名`。
1. 选择 **保存提供方**（Save provider）。
1. 选择 **应用提供方**（Apply providers）。网关重启，进行中的请求失败。

![提供方列表](/guide/zh/ai_providers.webp)

| 类型                                 | 协议                |
| ------------------------------------ | ------------------- |
| **Anthropic**                        | `/v1/messages`      |
| **OpenAI**                           | `/v1/responses`     |
| **Gemini**                           | `generateContent`   |
| **OpenAI 兼容**（OpenAI-compatible） | `/chat/completions` |

类型按端点说的协议选，和背后是谁的模型无关；中转服务的 `/anthropic` 端点选 **Anthropic**。提供方的第一个模型是设备默认使用的模型。所有提供方的模型名合在一起，就是每台机器的工具能选的列表。

列表顺序就是提供方之间的服务顺序：拖动一行改变位置，第一个启用的先应答。写着 **配上令牌才能服务**（Needs a token before it can serve）的行还没有令牌。**编辑**（Edit）和 **删除**（Delete）作用于单个提供方；删除后它用的令牌仍然保留。

## 登录订阅

订阅账号和提供方服务同样的模型，网关把两者当成一个池轮换。

1. 在 **账号**（Accounts）里选择 **登录**（Sign in），选一家订阅。
1. 打开面板显示的地址。验证码登录时，在那里输入验证码；跳转登录时，登录后把那个打不开的页面的地址粘到 **地址栏或验证码**（Address bar or code）。
1. 选择 **完成登录**（Finish sign-in）。

面板显示验证码的剩余有效时间，过期后写着 **已过期**（Expired）。账号一行写着它成功和失败的请求数；**删除** 让它立即停止服务。

## 发放端点和密钥

![接入一节，带端点和密钥](/guide/zh/ai_keys.webp)

**接入**（Access）显示 **端点**（Endpoint），也就是这台机器的地址加网关端口。每个加入的客户端拿到一把密钥，名字是 `client/` 后接客户端名。没有客户端的机器手动生成一把：

1. 选择 **生成密钥**（Generate key）。
1. 按用途给密钥起名，例如 `laptop`，选择 **生成**（Generate）。
1. 复制密钥。面板只显示这一次，并提示 **把它和上面的端点一起填进工具里。**

每行写着密钥上次使用的时间。**吊销**（Revoke）让持有这把密钥的工具立刻连不上网关。吊销的是客户端的密钥时，hub 给那个客户端发一把新的。

客户端自己的 AI 面板把工具指向这个端点，见[桌面客户端](../client/desktop.md)。

## 查看用量

**活动**（Activity）显示网关服务的模型、今日请求和今日 tokens，以及 **日志**（Journal），也就是网关最近的输出。选择一个模型名即可复制。

下面的格子图显示最近 30 天的用量，按 **提供方** 或 **密钥**（Keys）切换。写着 **暂无用量**（Usage unavailable）时，网关还没有上报用量。

## 修改网关端口

**网关端口**（Gateway port）是网关监听的 TCP 端口，默认 8317。

1. 填新的 **端口**（Port）。
1. 选择 **应用网关端口**（Apply gateway port）。网关在新端口上重启。

::: warning
指向旧端口的机器，在端点改过来之前都连不上网关。在每个客户端上重新应用一次 AI 面板，手动配置的工具要重新填端点。
:::
