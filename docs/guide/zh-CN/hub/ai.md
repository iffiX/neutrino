# AI

中枢自带一个 AI 网关 CLIProxyAPI，默认端口 8317。你的 API 密钥和订阅账号都放在它后面，客户端和被控端上的工具连同一个端点。在 **AI** 页上，提供方和账号各加一次，每个客户端拿到一把自己的密钥。

## 添加提供方

提供方是网关转发请求的 API 端点，每个提供方用一个存在[凭据](./credentials.md)页的令牌。先到那里存好令牌。

1. 在 **提供方**（Providers）里选择 **添加提供方**（Add provider）。
1. 填 **名称**（Name），选 **类型**（Kind）。
1. 可选：端点不是这个类型官方服务的地址时，在 **Base URL** 里填端点地址，例如中转服务或 DeepSeek 的 `/anthropic` 端点。留空则用官方服务的地址。
1. 选 **API 令牌**（API token）。
1. 在 **模型别名**（Model aliases）里每行写一个模型，真实名称在前；要让工具看到别的名字，在后面加 `= 别名`。
1. 选择 **保存提供方**（Save provider）。
1. 选择 **应用提供方**（Apply providers）。网关重启，进行中的请求失败。

![提供方列表](/guide/zh/ai_providers.webp)

| 类型                                 | 协议                |
| ------------------------------------ | ------------------- |
| **Anthropic**                        | `/v1/messages`      |
| **OpenAI**                           | `/v1/responses`     |
| **Gemini**                           | `generateContent`   |
| **OpenAI 兼容**（OpenAI-compatible） | `/chat/completions` |

类型按端点用的协议选，和背后是哪家的模型无关。例如 DeepSeek 的 `/anthropic` 端点选 **Anthropic**。提供方的第一个模型是设备默认用的模型。所有提供方的模型名合在一起，就是各台机器上的工具能选的模型列表。

列表顺序就是服务顺序：拖动一行改变位置，第一个启用的提供方先应答。写着 **配上令牌才能服务**（Needs a token before it can serve）的行还没有令牌。**编辑**（Edit）和 **删除**（Delete）作用于一个提供方；删除提供方不删它用的令牌。

## 登录订阅

订阅账号和提供方合成一个池，网关从池里挑选。

1. 在 **账号**（Accounts）里选择 **登录**（Sign in），选一家订阅。
1. 打开对话框显示的地址。验证码登录时，在那里输入验证码；跳转登录时，登录后把那个打不开的页面的地址粘到 **地址栏或验证码**（Address bar or code）。
1. 选择 **完成登录**（Finish sign-in）。

对话框显示验证码的剩余时间，过期后写着 **已过期**（Expired）。

登录拖得太久时，中枢返回 `login_expired`，意思是这次登录已经过期。对话框停在当时那一屏，不回到第一屏，屏幕下方显示这个错误码的说明。看到这个错误码，关掉对话框，重新选择 **登录**。登录失败时，网关给出的原因写在错误码说明的下面。

账号一行写着它成功和失败的请求数。**删除** 让这个账号立即停止服务。

## 发放端点和密钥

![接入一节，带端点和密钥](/guide/zh/ai_keys.webp)

**接入**（Access）一节显示 **端点**（Endpoint），也就是中枢的地址加网关端口。每个加入的客户端自动拿到一把密钥，名字是 `client/` 加客户端名，例如 `client/laptop`。

给不跑客户端的机器手动生成一把：

1. 选择 **生成密钥**（Generate key）。
1. 按用途给密钥起名，例如 `laptop`，选择 **生成**（Generate）。
1. 复制密钥。面板只显示这一次，旁边写着 **把它和上面的端点一起填进工具里。**（Paste it into the tool beside the endpoint above.）

每行写着密钥上次使用的时间。**吊销**（Revoke）让用这把密钥的工具立刻连不上网关。吊销的是客户端的密钥时，中枢给那个客户端发一把新的，随状态自动下发，客户端上不用做什么。要让一个客户端不再用网关，在[客户端](./clients.md)页关掉它的 **AI 网关** 权限。

## 让机器用上网关

客户端所在的电脑，在客户端窗口的 AI 页里把工具指向网关，见[桌面客户端](../client/desktop.md)。

受管机器，在模块页的全局配置里一次接上网关，见[AI 工具](../agent/modules/ai_tools.md)。

## 查看用量

**活动**（Activity）显示网关正在服务的模型、今日请求数和今日 tokens，以及 **日志**（Journal），也就是网关最近的输出。选择一个模型名就复制它。

下面的格子图是最近 30 天的用量，可以按 **提供方** 或 **密钥**（Keys）切换。写着 **暂无用量**（Usage unavailable）时，网关还没有上报用量。

## 修改网关端口

**网关端口**（Gateway port）是网关监听的 TCP 端口，默认 8317。

1. 填新的 **端口**（Port）。
1. 选择 **应用网关端口**（Apply gateway port）。网关在新端口上重启。

::: warning
指向旧端口的机器，端点改过来之前都连不上网关。在每个客户端上重新应用一次 AI 页，手动配置的工具重新填端点。
:::
