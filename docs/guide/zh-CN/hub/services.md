# 服务

**服务**（Services）页列出 hub 向客户端发布的每一条，分 **网页**（Web）、**端口**（Ports）、**AI** 和 **文件**（Files）四组；远程桌面是第五类，只出现在设备抽屉和客户端里。

## 五类

![服务页](/guide/zh/services_list.webp)

| 类型     | 从哪来                                   | 客户端上的按钮                                   |
| -------- | ---------------------------------------- | ------------------------------------------------ |
| 网页     | Gitea 模块，手动声明的网址               | **打开**（Open）                                 |
| 端口     | 容器发布的端口，手动声明的 TCP 端口      | **连接**（Connect）、**断开**（Disconnect）      |
| AI       | hub 的 AI 网关                           | **配置**（Config）、**应用**（Apply）            |
| 文件     | Samba 模块，手动声明的 SMB 共享          | **配置**、**挂载**（Mount）、**卸载**（Unmount） |
| 远程桌面 | 机器自己用 `nagent rdp start` 共享的桌面 | **连接**                                         |

![客户端的五个面板](/guide/zh/client_connected.webp)

每行显示是否 **提供服务中**（serving）以及来源标签：模块或手动声明。客户端把访问不到的条目画成灰色，写 **当前无法访问**。

## 自动发现

下列来源的条目自动出现，不用你在这一页做任何事。

- 被控端上启用的模块。Samba 的每个共享是一条文件服务；Gitea 的地址是一条网页服务；容器发布的每个主机端口各是一条端口服务。来源写着由某台机器上的 samba 模块或 gitea 模块发布，或由容器某镜像发布。
- hub 的 AI 网关：一条 AI 服务，由 AI 网关发布。
- 机器自报：运行 `nagent rdp start` 的机器声明它在共享桌面，来源是那台机器。

## 手动声明

![声明服务](/guide/zh/services_add.webp)

hub 不托管的东西用 **声明服务**（Declare service）加进来。

1. 点 **声明服务**，打开 **新建声明的服务**（New declared service）。
1. 填 **名称**（Name），选 **类型**（Kind）：**网页**、**端口** 或 **文件**（File）。
1. 填 **主机**（Host）和 **端口**（Port）。网页还有 **协议**（Scheme）和 **路径**（Path）；文件留空端口时用 445。
1. 文件类型点 **扫描主机**（Scan host），hub 用 smbclient 列出这台主机导出的共享，每个共享发布成独立一行；也能手动填 **共享**（Shares）。
1. 点 **声明**（Declare）。

主机填 `127.0.0.1`、`localhost` 或 `0.0.0.0` 时指 hub 自己，客户端收到的是它访问 hub 所用的地址。声明的行有 **测试**（Test）探测一次可达性，**删除**（Delete）移除声明和它发布的每一行，指向的机器不受影响。

## 客户端上的每类

网页条目点 **打开**，在默认浏览器里打开。端口条目点 **连接**，客户端把它转到本机 `127.0.0.1` 上的同号端口，行里写出实际地址。

![端口转发](/guide/zh/client_port_forwarding.webp)

AI 条目点 **配置** 选模型，再点 **应用**。文件条目点 **配置** 填共享的用户名、密码和挂载位置，再点 **挂载**。

![挂载配置](/guide/zh/client_files_config.webp)

![已挂载](/guide/zh/client_files_mounted.webp)

远程桌面条目点 **连接**，RustDesk 查看器打开。每个面板的细节在客户端分组：[网页](../client/web.md)、[端口](../client/ports.md)、[AI](../client/ai.md)、[文件](../client/files.md)、[远程桌面](../client/remote-desktops.md)。
