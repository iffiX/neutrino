# 客户端

**客户端**（Clients）页管每个人的客户端程序：发一条加入链接，之后启用、停用或删除它。

## 客户端是什么

每个人的每台电脑上装一个客户端，以这个人的普通账户运行。客户端使用 hub 发布的服务，自己不发布任何东西，也不接受模块。要管理一台机器，装的是被控端。客户端有 Linux、Windows 和 macOS 版本，安装步骤在[安装客户端](../client/install.md)。

## 建链接、启用停用、删除

![新建客户端链接](/guide/zh/clients_create_link.webp)

1. 点 **新建客户端链接**（New client link）。
1. 填名称，写这是谁的程序，例如 `alice-laptop`。
1. 点 **创建链接**（Create link），把链接交给那个人。

链接五分钟内有效。把链接粘进客户端窗口，或者在终端里运行 `nclient connect '<enroll-link>'`，`<enroll-link>` 换成这条链接。

![客户端列表](/guide/zh/clients_table.webp)

列表的列是 **名称**（Name）、**主机名**（Hostname）、**平台**（Platform）、**状态**（Status）、**版本**（Version）和 **最后出现**（Last seen）。每行三个动作：

| 动作                | 效果                                                                             |
| ------------------- | -------------------------------------------------------------------------------- |
| **停用**（Disable） | 那个窗口里每个按钮变灰，状态卡说明 hub 关闭了它                                  |
| **启用**（Enable）  | 恢复                                                                             |
| **删除**（Delete）  | hub 吊销这个客户端的网关密钥，那台电脑上的客户端回到未连接；要回来需要一条新链接 |

## 每个客户端自己的 AI 密钥

客户端接入时，hub 给它发一把 AI 网关密钥，在 **AI** 页 **接入**（Access）一节里写作 `client/<name>`，用量也按这个名字统计。在 AI 页吊销它，hub 立刻发给这个客户端一把新的。密钥怎么用，在 [AI](./ai.md) 页。

## 客户端那边长什么样

窗口上半是状态卡，下半是网页、端口、AI、文件、远程桌面五个面板，每条服务下面写它由谁发布。每个部分的细节在[窗口](../client/window.md)页。
