# 客户端

客户端是装在某个人电脑或手机上的程序，经中枢使用局域网里的服务。在 **客户端**（Clients）页上，你用一条链接接纳一个客户端，给它定权限，不再需要时停用或删除它。

## 生成客户端链接

1. 在客户端页选择 **新建客户端链接**（New client link）。
1. 填一个名称，写明这是谁的哪台设备，例如 `alice-laptop`。
1. 选择 **创建链接**（Create link）。

页面显示链接、**复制**（Copy）按钮和同一条链接的二维码。手机上的客户端扫二维码，电脑上的客户端粘贴链接。装客户端和加入的步骤在[安装客户端](../install/client.md)。

![新建的客户端链接、复制按钮和二维码](/guide/zh/clients_link_qr.webp)

链接 30 分钟内有效，只能用一次。中枢把没用过的链接存在盘上，30 分钟内中枢重启，链接照样能用。

链接和二维码里带着加入虚拟网用的材料：NetBird 的 setup key，EasyTier 的网络密码或控制台地址。所以中枢存的 NetBird key 只能用一次时，key 用掉之后，后来的客户端都加入不了 NetBird。换成可重复使用的 key，见[把中枢加入 NetBird](./netbird.md)。

同一台电脑再次加入时，回到它原来那一行，名称换成新链接里的名称。标题旁的标记写着在线台数，例如 **3 个中有 2 个在线**。

## 客户端列表

每一行显示 **名称**（Name）、**主机名**（Hostname）、**平台**（Platform）、**版本**（Version）、**状态**（Status）和 **最后出现**（Last seen）。停用的客户端带 **已停用**（disabled）标记。有自己权限、不跟随默认的客户端带 **自定权限**（own permissions）标记。

## 权限

页面顶部的 **默认权限**（Default permissions）管所有没有自定权限的客户端。每行的 **权限**（Permissions）打开这个客户端自己的抽屉。抽屉里的 **跟随默认**（Follow the default）开着时用默认权限，关掉它才能单独设置。

| 类型                                                     | 客户端得到什么                                         |
| -------------------------------------------------------- | ------------------------------------------------------ |
| **虚拟网**（Virtual network）                            | 作为对端加入中枢的虚拟网                               |
| **网页**（Web pages）                                    | 网页条目，在浏览器里打开                               |
| **端口**（Ports）                                        | 转发到客户端本机 `127.0.0.1` 的 TCP 端口               |
| **AI 网关**（AI gateway）                                | 自己的网关密钥和网关地址                               |
| **文件**（Files）                                        | 可以挂载的 SMB 共享                                    |
| **终端**（Terminals）                                    | 被控端上的 shell                                       |
| **远程桌面**（Remote desktops）                          | 各台机器共享出来的桌面                                 |
| **免密码进入中枢面板**（Hub panel without the password） | 客户端中枢那一行上的 **面板** 按钮，打开时已经登录面板 |

除了 **免密码进入中枢面板**，每一类默认都开着。这一项让客户端不输面板密码就能改面板里的一切，只给你自己的设备打开。在这样的会话里，解锁保险库照样要保险库口令，改面板密码照样要当前密码。

改完开关，选择 **应用权限**（Apply permissions）。在默认权限里应用，中枢把新列表推给所有跟随默认的客户端；在某个客户端的抽屉里应用，只推给它。

![一个客户端的权限抽屉](/guide/zh/clients_permissions_panel.webp)

## 设备过滤

除了虚拟网和免密码进入中枢面板，每一类旁边都有一个过滤器。没有收窄时，它写着 **所有被控端**（All agents）。

1. 选择这一类旁边的过滤器。
1. 勾选允许访问的被控端。
1. 选择 **应用权限**。

一台都不勾，就是所有被控端都允许。中枢自己的服务算在中枢所在的那台机器上，行名是 `hub`。手动声明的服务算在它地址所在的设备上。

在设备页忘记一台设备后，它从所有过滤器里消失。某一类的过滤器里只勾了这台设备时，这一类的开关随之关闭。

## 每个客户端的 AI 密钥

客户端加入后，中枢给它一把网关密钥，名字是 `client/` 加客户端名称。密钥随中枢推给客户端的状态一起下发，不用手动输入。用量按密钥统计，在 AI 页的 **接入**（Access）一节里查看。

在那里选择 **吊销**（Revoke），这个客户端立即连不上网关，中枢随即发给它一把新密钥。

## 停用或删除客户端

| 操作                | 结果                                                               |
| ------------------- | ------------------------------------------------------------------ |
| **停用**（Disable） | 中枢吊销它的网关密钥；客户端的中枢那一行写着已停用，每个条目都变灰 |
| **启用**（Enable）  | 重新打开这个客户端，中枢发给它一把新密钥                           |
| **删除**（Delete）  | 中枢吊销密钥并移除这一行；那台设备要拿一条新链接才能重新加入       |

停用或删除一个客户端时，它经 **面板** 按钮开着的面板会话立刻结束。客户端离开中枢，或者你关掉它的 **免密码进入中枢面板**，也是一样。
