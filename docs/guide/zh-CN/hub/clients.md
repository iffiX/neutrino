# 客户端

客户端是装在某个人电脑或手机上的程序，用来使用中枢发布的服务。在**客户端**（Clients）页上，你用一条链接接纳它，决定它能用什么，也能停用或删除它。

## 生成客户端链接

1. 在客户端页点**新建客户端链接**（New client link）。
1. 填一个名称，写明这是谁的程序，例如 `alice-laptop`。
1. 点**创建链接**（Create link）。通知里显示链接和**复制**（Copy）按钮，旁边是同一条链接的二维码。

![新建的客户端链接、复制按钮和二维码](/guide/zh/clients_link_qr.webp)

链接三十分钟内有效，只能用一次。手机上，对方用应用扫这个二维码。电脑上，对方把链接粘贴进客户端窗口，或者在终端里用它运行 `nclient join`。安装和加入的步骤在[桌面客户端](../client/desktop.md)和 [Android 应用](../client/android.md)里。

同一台电脑再次加入时，回到它原来那一行，名称换成新链接里的名称。页面标题旁的标记写在线台数，例如 **3 个中有 2 个在线**。

## 客户端列表

每一行显示**名称**（Name）、**主机名**（Hostname）、**平台**（Platform）、**版本**（Version）、**状态**（Status）和**最后出现**（Last seen）。停用的客户端带**已停用**（disabled）标记；不跟随默认权限的带**自定权限**（own permissions）标记。

## 权限

页面顶部的**默认权限**（Default permissions）管所有没有自定权限的客户端。每行的**权限**（Permissions）打开这个客户端自己的抽屉，里面的**跟随默认**（Follow the default）默认打开，关掉它才能单独设置。

每一类服务一个开关：

| 类型                            | 客户端得到什么                     |
| ------------------------------- | ---------------------------------- |
| **虚拟网**（Virtual network）   | 作为对等端加入中枢的虚拟网         |
| **网页**（Web pages）           | 网页条目，在浏览器里打开           |
| **端口**（Ports）               | 转发到本机 `127.0.0.1` 的 TCP 端口 |
| **AI 网关**（AI gateway）       | 自己的密钥和网关地址               |
| **文件**（Files）               | 可以挂载的 SMB 共享                |
| **终端**（Terminals）           | 受管机器上的 shell                 |
| **远程桌面**（Remote desktops） | 各台机器共享出来的桌面             |

改完开关后点**应用权限**（Apply permissions）。中枢把新列表推给这个客户端，或者推给所有跟随默认的客户端。

## 设备过滤

除了虚拟网，每个开关旁边都有一个过滤器，没收窄时写**所有 agent**（All agents）。收窄某一类服务的步骤：

1. 点这一类旁边的过滤器。
1. 勾选允许访问的受管设备。
1. 点**应用权限**。

一台都不勾，就是所有设备都允许。中枢自己的服务算在中枢这台机器的设备上；手动声明的服务算在它地址所在的设备上。在[设备](./devices.md)页忘记一台设备后，它从所有过滤器里消失；某一类的过滤器里只有这台设备时，这一类的开关随之关闭。

## 每个客户端的 AI 密钥

客户端加入后，中枢给它一把网关密钥，名字是 `client/` 加上客户端名称。密钥随客户端的状态一起下发，谁都不用手动输入。用量按密钥统计，在 [AI](./ai.md) 页的**接入**（Access）一节里查看。在那里点**吊销**（Revoke），这个客户端立即断开网关，中枢随即发给它一把新密钥。

## 停用或删除客户端

**停用**（Disable）关掉一个客户端：中枢吊销它的网关密钥，它的窗口显示**已被中枢关闭**，每个条目都变灰。**启用**（Enable）重新打开它，并发一把新密钥。

**删除**（Delete）吊销密钥并移除这一行。那台电脑上的程序失去这台中枢，只有拿到新链接才能重新加入。
