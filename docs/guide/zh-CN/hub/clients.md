# 客户端

你的电脑和手机加入中枢后，在 **客户端** 页上各占一行。在这一页上，你用一条链接接纳一个客户端，给它定权限，不再需要时停用或删除它。

## 生成客户端链接

1. 选择 **新建客户端链接**。
1. 填一个名称，例如 `laptop`。
1. 选择 **创建链接**。

页面显示链接、**复制** 按钮和二维码。手机扫二维码，电脑粘贴链接，步骤见[安装客户端](../install/client.md)。

![新建的客户端链接、复制按钮和二维码](/guide/zh/clients_link_qr.webp)

链接 30 分钟内有效，只能加入一台设备。30 分钟内中枢重启，链接照样能用。链接过期或用过之后，重新生成一条。加入失败时，见[故障排查](../reference/troubleshooting.md#加入中枢失败)。

链接里带着加入虚拟网用的 NetBird setup key 或 EasyTier 的网络密码、控制台地址，所以中枢存的 NetBird key 要能重复使用，见[把中枢加入 NetBird](./netbird.md)。

同一台电脑再次加入时，回到它原来那一行，名称换成新链接里的名称。

## 客户端列表

停用的客户端带 **已停用** 标记，有自己权限的带 **自定权限** 标记。标题旁写着在线台数，例如 **3 个中有 2 个在线**。

## 权限

页面顶部的 **默认权限** 管所有没有自定权限的客户端。每行的 **权限** 打开这个客户端自己的抽屉，关掉抽屉里的 **跟随默认** 才能单独设置。

| 类型                   | 客户端得到什么                                         |
| ---------------------- | ------------------------------------------------------ |
| **虚拟网**             | 作为对端加入中枢的虚拟网                               |
| **网页**               | 网页条目，在浏览器里打开                               |
| **端口**               | 转发到客户端本机 `127.0.0.1` 的端口                    |
| **AI 网关**            | 自己的网关密钥和网关地址                               |
| **文件**               | 可以挂载的 SMB 共享                                    |
| **终端**               | 被控端上的 shell                                       |
| **远程命令**           | 在被控端上用 `nclient terminal exec` 运行命令          |
| **远程桌面**           | 各台机器共享出来的桌面                                 |
| **免密码进入中枢面板** | 客户端中枢那一行上的 **面板** 按钮，打开时已经登录面板 |

除了 **远程命令** 和 **免密码进入中枢面板**，每一类默认都开着。**远程命令** 让脚本在无人值守时运行命令，用的是那台机器 **终端** 模块设的账户，没设时是 root，所以只给需要它的客户端打开。**免密码进入中枢面板** 让客户端不输密码就能改面板里的一切，只给你自己的设备打开；解锁保险库和改面板密码照样要口令和当前密码。

改完开关，选择 **应用权限**。在默认权限里应用，推给所有跟随默认的客户端；在抽屉里应用，只推给这一个。

![一个客户端的权限抽屉](/guide/zh/clients_permissions_panel.webp)

## 设备过滤

除了虚拟网和免密码进入中枢面板，每一类旁边有一个过滤器，没有收窄时写着 **所有被控端**。

1. 选择这一类旁边的过滤器。
1. 勾选允许访问的被控端。
1. 选择 **应用权限**。

一台都不勾，就是所有被控端都允许。中枢自己的服务算在行名为 `hub` 的机器上，手动声明的服务算在它地址所在的设备上。

## 每个客户端的 AI 密钥

客户端加入后，中枢自动给它一把网关密钥，名字是 `client/` 加客户端名称。用量按密钥统计，见 AI 页的 **活动** 一节；在 **接入** 一节 **吊销** 它，中枢随即发一把新的。

## 停用或删除客户端

| 操作     | 结果                                                               |
| -------- | ------------------------------------------------------------------ |
| **停用** | 中枢吊销它的网关密钥；客户端的中枢那一行写着已停用，每个条目都变灰 |
| **启用** | 重新打开这个客户端，中枢发给它一把新密钥                           |
| **删除** | 中枢吊销密钥并移除这一行；那台设备要拿新链接才能重新加入           |

停用、删除、客户端离开中枢，或者关掉它的 **免密码进入中枢面板**，它经 **面板** 按钮开着的面板会话都立刻结束。
