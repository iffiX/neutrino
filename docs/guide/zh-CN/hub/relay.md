# SSH 中继

SSH 中继是 **外部访问** 页上的一张卡片：中枢用 SSH 登录你的一台公网服务器，把服务器上的一个端口转发到中枢的 8443。准备服务器和第一次连上去的步骤，见[用自己的 VPS 中继连回家](../scenarios/vps_relay.md)。这一页列出卡片上的设置和状态。

## 设置项

| 设置         | 填什么                                                             |
| ------------ | ------------------------------------------------------------------ |
| **服务器**   | 服务器的主机名或 IP 地址                                           |
| **SSH 端口** | 服务器的 SSH 端口，默认 22                                         |
| **账户**     | 中枢登录服务器用的账户                                             |
| **对外端口** | 服务器上对外开放、转发到中枢 8443 的端口                           |
| **凭据**     | **SSH 密钥** 或 **密码**，再选[凭据](./credentials.md)页存好的一条 |

选择 **应用 SSH 中继** 保存设置并重新连接。每次应用，经它连着的客户端都断开，随后自己重新连上。

连上之后，**客户端连接地址** 显示 `https://<server>:<public-port>`，由服务器和对外端口组成。这个地址排在每条客户端链接、每台被控端地址列表的最后。**主机密钥** 显示第一次连接时记下的服务器密钥指纹。

## 看懂状态

转发启动 5 秒后，中枢自己去连这个公网地址，之后每分钟连一次。在那里碰到中枢自己的证书，状态才是 **已连上**。状态下方写着 SSH 输出的最后一行，或者检查没通过的原因。

| 状态                   | 含义                                               |
| ---------------------- | -------------------------------------------------- |
| **连接中**             | 转发已启动，第一次检查还没做完                     |
| **已连上**             | 公网端口上应答的是中枢自己的证书                   |
| **未配置**             | 服务器、账户、密钥或登录信息没填，或已从凭据里删掉 |
| **保管库已锁定**       | 这台机器上缺少保险库数据密钥的工作副本             |
| **认证失败**           | 服务器不接受这把密钥或这个密码                     |
| **服务器不让对外监听** | 服务器拒绝监听，或者别的程序占着这个端口           |
| **对外端口不通**       | 转发在运行，公网地址却没有应答，或应答的是别的证书 |
| **主机密钥已变**       | 服务器出示的密钥和记下的不一样                     |
| **连不上服务器**       | SSH 连不到服务器，或者连接断了                     |

状态不是 **已连上** 时怎么处理，见[故障排查](../reference/troubleshooting.md#外部访问)。

## 换一台服务器

应用新的 **服务器** 或 **SSH 端口** 时，中枢删掉记下的主机密钥，下次连接时记下新服务器的密钥。

同一地址上重装了系统时，先照[用自己的 VPS 中继连回家](../scenarios/vps_relay.md)重新设置服务器。然后在 **主机密钥** 旁选择 **忘记主机密钥**，再选 **忘记** 确认，中枢随即重新连接。
