# 外部访问

**外部访问**（Access）页上有四种从外面连回中枢的办法：直连、SSH 中继、NetBird 和 EasyTier。客户端和被控端不在中枢的局域网里时，经其中一种连到中枢的连接端口 8443。这一页管每种办法的开关、直连的设置、对端表和拓扑。几种办法各适合什么情况，见[选哪种外部访问](../scenarios/choose_a_way_in.md)。

## 打开一种外部访问

![四张卡片，开关都已打开](/guide/zh/overlay_switches.webp)

**组网方式**（Engine）一节每种办法一张卡片，顺序是直连、SSH 中继、NetBird、EasyTier，两张一行。国内版没有 NetBird 卡片。

1. 打开卡片上的 **启用**（Enable）开关。
1. 选择 **应用外部访问**（Apply access）。

引擎还没装时，中枢先装上它。然后中枢先启动开着的引擎，再停掉关掉的引擎。正在运行的卡片带 **使用中**（active）标记。写着 **这台机器没有对应的版本**（No build for this machine）的卡片打不开。

选中卡片本身，只切换下方显示哪一组设置。一种办法开着并且应用过，才显示它的设置。

打开 NetBird 或 EasyTier 时，如果它的网段和另一张虚拟网重叠，或和这台机器有地址的任何网络重叠，中枢拒绝并返回 `overlay_subnet_overlap`。NetBird 的网段是 `100.64.0.0/10`。EasyTier 的网段由本机在这张网里的地址决定。

## 打开直连

直连让客户端直接连中枢自己的地址，中间不经过别的服务器。你的设备能连到中枢的某个网口，或者路由器把一个公网端口转给了中枢，就用直连。

直连只开放连接端口 8443。它在每个启用的网口上开放这个端口：路由器形态下是角色不为 **停用**（Disabled）的网口，服务器和旁路网关形态下是网络页列出的每个网口。面板网页不在 8443 上，它和 AI 网关仍按[网络](./network.md)页的开放范围应答。所以直连开放的 8443 打不开面板网页。

1. 打开 **直连**（Direct）卡片的开关，选择 **应用外部访问**。
1. 可选：在 **公网地址**（Public address）里填从外面能连到中枢的主机名或 IP 地址，例如路由器转给中枢的那个地址。
1. 可选：在 **公网端口**（Public port）里填那个地址上对外的端口，也就是路由器转到中枢 8443 的那个端口，默认 8443。
1. 选择 **应用直连**（Apply Direct）。

![直连的设置和客户端连接地址](/guide/zh/overlay_direct_settings.webp)

**客户端连接地址**（Addresses for clients）列出直连发给客户端和被控端的地址。先是中枢自己网口上的地址，再是公网地址。网口上稳定的 IPv6 地址也列在里面，临时地址和链路本地地址不列。这一栏的几种显示：

| 显示                                                                                              | 含义                                             |
| ------------------------------------------------------------------------------------------------- | ------------------------------------------------ |
| 一列地址                                                                                          | 直连发出去的地址                                 |
| **没有哪个启用的网口有地址。**（No enabled interface has an address.）                            | 没有启用的网口拿到地址                           |
| **每个有地址的启用网口都已开放……**（Every enabled interface with an address is already exposed…） | 这些网口已经开放，直连不再添加；公网地址照样能填 |

公网地址既不是 IP 地址也不是主机名时，中枢拒绝并返回 `direct_host_invalid`。端口不在 1 到 65535 之间时，返回 `port_out_of_range`。

## 设置另外几种

SSH 中继、NetBird 和 EasyTier 的设置各有一页。

### SSH 中继

经你自己的一台公网服务器转发到中枢，步骤在[经自己的服务器连到中枢](./relay.md)。

### NetBird

用 NetBird 的 setup key 让中枢加入一张 NetBird 网，步骤在[把中枢加入 NetBird](./netbird.md)。

### EasyTier

经 EasyTier 控制台或手动碰头点组网，步骤在[把中枢放到 EasyTier 网络里](./easytier.md)。

## 同时开几种

四种办法可以同时开着。中枢对两张虚拟网的处理如下：

- 网段重叠时，中枢拒绝打开，返回 `overlay_subnet_overlap`。EasyTier 运行中改地址时，中枢做同样的检查。
- 从一张虚拟网进来、要从另一张出去的数据包，中枢一律丢弃。
- 某张虚拟网装了和其他网络重叠的路由时，页面用红字列出。NetBird 的这种路由，中枢取消选中；EasyTier 的只报告，到管理这张网的地方去改。
- 经虚拟网的默认路由，中枢删掉，并显示 `overlay_default_route_refused`。中枢仍从自己的上行出网。

客户端每一轮同时拨中枢的所有地址。还没连上时，先完成握手的那条连接留下。已经连上之后，网络一变化，客户端再拨一轮；新一轮先握手成功的路径排名更高时，客户端才换过去。排名从高到低是局域网、直连、NetBird 和 EasyTier、SSH 中继。

## 关掉一种外部访问

1. 关掉卡片上的开关。
1. 读应用栏里的警告。
1. 选择 **应用外部访问**。

![应用栏里关于在线客户端的警告](/guide/zh/overlay_off_warning.webp)

警告写着有几台在线客户端正经这种办法连着，以及经它进入这台机器的通路会关闭。中枢把新地址发给每个客户端和被控端，然后停掉引擎。设置保留，再打开时按原来的设置启动。

## 看对端表和拓扑

NetBird 和 EasyTier 的设置末尾是 **节点**（Peers），每 5 秒刷新一次。每行有对端的名称、虚拟网地址、连接方式和收发字节数。连接方式是 **直连**（direct）或 **中继**（relayed）。

时延一栏通常由引擎给出。经中继的 NetBird 对端没有引擎时延，这时显示中枢自己 ping 那个对端得到的往返时间。NetBird 还显示上次握手距今多久。EasyTier 还显示协议和丢包率。

空表有两种写法。NetBird 写着 **还没有节点。在另一台设备上用 NetBird 应用登录。**（No peers yet. Log in on another device with the NetBird app.）EasyTier 写着 **还没有机器加入。**（No machine has joined yet.）

设置上方的 **拓扑**（Topology）画出本机、它的局域网和各个对端。本机在虚拟网上是否应答自己的服务，由网络页的 **开放范围**（Exposure）决定。
