# 文件

hub 的 **文件**（Files）页是一台被控端机器的文件浏览器，浏览、上传、下载、改名和删除都在这一页完成。

![文件页](/guide/zh/files.webp)

1. 打开 **文件**（Files）页。
1. 在 **选择机器**（Which machine）里选一台在线的被控端。
1. 在目录列表里进出目录，`.. 上一级` 回到上一层。

被控端在那台机器上以 root 读写，所以每个路径都能到。工具栏上的按钮：

| 按钮                                         | 做什么                                     |
| -------------------------------------------- | ------------------------------------------ |
| **上传**（Upload）                           | 把本地文件放进当前目录                     |
| **下载**（Download）                         | 取回一个文件                               |
| **打包成 tar.gz 下载**（Download as tar.gz） | 取回一个目录                               |
| **新建文件夹**（New folder）                 | 在当前目录建一个文件夹                     |
| **重命名**（Rename）                         | 就地改名；改成另一个路径就是移动           |
| **删除**（Delete）                           | 要点两次，第二次是红色的对勾，删除不能撤销 |

机器离线时 hub 返回 `agent_offline`，什么都不读不写。设备抽屉里的 **文件** 按钮打开同一页并选好那台机器。
