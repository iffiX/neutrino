# 总览

**总览**（Dashboard）是登录后打开的第一页，实时显示这台机器的流量、出口、DNS 和在上报的设备。磁贴和实时图表读同一条数据流，中枢每秒推送一帧；某张卡片的数据源出错时，只有这张卡片报错。

![总览页的磁贴和卡片](/guide/zh/dashboard.webp)

## 标题栏

标题旁的圆点表示实时数据流的状态：**接收中**（streaming）、**连接中**（connecting）或 **统计连接已断开**（stats socket offline）。有代理开关开着、而所有启用的出口节点都不可达时，标题下出现红色提示 **所有启用的出口节点都不可达。** 打开了 **出口节点都不应答时直接放行**（Let traffic out directly when no exit node answers）时，提示变成黄色，说明送往代理的流量正改从 WAN 出去。

## 磁贴

| 磁贴                        | 数值                                                   | 下方一行                                               |
| --------------------------- | ------------------------------------------------------ | ------------------------------------------------------ |
| **下载**（Download）        | 上行网口当前的接收速率                                 | 今日接收的字节数，取自 vnstat                          |
| **上传**（Upload）          | 上行网口当前的发送速率                                 | 今日发送的字节数                                       |
| **DNS 查询**（DNS queries） | dnsmasq 日志最近 2000 行里的查询条数                   | **来自最近的日志**（in the recent log）                |
| **代理出口**（Proxy exits） | 最近两分钟里传过流量的出口节点数                       | 中枢测量的节点数，写作 **已探测**（probed）            |
| **AI token**（AI tokens）   | AI 网关今天服务的 token 数；网关没有上报时显示一条横线 | **今日已服务**（served today）                         |
| **设备**（Devices）         | 当前连在中枢上的被控端数                               | **个代理在上报**（agents reporting）                   |
| **CPU**                     | 这台机器的处理器负载                                   | 进度条，70% 起变黄，90% 起变红                         |
| **内存**（Memory）          | 这台机器已用的内存                                     | 进度条，颜色规则相同                                   |
| **运行时间**（Uptime）      | 这台机器开机以来的时长                                 | 上行网口的地址，或 **没有 WAN 地址**（no WAN address） |

上行网口是第一个 WAN 角色的接口。服务器和旁路网关形态下，它是默认路由所走的接口。

## 实时流量

**实时流量**（Live traffic）画出上行网口 **最近 2 分钟**（last 2 min）的速率，**下行**（down）和 **上行**（up）各一块面积，图例里是当前值。

| 范围                | 图表统计的内容               |
| ------------------- | ---------------------------- |
| **全部**（All）     | 上行网口上的全部字节         |
| **代理**（Proxied） | xray 交给出口节点的字节      |
| **直连**（Direct）  | 上行网口的字节减去代理的字节 |

直连里包含不经过 xray 的流量，例如虚拟网引擎自己的数据包。收到两帧之前，卡片写着 **正在等待第一批统计帧**（Waiting for the first stats frames）。

## 流量历史

**流量历史**（Traffic history）用堆叠柱状图显示 vnstat 记录的上行网口 **接收**（received）和 **发送**（sent）字节，可按 **天**（Day）、**周**（Week）、**月**（Month）、**年**（Year）切换，默认是 **月**。新装的机器在 vnstat 攒够一天样本之前，写着 **还没有历史**（No history yet）。

## 活动出口

**活动出口**（Active exits）列出最近两分钟里传过字节的出口节点，流量大的在前。每行有节点名、最近一次测得的时延，以及这段时间的字节数，写作 **/ 2 分钟**。上次测量失败的节点用红点标出。没有出口在传流量时，卡片写着 **没有出口在承载流量**（No exit is carrying traffic）：要么服务的网络空闲，要么每个请求都命中了直连规则。

## DNS 查询

**DNS 查询** 卡片按 **最新在前**（newest first）列出服务网络里解析的域名，徽章上的 **已保留**（held）是当前保留的行数。每行有时间、域名、发起查询的设备地址，以及应答的解析器：

| 标记     | 应答方                                           |
| -------- | ------------------------------------------------ |
| `cached` | dnsmasq 的缓存                                   |
| `config` | dnsmasq 自己的记录，例如 `hub.neutrino.internal` |
| `direct` | [代理](./proxy.md)页的直连解析器                 |
| `xray`   | xray，由它自己选直连解析器或远程解析器           |

还在等应答的行写着 **等待中**（pending）。服务器形态不服务任何网络，卡片写着 **还没有 DNS 查询**（No DNS queries yet）。

## AI 用量

**AI 用量**（AI usage）按 **天**、**周**、**月**、**年** 显示网关的请求和 token，可以看 **全部密钥**（All keys）或单独一把。磁贴有 **请求**（Requests）、**Tokens**、**RPM**、**TPM**、**缓存率**（Cache rate）和 **日均**（Daily average），下面是 **Token 活动**（Token activity）和 **请求健康度**（Request health）两张格子图。网关和密钥见 [AI](./ai.md) 页。
