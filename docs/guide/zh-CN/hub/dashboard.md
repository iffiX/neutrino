# 总览

**总览** 是登录面板后的第一页，显示这台机器的流量、出口、DNS 查询和在上报的被控端。数据每秒更新一次；一张卡片的数据出错时，只有这张卡片报错。

![总览页的磁贴和卡片](/guide/zh/dashboard.webp)

## 标题栏

标题旁的圆点写着实时数据的状态：**接收中**、**连接中** 或 **实时统计已断开**。所有启用的出口节点都不可达时，标题下出现红色提示。[代理](./proxy.md)页打开了直接放行的开关时，提示是黄色，送往代理的流量改从 WAN 出去。

## 磁贴

| 磁贴               | 数值                               | 下方一行                             |
| ------------------ | ---------------------------------- | ------------------------------------ |
| **下载**、**上传** | 上行网口当前的接收、发送速率       | 今日的字节数，取自 vnstat            |
| **DNS 查询**       | dnsmasq 日志最近 2000 行里的查询数 | **来自最近的日志**                   |
| **代理出口**       | 最近两分钟传过流量的出口节点数     | 测量过的节点数，写作 **已探测**      |
| **AI token**       | AI 网关今天服务的 token 数         | **今日已服务**                       |
| **设备**           | 连着中枢的被控端数                 | **个被控端在上报**                   |
| **CPU**、**内存**  | 处理器负载、已用内存               | 进度条，70% 起变黄，90% 起变红       |
| **运行时间**       | 开机以来的时长                     | 上行网口的地址，或 **没有 WAN 地址** |

上行网口是第一个 WAN 角色的网口。服务器和旁路网关模式下，它是默认路由走的网口。

## 实时流量

**实时流量** 画出上行网口 **最近 2 分钟** 的 **下行** 和 **上行** 速率。

| 范围     | 统计什么                                 |
| -------- | ---------------------------------------- |
| **全部** | 上行网口上的全部字节                     |
| **代理** | xray 交给出口节点的字节                  |
| **直连** | 全部减去代理，包括虚拟网引擎自己的数据包 |

## 流量历史

**流量历史** 用柱状图显示 vnstat 记下的 **接收** 和 **发送** 字节，按天、周、月、年切换，默认是月。新装的机器写着 **还没有历史**，vnstat 攒够一天的样本后才有图。

## 活动出口

**活动出口** 列出最近两分钟传过字节的出口节点，流量大的在前。每行有节点名、时延和 **/ 2 分钟** 的字节数。上次测量失败的节点带红点。

## DNS 查询

**DNS 查询** 卡片按 **最新在前** 列出服务网络里解析的域名。每行有时间、域名、发起查询的设备地址和应答方：

| 标记     | 应答方                                                                                       |
| -------- | -------------------------------------------------------------------------------------------- |
| `cached` | dnsmasq 的缓存                                                                               |
| `config` | dnsmasq 自己的记录，例如 `hub.neutrino.internal`                                             |
| `direct` | dnsmasq 直接查询的解析器：上行线路的解析器，开了直连兜底时是[代理](./proxy.md)页的直连解析器 |
| `xray`   | xray，由它自己选直连解析器或远程解析器                                                       |

服务器模式不服务任何网络，卡片写着 **还没有 DNS 查询**。
