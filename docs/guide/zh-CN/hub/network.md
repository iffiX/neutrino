# 网络

**网络** 页列出中枢所在机器的网络设置：模式、网口角色、DHCP、无线、开放范围和端口。每一节有自己的应用栏，只应用这一节的内容。把中枢从服务器换成路由器或旁路网关的步骤，见[把中枢配置成路由器或旁路网关](../scenarios/router_or_gateway.md)。

| 节               | 出现在               | 设置什么                       |
| ---------------- | -------------------- | ------------------------------ |
| **模式**         | 所有模式             | 机器的模式                     |
| **上游网关**     | 旁路网关             | 转发的流量送往哪台路由器       |
| **拓扑**         | 路由器               | 网口和网口上设备的示意图       |
| 网口标签页       | 路由器               | 每个网口的角色和地址           |
| **静态地址分配** | 路由器，有 LAN 时    | 总拿到同一个地址的设备         |
| **已知网络**     | 路由器，有无线网卡时 | WAN 无线网卡加入的网络         |
| **路由行为**     | 路由器               | 多条上行和多个服务网络怎么配合 |
| **开放范围**     | 所有模式             | 哪些网段的主机能连到中枢的端口 |
| **端口**         | 所有模式             | 面板的两个端口和连接端口       |

macOS 和 Windows 上只有服务器模式，网络页只有模式、开放范围和端口三节。

## 模式

![模式一节的三种模式](/guide/zh/network_modes.webp)

| 模式         | 做什么                             | 机器上的地址 |
| ------------ | ---------------------------------- | ------------ |
| **服务器**   | 不做路由，在它所连的网络上提供服务 | 保持原样     |
| **旁路网关** | 为把它设为网关的主机转发流量       | 保持原样     |
| **路由器**   | 在上行网口和它服务的网络之间路由   | 由中枢接管   |

当前模式带 **使用中** 标记。向导里的单臂路由，在面板上存成 **路由器**，主干的角色是 **拆分**。

## 上游网关

旁路网关模式下，网络原来的路由器照旧发放租约。**上游网关** 填那台路由器的地址，机器把转发的流量送到那里。**应用上游网关** 重写默认路由并重载防火墙。

## 网口角色

路由器模式下，每个网口一个标签页，**角色** 四选一：

| 角色     | 含义                 |
| -------- | -------------------- |
| **WAN**  | 通往互联网的上行线路 |
| **LAN**  | 网关自己服务的网络   |
| **拆分** | 切成多个 VLAN 的主干 |
| **停用** | 交给系统自己管理     |

WAN 网口选 **DHCP** 从上游取地址，或选 **静态** 手填 **地址**、**前缀长度** 和 **网关**。静态上行另有 **DNS** 列表，每行一个地址或 `<address>:<port>`。列表空着时，下方写着 **使用内置解析器 223.5.5.5、119.29.29.29**。

**优先级** 定多条上行的先后：**自动** 由网关自己排，**优先使用这条** 固定排在最前，**仅作备用** 只在没有别的上行时使用。

LAN 网口填 **网关地址** 和 **前缀长度**。第一个服务网络默认是 `192.168.8.0/24`，机器在 `192.168.8.1`。改完一个标签页，选择 **应用到** 加网口名的按钮。

**拆分** 主干上，不打标签的流量走主网口。每个 VLAN 号加成一个网口，应用之后各有自己的标签页。

**路由行为** 有两个开关，作用于整台网关：

- **把流量分摊到多条上行线路**：新连接分到不同的上行线路上。
- **网络之间可以互通**：一个服务网络里的设备能访问另一个服务网络。

## DHCP 与 DNS

在每个服务网络上，机器把自己的地址作为网关和解析器发给设备。LAN 标签页的 **DHCP** 一栏：

| 项                         | 含义                                             |
| -------------------------- | ------------------------------------------------ |
| **在这个网络上分配地址**   | 这个网络是否发放地址                             |
| **起始地址**、**结束地址** | 地址池，默认 `.100` 到 `.200`；网关地址在池外    |
| **租约时长**               | 写成 `12h`、`30m` 或 `1d` 这样的时长；默认 `12h` |

DHCP 关着时，机器照样应答 DNS。每个服务网络上，`hub.neutrino.internal` 都解析到机器在这个网络上的地址。

机器向上行线路的解析器查询：DHCP 上行用租约给出的，静态上行用自己的 **DNS** 行。没有一条上行给出解析器时，用内置的 `223.5.5.5` 和 `119.29.29.29`。[代理](./proxy.md)页的解析器只管走代理的域名。

**静态地址分配** 把一个 MAC 绑到一个固定地址：

1. 选择 **添加**。
1. 填 **MAC 地址**，或从已发现的设备里选一个。
1. 填 **地址**，需要时再填 **名字**。
1. 选择 **应用静态地址分配**。

地址要在某个发放地址的网络里，可以在地址池之外。设备下次续租时换到固定地址。填了名字的设备，在每个服务网络上都能按名字解析。

## 无线

WAN 角色的无线网卡加入一个网络，LAN 角色的无线网卡发布一个网络。

加入网络：在无线网卡的标签页里选择 **扫描网络**，选中网络，填密码，选择 **加入**。加入会把这个网口设为 WAN。**已知网络** 里靠前的优先加入。标着 **需要密码** 的条目，在扫描结果里选中它再输一次密码。**忘记** 删掉一个网络的密码。

LAN 无线网卡有 **接入点** 一栏：

| 字段         | 写法                                  |
| ------------ | ------------------------------------- |
| **网络名称** | 这块网卡发布的网络名                  |
| **密码**     | 8 到 63 个字符，仅支持 WPA2           |
| **国家代码** | 两个大写字母，ISO 3166-1 代码，可留空 |
| **频段**     | 2.4 GHz 或 5 GHz                      |

填了国家代码，**频段** 里才出现 5 GHz。应用时，中枢把系统的无线管制区设成这个国家。没有接入点模式的网卡不能设为 LAN。

## 开放范围

**开放范围** 决定谁能连到中枢自己的端口。发送方的地址在这里打开的一个网段里，才连得上。一个网段是一个网口的 IPv4 网络或 IPv6 网络，或者一张虚拟网。中枢自己的端口有这些：

| 端口                                        | 什么时候有             |
| ------------------------------------------- | ---------------------- |
| 面板的 **HTTP 端口** 和 **HTTPS 端口**      | 一直有                 |
| **连接端口**，默认 8443，被控端和客户端连它 | 一直有                 |
| DNS 的 53 端口，UDP 和 TCP                  | 路由器和旁路网关模式下 |
| [代理](./proxy.md)页上的每个 SOCKS 端口     | 代理有 SOCKS 端口时    |

AI 网关只在中枢的回环地址上监听，不归哪个格子管。

格子是一个网段的开关按钮。打开一个格子，上表里中枢的每个端口都对这个网段里的发送方开放。每个网口有两个格子，一个是它的 IPv4 网段，一个是它的 IPv6 网段。每个运行中的虚拟网也有一个格子，标着 **虚拟网**，默认打开。

格子上写着网口名和这个网口在该协议下的网络；路由器模式下还写着角色 **lan** 或 **wan**。直连不用格子，只把连接端口对所有发送方开放，在[外部访问](./overlay.md#打开直连)页打开。

1. 在 **开放范围** 里选择格子，打开或关掉它。
1. 读应用栏里的警告。
1. 选择 **应用开放范围**。页面写着 **已应用。**

![开放范围一节](/guide/zh/network_exposure.webp)

关掉一个格子时，警告写着有几台设备正经它连着中枢。打开 WAN 口的格子时，警告写着这条上行所在网段里的每台主机都能连到中枢的端口。IPv6 网段包括网口有地址的每个 IPv6 网络，也包括本链路的 `fe80::/64`；运营商换了前缀，格子的开关不变。

Linux 上，装好之后才插上的网卡，两个格子都关着，标着 **新网口，打开并应用后才使用**。macOS 和 Windows 上，系统新加的网卡两个格子都开着，要在这一节里关掉。

路由器模式下，打开角色为 **停用** 的网口的格子时，同一行出现角色选择，**应用开放范围** 把角色和开放设置一起写入。中枢拒绝设置时，见[故障排查](../reference/troubleshooting.md#中枢拒绝网络设置)。

### 不用格子就开放的端口

下面这些端口不归格子管，条件满足时自动开放：

- 运行中的虚拟网引擎的对端端口，对所有发送方开放：NetBird 的 UDP 51820，EasyTier 的 TCP 和 UDP 11010。
- DHCP 的 UDP 67 端口，开在中枢发放地址的网络上。

机器上的其他端口，中枢的规则一概不管，三种模式都一样。SSH、文件共享和不是中枢运行的服务，开不开由系统自己的防火墙决定。路由器模式也一样，WAN 口上的 SSH 归系统防火墙管：机器的 SSH 服务在所有地址上监听时，在系统防火墙里关掉 WAN 口的 22 端口。

### 规则写在哪里

| 系统    | 中枢把规则写进                                                                                            |
| ------- | --------------------------------------------------------------------------------------------------------- |
| Linux   | 中枢自己的 nftables 表里单独的一条链；运行着 firewalld 时，例如 RHEL 和 Rocky 上，也写进 firewalld 的区域 |
| Windows | Windows Defender 防火墙，每个端口一条规则，名字是 `neutrino_hub_` 加端口的用途                            |
| macOS   | pf 锚点 `com.apple/neutrino_hub`；中枢的程序另外登记在系统的应用防火墙里                                  |

选择 **应用开放范围** 时，中枢重写这些规则；开放的网口换了地址时也重写。运行 `nhub reset network` 或卸载中枢的包，这些规则随之删掉。

## 端口

**端口** 一节是中枢应答的三个 TCP 端口。面板用 **HTTP 端口**，默认 `8080`，和 **HTTPS 端口**，默认 `443`，向导里选过别的就用选过的。被控端和客户端连 **连接端口**，默认 `8443`。三个端口不能相同，各自只应答开放范围放进来的发送方。

### 改面板端口

1. 在 **端口** 一节改 **HTTP 端口**、**HTTPS 端口**，或者两个都改。
1. 选择 **应用端口**。

页面写着 **正在迁移到** 加新地址，到那里重新登录。从你这里访问不到新地址时，页面写着那个地址 **没有应答**。HTTP 端口是否转到 HTTPS，在[设置](./settings.md#https)页切换。

### 改连接端口

开始之前，要留下的客户端和被控端都要在线，中枢只把新端口发给此刻在线的那些。

1. 在 **端口** 一节改 **连接端口**。
1. 读应用栏里的警告。它写着此刻离线的客户端和被控端各有几个，它们会连不上这台中枢，要用 **客户端** 页或 **设备** 页的新链接重新加入。
1. 选择 **应用端口**。

中枢把新地址发给每个在线的客户端和被控端之后，重启面板的服务，被控端和客户端改连新端口。面板自己的端口不变，重启后重新登录。直连开着时，警告还写着路由器的端口转发和直连的公网端口也要跟着改，后者在[外部访问](./overlay.md#打开直连)页上。SakuraFrp 或 OpenFrp 选了隧道时，警告还提醒到服务商那里改隧道的本地端口，做法见[改了连接端口之后](./frp.md#改了连接端口之后)。
