# 网络

在**网络**（Network）页上，你设定这台机器在你的网络里是什么形态。路由器形态下，它还给每个接口定角色，设置服务网络的 DHCP 和 DNS。机器在哪些网络上应答，也在这一页设定。每一节有自己的应用栏，只改这一节显示的内容。

| 节                                  | 出现在               | 设置什么                       |
| ----------------------------------- | -------------------- | ------------------------------ |
| **模式**（Mode）                    | 所有模式             | 这台机器的形态                 |
| **上游网关**（Upstream gateway）    | 旁路网关             | 转发流量送往的路由器           |
| **拓扑**（Topology）                | 路由器               | 接口和接口上设备的示意图       |
| 接口标签页                          | 路由器               | 每个接口的角色和地址           |
| **静态地址分配**（Fixed addresses） | 路由器，有 LAN 时    | 总拿到同一个地址的设备         |
| **已知网络**（Known networks）      | 路由器，有无线网卡时 | WAN 无线网卡加入的网络         |
| **路由行为**（Routing behavior）    | 路由器               | 多条上行和多个服务网络怎么配合 |
| **开放范围**（Exposure）            | 所有模式             | 机器在哪些网络上接受连接       |
| **面板端口**（Panel ports）         | 所有模式             | 面板的 HTTP 端口和 HTTPS 端口  |

## 选择形态

![模式一节的三种形态](/guide/zh/network_modes.webp)

| 形态                         | 做什么                             | 机器上的地址 |
| ---------------------------- | ---------------------------------- | ------------ |
| **服务器**（Server）         | 不做路由，在别人访问它的网口上应答 | 保持机器原样 |
| **旁路网关**（Side gateway） | 为把它设为网关的主机转发流量       | 保持机器原样 |
| **路由器**（Router）         | 在上行网口和它服务的网络之间路由   | 由中枢接管   |

初始化向导里还有单臂路由：一根有线主干，不带标签出网，带 VLAN 标签入内。面板把它存为 **路由器**，主干的角色是 **拆分**（Split）。

换形态：

1. 在 **模式** 里选一个形态。当前形态带 **使用中**（active）标记。
1. 选择 **应用模式**（Apply mode）。中枢重写接口角色并重载防火墙。

进入路由器形态时，接口交给中枢管理，DHCP 上行可能拿到新地址。离开路由器形态时，接口交还给机器自己的网络管理器，服务网络随之结束。这两种情况下，应用栏都会先给出警告。离开旁路网关时，把这台机器设为网关的主机失去出网的路。

## 上游网关

旁路网关形态下，设备把这台机器设为网关就能用上代理，网络原来的路由器继续发放租约。**上游网关** 填那台路由器的地址，这台机器把转发的流量送到那里。**应用上游网关**（Apply upstream gateway）重写默认路由并重载防火墙。

## 接口角色

路由器形态下，每个接口一个标签页，**角色**（Role）四选一：

| 角色                 | 含义                 |
| -------------------- | -------------------- |
| **WAN**              | 通往互联网的上行线路 |
| **LAN**              | 网关自己服务的网络   |
| **拆分**（Split）    | 切成多个 VLAN 的主干 |
| **停用**（Disabled） | 不作任何处理         |

WAN 接口用 **DHCP** 从上游取地址，或用 **静态**（Static）手填 **地址**（Address）、**前缀长度**（Prefix length）和 **网关**（Gateway）。DHCP 上行的表单下方写着租约给出的解析器。静态上行在网关下方有 **DNS** 列表，每行一个地址或 `<address>:<port>`；列表空着时写着 **使用内置解析器 223.5.5.5、119.29.29.29**（Built-in resolvers: 223.5.5.5, 119.29.29.29）。**优先级**（Priority）有三档：**自动**（Automatic）由网关排序，**优先使用这条**（Prefer this one）排在最前，**仅作备用**（Backup only）只在没有其他上行时使用。**克隆 MAC**（Clone MAC）替换接口的硬件地址。

LAN 接口填 **网关地址**（Gateway address）和 **前缀长度**。第一个服务网络默认是 `192.168.8.0/24`，机器在 `192.168.8.1`。改完一个标签页，选择 **应用到**（Apply to）加接口名的按钮。

**拆分** 主干上，不打标签的流量走主接口，每个 VLAN 标签在 **VLAN** 一栏里加成一个接口。应用主干之后，每个 VLAN 有自己的标签页。

**路由行为** 有两个开关，作用于整台网关。**把流量分摊到多条上行线路**（Spread traffic across uplinks）把连接分到不同的上游线路上。**网络之间可以互通**（Networks reach each other）让一个服务网络里的设备访问另一个服务网络。**应用路由行为**（Apply routing behavior）重载防火墙并重建上行路由。

## DHCP 与 DNS

在每个服务网络上，机器把自己的地址作为网关和解析器发给 DHCP 客户端。LAN 标签页的 **DHCP** 一栏有这些项：

| 项                                                           | 含义                                                    |
| ------------------------------------------------------------ | ------------------------------------------------------- |
| **在这个网络上分配地址**（Allocate address on this network） | 这个网络是否发放地址                                    |
| **起始地址**（Range start）、**结束地址**（Range end）       | 地址池，默认 `.100` 到 `.200`；机器自己的地址在池外     |
| **租约时长**（Lease time）                                   | dnsmasq 的时长写法，例如 `12h`、`30m`、`1d`；默认 `12h` |

不论 DHCP 开不开，机器都在每个服务网络上应答 DNS。在每个服务网络上，`hub.neutrino.internal` 都解析到机器在这个网络上的地址。服务器形态不服务任何网络，不为别人提供 DHCP 和 DNS。

机器转发查询用的是上行线路的解析器：DHCP 上行用租约给出的，静态上行用自己的 **DNS** 行；有多条上行时，按上行的优先级依次排列。没有一条上行给出解析器时，用内置的 `223.5.5.5` 和 `119.29.29.29`。[代理](./proxy.md)页的两个列表只管代理范围内的流量。

**静态地址分配** 把一个 MAC 绑定到一个分配地址的网络里的固定地址：

1. 在 **静态地址分配** 里选择 **添加**（Add address）。
1. 填 **MAC 地址**（MAC address），或从已发现的设备里选一个。
1. 填 **地址**，需要时再填 **名字**（Name）。
1. 选择 **应用静态地址分配**（Apply fixed addresses）。

已经拿到动态地址的设备，下次续租时换到固定地址。填了名字的设备，在每个服务网络上都能按名字解析。

## 无线

WAN 角色的无线网卡加入一个网络，LAN 角色的无线网卡发布一个网络。

加入网络时，在无线网卡的标签页里选择 **扫描网络**（Scan for networks），选中网络，填密码，再选择 **加入**（Join）。加入会把这个接口设为 WAN。**已知网络** 列出 WAN 无线网卡会加入的网络，列表靠前的优先。写着 **需要密码**（needs a passphrase）的条目，中枢读不到它的密钥，在扫描结果里选中它再输一次。**忘记**（Forget）删掉密码。

LAN 无线网卡有 **接入点**（Access point）一栏：**网络名称**（Network name）、**密码**（Passphrase）和 **频段**（Band）。密码 8～63 个字符，仅支持 WPA2；频段是 2.4 GHz 或 5 GHz。没有接入点模式的网卡不能设为 LAN。

## 开放范围

**开放范围** 列出机器接受自身服务连接的网络，服务包括面板、SSH、DNS 和共享。每个开着的虚拟网也是一项，标着 **虚拟网**（overlay）。SOCKS 端口和虚拟网的对端端口在同样的网络上可达。

1. 在 **开放范围** 里勾选机器要应答的网络。
1. 选择 **应用开放范围**（Apply exposure）。页面写着 **已应用到防火墙。**（Applied to the firewall.）

![开放范围一节](/guide/zh/network_exposure.webp)

应用之前，应用栏会写出每一种损失。开放一条上行线路，机器在它监听的每个端口上都接受来自互联网的连接。取消勾选一个网络，这个网络就连不到机器，警告里写着有几台被控端正经它连着中枢。机器在网络之间转发的流量不受影响。

## 面板端口

面板在每个开放接口上占两个 TCP 端口：**HTTP 端口**（HTTP port）默认 `8080`，**HTTPS 端口**（HTTPS port）默认 `443`，setup 时选过别的就用选的。不管 HTTPS 开没开，两个端口都提供面板。每个字段下面写着这个端口当前的访问地址。

1. 在 **面板端口** 里填新的 **HTTP 端口**、新的 **HTTPS 端口**，或者两个都改。两个端口不能相同。
1. 选择 **应用面板端口**（Apply panel port）。

面板重启，页面写着 **正在迁移到**（Moving to）新地址，协议和你当前打开的一样，到那里重新登录。从你这里访问不到新地址时，页面写着那个地址 **没有应答**（No answer at）。HTTP 端口要不要把浏览器转到 HTTPS 端口，在[设置](./settings.md#https)页切换。
