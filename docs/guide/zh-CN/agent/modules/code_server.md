# code-server

Linux 或 Mac 受管机器上，**code-server** 模块给每个账户运行一个 code-server，也就是 Coder 以 MIT 许可发布的浏览器版 VS Code。模块的安装程序取来 Coder 独立发布包的一个固定版本，由被控端解包并运行。

| 系统    | 能运行它的机器                    |
| ------- | --------------------------------- |
| Linux   | amd64 和 arm64，glibc 2.28 及以上 |
| macOS   | Apple 芯片和 Intel                |
| Windows | 不支持，列表里是灰的              |

国内版的安装程序改从中科大镜像 `mirrors.ustc.edu.cn` 取同一个发布包，用 SHA-256 核对。镜像上没有这一版时，改装镜像上的最新版，只靠 HTTPS 核对。

## 启用

1. 在[模块](../modules.md)页的 **code-server** 标签上，选择 **安装**。
1. 选择 **配置**，标签下面展开 **实例**。

**实例** 顶上一行写着 **你在这台机器上安装 code-server，它是 Coder 以 MIT 许可发布的编辑器。** 机器上报版本后，这一行后面再跟版本号。

## 添加实例

1. 在 **实例** 下选择 **添加实例**。
1. 在 **账户** 里填这台机器上的一个账户名。
1. 可选：改 **端口**。第一个实例用 8443，之后每个用已占用的最大端口加一。
1. 选择 **应用 code-server**。机器保存实例，为每个账户启动 code-server。

每个实例以它的账户身份运行，设置和扩展放在这个账户主目录下。实例那一行写着 **运行中** 或 **未运行**，机器上报了原因时写在下面。应用时的拒绝见[故障排查](../../reference/troubleshooting.md#code-server)。

## 扩展

编辑器从 Open VSX 装扩展，Claude Code 和 Codex 的扩展都在上面。在编辑器的 **扩展** 视图里搜索就能装。

## 让它的 AI 工具走网关

实例所属账户的 Claude Code、Codex 和 Gemini 也能改用中枢的 AI 网关，见[把一台机器的 AI 工具指向网关](./ai_tools.md)。

## 实例的端口

一个账户对应一个实例，一个实例对应一个端口，范围 1024～65535，不能两个实例同号。这个端口是被控端的转发器在机器回环地址上监听的端口，和中枢自己的 8443 无关。code-server 本身监听一个套接字，只有它的账户和 root 能打开。客户端打开实例时，连的就是这个端口。

模块发布的只有实例的端口。在编辑器的终端里启动的程序，例如在 5173 端口上的开发服务器，客户端里没有它。要用它，到[服务](../../hub/services.md#手动声明服务)页把它声明成 **端口** 或 **网页**，**主机** 写这台机器的地址。中枢自己去连声明的服务，所以这个程序不能只监听 `127.0.0.1`。

## 从客户端打开

每个运行中的实例，都是[服务](../../hub/services.md)页 **网页** 组里的一行，标题是 **code-server** 加括号里的账户名。客户端要有那台机器的网页权限，权限在[客户端](../../hub/clients.md)页上设。

在客户端的 **网页** 页上选择 **打开**，浏览器打开实例。之后转发器在这个浏览器里设一个登录 cookie，有效期七天；过期后再选一次 **打开**。
