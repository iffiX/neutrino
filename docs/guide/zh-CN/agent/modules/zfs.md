# ZFS 存储（ZFS storage）

**ZFS storage** 标签管理受管 Linux 机器上的 ZFS 存储：建存储池和数据集，看每块磁盘的健康状况，需要时经文件共享发出去。中枢不保存想要的池清单。标签里显示的是机器自报的磁盘情况，每个按钮都在你按下时当场在机器上执行。

开始之前，在[模块](../modules.md)页的 **ZFS storage** 标签下依次选择 **安装**（Install）和 **配置**（Configure）。安装时一并装上 smartmontools，用来读磁盘健康。标签下面随即展开 **拓扑**（Topology）、**存储池**（Pools）和 **数据集**（Datasets）。

![server 的 ZFS storage 标签，一个存储池和它的磁盘](/guide/zh/zfs.webp)

## 建池

1. 在 **存储池** 下选择 **创建存储池**（Create pool）。
1. 填 **池名**（Pool name）。
1. 在 **第一个 vdev 的磁盘**（First vdev disks）里勾选磁盘。
1. 在 **vdev 布局**（Vdev layout）里选一种布局。盘数够了，对应的布局才可选。
1. 选中的盘上有数据时，输入 `wipe` 确认抹掉。
1. 选择 **创建存储池**。

vdev 是池里的一组磁盘，布局决定这一组最多能坏几块：

| 布局               | 效果        |
| ------------------ | ----------- |
| **单盘**（Single） | 无冗余      |
| **镜像**（Mirror） | 完整副本    |
| **RAID-Z1**        | 可坏 1 块盘 |
| **RAID-Z2**        | 可坏 2 块盘 |

池上的 **扩容**（Expand）给池再加一个 vdev。新 vdev 永久加入这个池，之后无法移除。

::: warning
新 vdev 的布局和池里其他 vdev 不一致时，池的安全程度只取决于最弱的那个 vdev。添加这样的 vdev，要再按一次 **仍然添加**（Add anyway）。
:::

接入的磁盘上有这台机器还没导入的池时，标签里显示池名和 **导入**（Import）按钮。**销毁存储池**（Destroy pool）要先输入池名，然后抹掉池上的所有数据集。

## 磁盘健康

**拓扑** 画出每个池的 vdev 和磁盘，没用上的盘标为 **未分配**（UNASSIGNED）。每块盘显示 **SMART 正常**（SMART ok）或 **SMART 即将故障**（SMART FAILING）；磁盘报告温度时，温度也一起显示。选中一块盘，能看到型号、序列号、容量、SMART 结果，以及读、写和校验错误的次数。

- 池上的 **校验**（Scrub）按校验和检查池里的每个数据块。
- **下线**（Offline）把选中的盘暂时从池里摘下，**上线**（Online）再接回去。
- 选中的盘上按 **替换**（Replace），列出空闲盘。挑一块，选择 **开始重建**（Start resilver），数据就重建到这块盘上。

没有接空闲盘时，**替换** 不可用，提示文字是 **没有可用来替换的空闲盘**（No spare disk to replace with）。

## 数据集

1. 在 **数据集** 下选择 **添加数据集**（Add dataset）。
1. 选 **存储池**（Pool），填 **名称**（Name）。
1. 可选：设置 **挂载点**（Mountpoint）。留空时是 `/池名/名称`。
1. 选 **压缩**（Compression）和 **记录大小**（Record size）。小记录适合数据库和虚拟机镜像，大记录适合媒体和归档。
1. 选择 **创建数据集**（Create dataset）。

每个数据集一行，显示压缩方式、记录大小和使用率。**销毁**（Destroy）删掉数据集和上面的每个文件，只有事先做过的快照能把它们找回来。

## 共享数据集

1. 在已挂载的数据集那一行，选择 **共享**（Share）。
1. 勾选能用这个共享的用户；一个都不勾时，所有用户都能用，以后新增的也一样。
1. 选择 **共享**。

同一台机器上的[文件共享（File share）](./shares.md)模块经 SMB 导出数据集的挂载点，勾选的用户可以读写。File share 模块没装或没启动时，按钮写着 **请先安装并启动 Samba**（Install and start Samba first）。共享之后，这一行带一个 `smb` 标记和共享名，**取消共享**（Unshare）把它收回。
