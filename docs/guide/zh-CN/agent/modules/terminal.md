# 终端模块

受管机器上的终端以哪个账户运行、启动哪个 shell 程序，由 **终端** 模块设定。被控端的安装包里带着它，所以每台受管机器都有这个标签，不用安装，也不能卸载。

| 系统    | 能设置的内容                        |
| ------- | ----------------------------------- |
| Linux   | 账户和 shell 程序                   |
| macOS   | 账户和 shell 程序                   |
| Windows | 只有 shell 程序，终端以 SYSTEM 运行 |

## 设置账户和 shell

1. 在[模块](../modules.md)页的 **终端** 标签上，选一个 **账户**。
1. 可选：在 **Shell 程序** 里填程序的完整路径，或者选择 **浏览…**，在这台机器上选中程序。
1. 选择 **应用终端设置**。

![server 的终端标签，选了一个账户](/guide/zh/modules_terminal_tab.webp)

**账户** 的默认值是 **被控端自己的账户（root；Windows 上是 SYSTEM）**。**Shell 程序** 留空时，用这个账户的登录 shell，Windows 上是 PowerShell。为某个账户开的终端，从它的主目录启动，用它自己的环境变量。

之后打开的终端都按新设置运行，面板的[终端](../terminals.md)页和客户端开的都一样。已经打开的终端和容器里的 shell 不受影响。

账户或程序后来从机器上消失时，新开的终端打不开，终端也不改用 root 运行。拒绝的原因见[故障排查](../../reference/troubleshooting.md#终端)。
