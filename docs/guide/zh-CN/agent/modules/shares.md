# File share

**File share** 模块把被控端机器上的文件夹通过 SMB 共享出去，客户端一键就能挂载。机器可以是 Linux、Windows 或 Mac。Linux 上，模块装好并运行 Samba；Windows 和 macOS 上，模块驱动系统自带的 SMB 服务，所以 **安装**（Install）在那里什么都不下载。

开始之前，在[模块](../modules.md)页的 **File share** 标签下依次选择 **安装** 和 **配置**（Configure）。标签下面随即展开 **共享**（Shares）、**用户**（Users）和 **当前连接**（Now serving）三个分区。

## 添加共享

1. 在 **共享** 下选择 **添加共享**（Add share）。
1. 填 **名称**（Name）和 **路径**（Path），路径是机器上的文件夹。
1. 可选：填 **备注**（Comment）。
1. 可选：打开 **只读**（Read only），对所有人都拒绝写入。
1. 在 **谁可以用**（Who may use it）里勾选这个共享接受的用户。
1. 选择 **应用共享**（Apply shares）。机器保存共享，并重载 SMB 服务。

一个用户都不勾时，**用户** 里的每个账号都能用这个共享。Windows 上，如果一个账号都没有，只有这台机器的管理员能用。共享名旁边的复制按钮复制它的 `smb://` 地址。

## 添加用户

用户是客户端登录时用的账号。**添加用户**（Add user）把用户名和密码一起暂存，**应用用户**（Apply users）创建账号、设置暂存的密码、吊销已移除的账号。要换密码，先移除这个用户，再重新添加。

应用之前，用户行写着 **应用时创建**（created on apply）或 **应用时设置密码**（password set on apply）；应用之后写 **就绪**（ready）。密码只存在机器自己的账号库里。从备份恢复之后，用户行写着 **还没有密码**（no password yet），重新添加一次才有。

## 允许的子网

hub 自己算出机器上的共享对哪些网络开放，依据是[网络](../../hub/network.md)页的设置：hub 服务的子网、暴露的网口和暴露的虚拟网。服务器形态下，这台盒子有地址的每个网络都算在内。要改这份清单，去改 **网络** 页。网络一变，hub 就把新的子网清单发给每台在线机器。

| 系统    | 机器怎样把 SMB 限制在这些子网                                                          |
| ------- | -------------------------------------------------------------------------------------- |
| Linux   | Samba 的 `hosts allow`，另加 `127.0.0.1`                                               |
| Windows | 一条名为 **Neutrino file share fence** 的防火墙规则，拦下其他所有地址到 TCP 445 的连接 |
| macOS   | pf 锚点 `com.apple/neutrino_smb`，被控端每次启动时重新加载                             |

::: warning
Windows 和 macOS 上，这道限制作用于机器上的所有共享，你在 hub 之外自己建的共享也包括在内。
:::

## Windows 和 macOS 上

模块只改动它自己建的共享和账号，你自己的共享和账号保持原样。第一次 **配置** 也只收下这个模块以前建的共享和账号。**共享** 分区里写着 **这台机器用系统自带的 SMB 服务提供这些共享。**

![一台 Windows 机器的 File share 标签和它的共享](/guide/zh/shares_windows.webp)

- Windows 上，每个账号都是本地账号，不属于任何组，不出现在登录界面上，也不能在本机或通过远程桌面登录。
- macOS 上，每个账号没有登录 shell，没有主目录，并且隐藏。
- **卸载**（Uninstall）移除模块的共享，停用它的账号，删掉这道限制。

macOS 保护每个账号的桌面、文稿和下载文件夹。要共享其中的文件夹，在 **系统设置** > **隐私与安全性** > **完全磁盘访问权限** 里加入 SMB 服务。其他位置的文件夹，比如 `/Users/Shared` 下面的，直接就能共享。

## 当前连接

**当前连接** 列出此刻机器上打开的连接：用户、客户端的名字或地址，以及它打开的共享。列表下面，每个共享有一条进度条，显示它所在磁盘的用量。没有人连接时，列表写着 **没有人连接。**

## 发布到哪里

每个共享是[服务](../../hub/services.md)页 **文件**（Files）组里的一行，来源写着由那台机器上的 samba 模块发布。在[桌面客户端](../../client/desktop.md)里，它是 **文件** 面板中的一项，用 **配置**（Config）和 **挂载**（Mount）挂上。在 Android 上，它是系统“文件”应用里的一个位置。
