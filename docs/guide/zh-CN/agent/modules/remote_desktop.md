# Remote desktop

**Remote desktop**（远程桌面）模块把受管机器的桌面共享给这台中枢的客户端。它只有一个开关，新机器上默认关着。被控端自己的安装包里带着 RustDesk，不用安装：开关决定被控端的 RustDesk 跑不跑。

## 共享桌面

1. 在[模块](../modules.md)页的 **Remote desktop** 标签上，打开**共享这台机器的桌面**（Share this machine's desktop）。
1. 点**应用远程桌面**（Apply remote desktop）。
1. 在客户端的**远程桌面**（Remote desktops）里点**连接**（Connect）。

开关打开后，被控端会停掉机器上其它的 RustDesk 主机，用 RustDesk 自己的服务名运行它自带的那一份，所以机器重启后共享会自动恢复。有人正在这台机器上用的 RustDesk 查看器不受影响。共享走直连端口 21118，不经过任何公共服务器。观看者看到的，是正坐在屏幕前登录的那个人的桌面。

开关第一次打开时，中枢生成坐席密码并保管。设备抽屉里的**重置坐席密码**（Reset seat password）会立即给机器换一个，并断开所有观看者。

## 停止共享

关掉开关，再点**应用远程桌面**。被控端的 RustDesk 停下，你原先装在这台机器上的 RustDesk 恢复原样。卸载被控端时，也会先这样停下它的 RustDesk。

## 失败时

哪一步失败，标签上就显示它的代码；再点**应用远程桌面**会重试这一步。

| 代码                  | 原因                                                 |
| --------------------- | ---------------------------------------------------- |
| `rdp_takeover_failed` | 启动被控端 RustDesk 的某一步失败，代码里写着是哪一步 |
| `rdp_restore_failed`  | 还原机器原来的 RustDesk 的某一步失败                 |

共享没有可显示的内容时，客户端的**连接**会被拒绝：

| 代码                     | 原因                                                     |
| ------------------------ | -------------------------------------------------------- |
| `rdp_nobody_seated`      | 机器屏幕前没人登录                                       |
| `rdp_screen_not_allowed` | Wayland 会话还没允许屏幕共享，在那台机器的屏幕上允许一次 |

在 Mac 上，屏幕前的人要给 RustDesk 授一次“屏幕录制”和“辅助功能”权限。开关打开时，Mac 上会弹出对话框列出这两项。
