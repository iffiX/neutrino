# 终端

**终端**（Terminals）页在受管机器上开 shell，机器的被控端要在线。读完这页，你能在面板里开一个 shell，按需要保留或共享它，之后回到机器上的任何一个会话。

![终端页，server 上的两个 shell 标签，持久开关已打开](/guide/zh/terminals_persist.webp)

## 打开 shell

1. 在 **选择机器**（Which machine）里选一台机器，比如 `server`。
1. 选择 **新终端**（New terminal）。

新标签以机器名命名。shell 以这台机器 Terminal 模块设的账户运行，模块没设账户时以 root 运行。Windows 机器上，shell 以 SYSTEM 运行，默认是 PowerShell。账户和 shell 程序怎样设，见[终端（Terminal）](./modules/terminal.md)。

按键直接送到机器上，Escape 也一样。切到面板别的页面时，标签保持打开。[设备](../hub/devices.md)页抽屉里的 **终端**（Terminal）按钮也打开本页，并选好那台机器。

## 保留或共享会话

shell 下方有 **持久**（Persistent）和 **共享**（Shared）两个开关，作用于当前显示的标签。新标签的两个开关都关着。

标签连着机器，圆点显示 **已连接**（open），而且会话是面板开的，开关才能拨。会话由别处打开时，开关是灰的，旁边写着 **由 laptop 打开**（Opened by laptop）这样的一行，名字是开会话的客户端。

- 开着 **持久**：关掉浏览器、刷新面板或退出登录，shell 都在机器上继续运行。
- 开着 **共享**：对这台机器有终端权限的客户端都能列出并接上这个会话。最后一个窗口断开后，会话继续运行。
- 两个都关着：最后一个窗口断开时，shell 随之结束。

会话由被控端进程持有。被控端重启或升级时，机器上的所有会话都结束。

## 回到会话

面板载入时，本页给在线机器上的每个会话各开一个标签，按创建先后排列。第一个标签立刻接上，先显示会话最近 256 KB 的输出。其他标签在你选中时接上。之后在别处新开的会话，也作为新标签出现。

| 标签上的标记       | 意思                   |
| ------------------ | ---------------------- |
| **保留**（kept）   | 会话是持久的           |
| **共享**（shared） | 会话是共享的           |
| **2 处**（2 open） | 有两个窗口接着这个会话 |

面板能接上任何会话，包括客户端开的、没有共享的会话。客户端只能接上自己开的会话和共享的会话。开会话的客户端关掉 **共享** 时，别的客户端立刻断开，标签下显示 `session_not_owned` 的说明。面板里接着的标签保持连接。

## 在几个窗口里看同一个会话

一个会话能同时接上任意多个窗口，浏览器和客户端都算，和 tmux 一样。每个窗口显示同样的输出，任一窗口的按键都送进 shell。shell 的列数和行数取最小的那个窗口。

## 结束会话

- 面板自己开的标签，两个开关都关着：选标签上的 ×，标签关闭，shell 结束。
- 其他标签：× 要按两次。第一次按下只做准备，提示文字变成再按一次就在机器上结束；第二次按下才结束会话。
- 任何标签：在 shell 里运行 `exit`。

## 标签自己结束

会话在机器上结束时，标签显示 **已结束**（Ended），并留着最后的输出。有人运行了 `exit`，或者从别的窗口结束了会话，都是这样。选 × 关掉这个标签。

标签和机器之间的连接断开时，shell 下方显示 **这个会话已经关闭。**（This session closed.）。中枢关闭连接时带了错误码，这一行就换成这个码的说明。
