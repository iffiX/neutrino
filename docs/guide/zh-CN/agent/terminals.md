# 终端

在 **终端**（Terminals）页上，你能给被控端在线的任一台机器开一个 root shell。打开 **持久**（Persistent）开关的 shell，在你关掉浏览器之后仍留在那台机器上运行。

![终端页，两个 shell 标签，持久开关已打开](/guide/zh/terminals_persist.webp)

## 打开 shell

1. 在 **选择机器**（Which machine）里选一台机器。
1. 选择 **新终端**（New terminal）。

新标签以机器名命名，里面是 root shell；Windows 机器上是 PowerShell。按键直接送到机器上，Escape 也一样。切到面板的其他页面时，标签保持打开。[设备](../hub/devices.md)页的设备抽屉里有 **终端**（Terminal）按钮，它打开本页并选好那台机器。

## 离开后保留会话

shell 下方的 **持久** 开关属于当前显示的标签。新标签的开关是关着的。标签连上之后，也就是 shell 上方的圆点显示 **已连接**（open）时，开关才能拨动。

- 开着 **持久**：关掉浏览器、刷新面板或退出登录，shell 都继续在机器上运行。
- 关着 **持久**：标签关闭，shell 随之结束。

会话由被控端自己持有。重启或升级被控端，所有会话都会结束。

## 回到保留的会话

面板加载时，**终端** 页给每台在线机器上的每个持久会话各开一个标签，按会话的创建顺序排列。桌面客户端或 Android 客户端里保留的会话也在其中。

这样回来的标签显示 **这个会话保留在机器上**（This session is kept on the machine），选中之后才连上。连上后先显示会话最近 256 KB 的输出。

## 结束会话

- **持久** 关着的标签：选择标签上的 ×，标签关闭，shell 结束。
- **持久** 开着的标签：× 要按两次。第一次只是预备，提示文字改为再按一次就在机器上结束；第二次才结束会话。
- 任何标签里运行 `exit`，shell 结束，标签关闭。

## 标签自己关闭

一个会话同一时间只有一个查看者。同一个会话在别的浏览器或客户端里打开时，这里的标签以 `session_taken` 关闭，shell 下方显示 **这个终端在别处打开了，所以这里关闭了。** 要把持久会话拿回来，刷新页面，再选中它的标签。

shell 下方显示 **这个会话已经关闭。那台机器可能不再应答了。** 时，标签和机器之间的连接断了。
