# 终端

在 **终端**（Terminals）页上，你能给被控端在线的任一台机器开一个 root shell。打开 **持久**（Persistent）开关的 shell，在你关掉浏览器之后仍留在那台机器上运行；打开 **共享**（Shared）开关的 shell，对那台机器有终端权限的每个客户端都能打开。

![终端页，两个 shell 标签，持久开关已打开](/guide/zh/terminals_persist.webp)

## 打开 shell

1. 在 **选择机器**（Which machine）里选一台机器。
1. 选择 **新终端**（New terminal）。

新标签以机器名命名，里面是 root shell；Windows 机器上是 PowerShell。按键直接送到机器上，Escape 也一样。切到面板的其他页面时，标签保持打开。[设备](../hub/devices.md)页的设备抽屉里有 **终端**（Terminal）按钮，它打开本页并选好那台机器。

## 保留或共享会话

shell 下方的两个开关 **持久**（Persistent）和 **共享**（Shared）属于当前显示的标签。新标签的两个开关都是关着的。标签连上之后，也就是 shell 上方的圆点显示 **已连接**（open）时，而且会话是本面板打开的，开关才能拨动。客户端打开的会话上，两个开关是灰的，旁边写着 **由**（Opened by）那个客户端的名字 **打开**。

- 开着 **持久**：关掉浏览器、刷新面板或退出登录，shell 都继续在机器上运行。
- 开着 **共享**：对那台机器有终端权限的每个客户端都列出这个会话，都能连上。共享的会话在最后一个标签关闭后也继续运行。
- 两个都关着：标签关闭，shell 随之结束。

会话由被控端自己持有。重启或升级被控端，所有会话都会结束。

## 回到会话

标签跟着在线机器上的会话走。面板加载时，本页给每个会话各开一个标签，按会话的创建顺序排列。第一个标签立刻连上，先显示会话最近 256 KB 的输出；其他标签在你选中时连上。之后在这里或在客户端里新开的会话，会作为新标签出现。

持久的会话，标签上标着 **保留**（kept）；共享的标着 **共享**（shared）；有两个窗口连着时标着 **2 处**（2 open）。

客户端打开而没有共享的会话也列出来，方便你结束它，但面板不连上它。它的标签上写着 **由** 那个客户端 **打开，没有共享**。

## 在几个窗口里看同一个会话

一个会话可以同时连上任意多个窗口，浏览器和客户端都算，和 tmux 一样。每个窗口显示同样的输出，任何一个窗口的按键都送进 shell，shell 的大小取最小的那个窗口的列数和行数。

## 结束会话

- 本面板的标签，两个开关都关着：选择标签上的 ×，标签关闭，shell 结束。
- 其他标签：× 要按两次。第一次只是预备，提示文字改为再按一次就在机器上结束；第二次才结束会话。
- 任何标签里运行 `exit`，shell 结束。

## 标签自己结束

会话在机器上结束时，不管是运行了 `exit` 还是从别的窗口结束的，标签都显示 **已结束**（Ended），并留着最后的输出。选择 × 关掉它。

shell 下方显示 **这个会话已经关闭。那台机器可能不再应答了。** 时，标签和机器之间的连接断了。
