# 终端

面板的 **终端** 页在受管机器上开 shell，那台机器的被控端要在线。

![终端页，server 上的两个 shell 标签，持久开关已打开](/guide/zh/terminals_persist.webp)

## 打开 shell

1. 在 **选择机器** 里选一台机器，比如 `server`。
1. 选择 **新终端**。

新标签以机器名命名。shell 以这台机器 **终端** 模块设的账户运行，没设账户时以 root 运行。Windows 上，shell 以 SYSTEM 运行，默认是 PowerShell。账户和 shell 程序的设法见[终端模块](./modules/terminal.md)。

按键直接送到机器上，Escape 也一样。[设备](../hub/devices.md)页抽屉里的 **终端** 按钮也打开本页，并选好那台机器。

## 保留或共享会话

shell 下方有 **持久** 和 **共享** 两个开关，作用于当前的标签。新标签的两个开关都关着。

会话是面板开的，而且标签连着机器，开关才能拨。别处开的会话，开关是灰的，旁边写着 **由 laptop 打开** 这样的一行。

- 开着 **持久**：关掉浏览器、刷新面板或退出登录，shell 都在机器上继续运行。
- 开着 **共享**：对这台机器有终端权限的客户端都能接上这个会话。
- 两个都关着：最后一个窗口断开时，shell 随之结束。

被控端重启或升级时，机器上的所有会话都结束。

## 回到会话

面板载入时，本页给在线机器上的每个会话各开一个标签。第一个标签立刻接上，先显示最近 256 KB 的输出。其他标签在你选中时接上。

| 标签上的标记 | 意思                   |
| ------------ | ---------------------- |
| **保留**     | 会话是持久的           |
| **共享**     | 会话是共享的           |
| **2 处**     | 有两个窗口接着这个会话 |

面板能接上任何会话。客户端只能接上自己开的和共享的会话。

一个会话能同时接上任意多个窗口，浏览器和客户端都算。每个窗口显示同样的输出，任一窗口的按键都送进 shell。shell 的大小取最小的那个窗口。

## 结束会话

- 面板开的标签，两个开关都关着：选 ×，标签关闭，shell 结束。
- 其他标签：× 要按两次，第二次才在机器上结束会话。
- 任何标签：在 shell 里运行 `exit`。

会话在机器上结束时，标签显示 **已结束**，留着最后的输出。连接断开时，shell 下方显示 **这个会话已经关闭。**，中枢给了原因时换成原因。各个原因见[故障排查](../reference/troubleshooting.md#终端关闭)。
