# nagent 命令

`nagent` 是被控端的命令行入口，装在每台运行被控端的 Linux 机器上。每个子命令都要 root，不以 root 运行时它打印原因和带 `sudo` 的命令并返回 2；`--version` 除外。没有子命令时打印帮助并返回 2。

| 子命令           | 参数                                                                                    | 作用                                                                               |
| ---------------- | --------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------- |
| `connect [link]` | `link` 是 hub 发的 `neutrino://enroll` 链接，省略则提示粘贴；`--yes` 直接替换已有的绑定 | 加入链接指向的 hub：写入绑定并启动服务                                             |
| `disconnect`     | 无                                                                                      | 离开 hub：删除绑定                                                                 |
| `status`         | 无                                                                                      | 经 root 专用的控制套接字向被控端服务读取这台机器绑定的 hub                         |
| `sync`           | 无                                                                                      | 让被控端立刻向 hub 取期望状态，即 hub 记录的这台机器该启用哪些模块、该有什么配置   |
| `run`            | 无                                                                                      | 在前台运行被控端                                                                   |
| `rdp start`      | `--user USER` 指定共享谁的桌面；省略则是执行 sudo 的账户，没有则是屏幕前唯一登录的账户  | 用 hub 设定的坐席密码共享这台机器的桌面，打印 RustDesk ID                          |
| `rdp stop`       | 无                                                                                      | 停止共享；机器本来就没在共享时打印 `this machine's desktop is not shared` 并返回 0 |

顶层参数：`--version` 打印包版本并退出；`-h` 在每一级打印帮助。`rdp` 不带动作时打印 `rdp` 的帮助并返回 2。
