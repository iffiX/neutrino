# 文件

用 **文件**（Files）页，你以 root 身份浏览一台被控端机器的整个文件系统，并在它和你自己的电脑之间传文件。

![手机宽度下的文件页，每行两行显示，一行的菜单已展开](/guide/zh/files_row_menu.webp)

## 浏览一台机器

1. 在 **选择机器**（Which machine）里选一台被控端在线的机器。
1. 选择文件夹的名字，进入这个文件夹。

列表上方的路径由一串按钮组成，选其中任一段就回到那一层。浏览从 `/` 开始，也就是机器的根目录。

Windows 机器上，浏览从 **驱动器**（Drives）开始，每个盘一行，例如 `C:`。选一个盘就进入它的根目录。路径里的文件夹之间用 `\` 分隔，和 Windows 自己的写法一样。在 **驱动器** 这一层，**新建文件夹** 和 **上传** 是灰的，各行也没有按钮。

刷新面板之前，本页记住你选的机器和打开的文件夹。[设备](../hub/devices.md)页的设备抽屉里有 **文件**（Files）按钮，它打开本页并选好那台机器。

## 传文件

- 上传：先进入目标文件夹，选择 **上传**（Upload），再选一个或多个文件。列表上方逐个显示上传进度。
- 下载文件：选择这一行的下载按钮。
- 下载文件夹：选择这一行的 **打包成 tar.gz 下载**（Download as tar.gz）。文件名以点开头的文件也打包成 tar.gz，因为浏览器直接下载时会去掉开头的点。

符号链接这一行没有下载按钮；选中它，进入它指向的文件夹。

## 改名、删除和新建文件夹

- **新建文件夹**（New folder）在列表里加一行输入框。填好名字，按 Enter 或选 **创建**（Create）。
- **重命名**（Rename）把这一行的名字变成输入框。填新名字后按 Enter；按 Escape 保留原名。
- **删除**（Delete）要按两次。第一次按下后，按钮变成对勾，列表底部提示删除无法撤销；第二次按下才删除。

## 在手机上

宽度小于 720 像素时，每个条目占两行：第一行是名字，第二行是大小和时间。

在触屏上、宽度小于 880 像素的窗口里，或者高度大于宽度的窗口里，一行的按钮收进 **⋯**（**更多操作**，More actions）。菜单里有 **下载**（文件夹是 **打包成 tar.gz 下载**）、**重命名** 和 **删除**。第一次按 **删除** 后，它变成 **再点一次即删除**（Click again to delete），菜单保持打开，再按一次同一项就删除。

## 机器离线时

被控端离线时，中枢拒绝每个请求并返回 `agent_offline`。页面显示 **这台机器没有应答，没有读取也没有写入任何内容。**
