# 选哪种外部访问

从家外面连回中枢，走的是外部访问。它是客户端和被控端在外面连回中枢 8443 端口的那条路，中枢本身留在家里的局域网里。这一页对照每种办法要准备什么，读完你就知道自己的网络该开哪一种，接着读哪一页。

## 一个端口走全部功能

客户端用到的七类功能都经过中枢的 8443 端口：网页、端口、AI 网关、文件、终端、远程桌面和面板。客户端的每条连接都到中枢为止，再由中枢转给提供服务的那台机器。所以这些功能只要求客户端连得上 8443。

外部访问因此只回答一个问题：客户端在外面怎样到达 8443。几种办法可以同时开着，客户端用其中连得通的一条。

## 每种办法要什么

| 办法                                              | 要准备什么                                                                                                                                                | 每个客户端要多做一步吗                         | 哪个版本有     |
| ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------- | -------------- |
| **直连**（Direct）                                | 客户端能连到中枢的某个网口。在家外面用，家里要有公网 IPv4，路由器把一个端口转发到中枢的 8443，再在 **公网地址**（Public address）里填家里的公网 IP 或域名 | 不用                                           | 完整版和国内版 |
| **SSH 中继**（SSH Relay）                         | 一台有公网地址、运行 OpenSSH 的服务器，你能以 root 身份改它的 SSH 配置。开之前先读服务商关于流量转发的条款                                                | 不用                                           | 完整版和国内版 |
| NetBird                                           | 一个 netbird.io 账号或自建的管理面，加一把可重复使用的 setup key                                                                                          | 不用，中枢把 key 发给每个客户端                | 只有完整版     |
| **EasyTier 控制台**（EasyTier console）           | 一个 EasyTier 控制台账号，控制台有免费档                                                                                                                  | 要：每个客户端第一次连上后，在控制台里挂载一次 | 完整版和国内版 |
| EasyTier **手动碰头点**（Manual bootstrap peers） | 不用账号。客户端连的碰头点是中枢上行口的地址加 11010 端口，在家外面用时，这个地址要从外面连得到                                                           | 不用                                           | 完整版和国内版 |

每种办法的设置步骤见[外部访问](../hub/overlay.md)。

## 什么时候才要子网路由

NetBird 和 EasyTier 都是虚拟网，即架在公网上的私网。子网路由只为局域网里没装被控端的设备而设，例如打印机、路由器的管理页、NAS 自带的管理页。客户端打开这类设备时，用的是设备自己的局域网地址，不经过中枢的 8443。

这条路由由你设置。NetBird 和 EasyTier 控制台模式在虚拟网自己的控制台里设，EasyTier 手动碰头点模式在面板的 **导出的局域网**（Exported networks）里设。完整版两种虚拟网都能用，国内版只有 EasyTier。

用 NetBird 时，读[经 NetBird 访问没装被控端的局域网设备](./netbird_lan_routes.md)。

用 EasyTier 时，读[经 EasyTier 访问没装被控端的局域网设备](./easytier_lan_routes.md)。
