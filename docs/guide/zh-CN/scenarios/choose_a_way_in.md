# 选哪种外部访问

人在家外面时，客户端经外部访问连回中枢。客户端只连中枢的 8443，所以选外部访问，就是选在外面怎样到达这个端口。这一页对照四种办法各要准备什么、适合谁。

![外部访问页上的四张卡片](/guide/zh/overlay_switches.webp)

## 四种办法对照

| 办法         | 要准备什么                                                                                     | 适合谁                         | 设置步骤                                         |
| ------------ | ---------------------------------------------------------------------------------------------- | ------------------------------ | ------------------------------------------------ |
| **直连**     | 家里有公网 IPv4，路由器把一个端口转发到中枢的 8443                                             | 宽带有公网地址的人             | [外部访问](../hub/overlay.md)                    |
| **SSH 中继** | 一台有公网地址、运行 OpenSSH 的服务器，你能以 root 改它的 SSH 配置                             | 手上有一台 VPS 的人            | [用自己的 VPS 中继连回家](./vps_relay.md)        |
| **NetBird**  | 一个 netbird.io 账号或自建的管理面；国内版没有                                                 | 用完整版、不想自己管服务器的人 | [把中枢加入 NetBird](../hub/netbird.md)          |
| **EasyTier** | 一个 EasyTier 控制台账号，每个客户端第一次连上后在控制台里挂一次；或者不用账号，改用手动碰头点 | 用国内版的人                   | [把中枢放到 EasyTier 网络里](../hub/easytier.md) |

用手动碰头点时，碰头点是中枢上行口的地址加 11010 端口，这个地址要从外面连得到。

SSH 中继的流量全走你的 VPS。EasyTier 控制台模式下，设备之间直接连不通时，流量经 EasyTier 的服务器中转，按控制台的档位计流量。

## 同时开几种

几种办法可以同时开着，客户端用其中连得通的一条。几条都通时，客户端先用局域网和直连，其次 NetBird 和 EasyTier，最后才用 SSH 中继。客户端中枢一行的状态写着正在走的那条，例如 **已连接 · SSH 中继**。想让手机改走 SSH 中继，在客户端的 **虚拟网** 一行选 **断开**，或者在面板的 **外部访问** 页关掉 EasyTier。

## 什么时候才要子网路由

子网路由只为局域网里没装被控端的设备而设，例如打印机、NAS 自带的管理页。客户端打开这类设备时，用的是设备自己的局域网地址。装了被控端的机器用不到子网路由。子网路由要求中枢是路由器或旁路网关模式。

用 NetBird 时，读[经 NetBird 访问没装被控端的设备](./netbird_lan_routes.md)。

用 EasyTier 时，读[经 EasyTier 访问没装被控端的设备](./easytier_lan_routes.md)。
