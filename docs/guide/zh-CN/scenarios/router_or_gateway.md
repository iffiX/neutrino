# 把中枢配置成路由器或旁路网关

一台装好的 Linux 中枢能从服务器形态换成路由器或旁路网关，给家里的设备转发流量。下面从什么时候要换讲起，再设网口、DHCP 和开放范围。只有 Linux 上的中枢有这两种形态。旁路网关只在完整版里有，国内版没有。

## 什么时候要这么做

- 要用[代理](../hub/proxy.md)给家里的设备分流。设备的流量先经过中枢，代理才分得到。代理只在完整版里有。
- 这台机器本来就做家里的路由器，或者你想让它做。

只在手机和笔记本上用电脑里的服务时，服务器形态就够了，不用换。

| 形态         | 机器上的地址 | 设备怎么用上它                             |
| ------------ | ------------ | ------------------------------------------ |
| **路由器**   | 由中枢接管   | 接在中枢的 LAN 口上，从中枢拿地址          |
| **旁路网关** | 保持原样     | 留在家里原来的网络上，把网关改成中枢的地址 |

## 换之前要知道的

面板的应用栏在应用之前写出这次切换的代价：

- 进入路由器形态，中枢接管网口。上行口用 DHCP 时可能换到新地址，面板要在新地址上重新打开。
- 离开路由器形态，网口交还给机器自己的网络管理器。中枢服务的网络随之结束，上面的设备失去地址、DNS 和网关。
- 离开旁路网关，把中枢设为网关的设备失去出网的路。

在中枢这台机器自己的屏幕前操作最稳。在这台机器上运行 `nhub open`，面板在本机的浏览器里打开，经回环地址连接，换网口不影响它。

从家里另一台设备操作时，连接会断。在中枢机器上运行 `sudo nhub open --print`，打印面板的新地址，到那里重新登录。

## 选形态

新装中枢时，在向导的 **这台机器做什么？** 一屏选 **路由器**、**单臂路由** 或 **旁路网关**，下一屏 **用哪些网口？** 填这个形态要的网口和地址。

![向导的形态屏](/guide/zh/setup_shape.webp)

已经装好的中枢，在面板里换：

1. 在 **网络** 页的 **模式** 一节，选 **路由器** 或 **旁路网关**。
1. 选择 **应用模式**。

![网络页的模式一节](/guide/zh/network_modes.webp)

换成旁路网关时，在 **上游网关** 里填家里原来那台路由器的地址，再选择 **应用上游网关**。

换回服务器形态，也在 **模式** 一节，代价见上一节。

## 给网口定角色

路由器形态下，每个网口有一个 **角色**：

| 角色     | 含义                 |
| -------- | -------------------- |
| **WAN**  | 通往互联网的上行线路 |
| **LAN**  | 中枢自己服务的网络   |
| **拆分** | 切成多个 VLAN 的主干 |
| **停用** | 交给系统自己管理     |

从服务器形态换过来时，每个网口的角色都是 **停用**，开放着的网口要先选角色：

1. 在 **网络** 页的 **开放范围** 一节，找到每个开放的网口那一行。
1. 在这一行的角色选择里，接上行线路的网口选 **WAN**，接家里设备的网口选 **LAN**。
1. 选择 **应用开放范围**。

之后在网口标签里改细节。WAN 口选 **DHCP** 或 **静态**；LAN 口填 **网关地址** 和 **前缀长度**，第一个服务网络默认是 `192.168.8.0/24`，中枢在 `192.168.8.1`。改完选择 **应用到** 加网口名的按钮。

![路由器形态下的网口角色，一个 WAN，一个 LAN](/guide/zh/network_roles.webp)

单臂路由只用一根网线：主干网口的角色是 **拆分**，不打标签的流量出网，设备在一个 VLAN 上。主干接的交换机要透传 VLAN 标签。

## DHCP

路由器形态下，LAN 网口的 **DHCP** 一栏给设备发地址：

| 项                         | 默认           |
| -------------------------- | -------------- |
| **在这个网络上分配地址**   | 打开           |
| **起始地址**、**结束地址** | `.100`～`.200` |
| **租约时长**               | `12h`          |

设备拿到的网关和 DNS，都是中枢在这个网络上的地址。给某台设备固定地址，见[网络](../hub/network.md)页的静态地址分配。

旁路网关形态下，中枢不发地址，家里原来的路由器照旧发。在每台要经过中枢的设备上，把网关和 DNS 改成中枢的地址。没改的设备照旧走原来的路由器。

## 开放范围

**开放范围** 列出中枢接受连接的网络，连接的对象是中枢自己的服务：面板、SSH、DNS、共享。路由器形态下，LAN 网口默认开放。向导建的路由器，WAN 网口默认关着。

1. 在 **开放范围** 里勾选中枢要应答的网络。
1. 选择 **应用开放范围**。

![开放范围一节](/guide/zh/network_exposure.webp)

开放一条 WAN 线路，中枢在它监听的每个端口上接受来自互联网的连接。从服务器形态换过来的 WAN 口仍然开放，取消勾选它，再选择 **应用开放范围**。<!-- 待核: 从服务器形态经面板换成路由器后，在开放范围里选了 WAN 的网口保持开放，取消勾选后角色仍是 WAN；没有在真机上走过 -->

从家外面连回中枢，用[外部访问](./choose_a_way_in.md)，不用开放 WAN。中枢拒绝网络设置时，见[故障排查](../reference/troubleshooting.md#中枢拒绝网络设置)。
