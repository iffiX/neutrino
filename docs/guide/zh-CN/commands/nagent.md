# nagent 命令

受管机器上的被控端用 `nagent` 在命令行里控制，机器可以是 Linux、Windows 或 macOS。下表的子命令顺序与 `nagent --help` 的输出一致。

## 权限

在 Linux 和 macOS 上，每个子命令都要以 root 运行；在 Windows 上，要在以管理员身份打开的终端里运行。权限不够时，子命令打印原因和应该运行的那一行，返回 2。只有 `nagent --version` 任何账户都能运行。

## 子命令

**先确认** 一列标出动手前先问一次 `[y/N]` 的子命令：加 `--yes` 就不再问；回答 no 时打印 `nothing changed`，返回 1。标准输入不是终端又没加 `--yes` 时不提问，在 stderr 打印一行提示加 `--yes`，按回答 no 处理。

| 子命令                     | 参数                                                                                                 | 先确认             | 作用                                                                                                                                                                                                                                                                                                                   |
| -------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nagent join <link>`       | `<link>` 是中枢 **设备**（Devices）页给出的 `neutrino://enroll/` 链接；省略时在提示符下读入。`--yes` | 机器已有绑定时才问 | 加入链接指向的中枢，写入绑定；被控端服务没在运行时启动它。                                                                                                                                                                                                                                                             |
| `nagent leave`             | `--yes`                                                                                              | 是                 | 离开中枢，删除绑定。服务照常运行，以后可以用新链接再加入。机器没有绑定时不提问，返回 1。                                                                                                                                                                                                                               |
| `nagent status`            |                                                                                                      | 否                 | 打印版本、绑定的中枢、上次连上的地址、服务状态，以及中枢有没有应答。机器有绑定且中枢应答时返回 0，否则返回 1。                                                                                                                                                                                                         |
| `nagent sync`              |                                                                                                      | 否                 | 立即把这台机器的汇报发给中枢；两边的哈希不同时，中枢推送状态。服务没在运行时返回 1。                                                                                                                                                                                                                                   |
| `nagent start`             | `--yes`                                                                                              | 是                 | 通过 systemd、Windows 服务控制管理器或 launchd 启动被控端服务，打印它的状态。绑定不变。                                                                                                                                                                                                                                |
| `nagent stop`              | `--yes`                                                                                              | 是                 | 停下被控端服务。下次开机它重新启动，绑定保留；服务再次运行之前，中枢显示这台机器离线。                                                                                                                                                                                                                                 |
| `nagent run`               |                                                                                                      | 否                 | 在前台运行被控端。systemd 单元和 macOS 的 LaunchDaemon 运行的就是它；控制服务用 `start` 和 `stop`。                                                                                                                                                                                                                    |
| `nagent service run`       |                                                                                                      | 否                 | 作为 Windows 服务运行被控端。Windows 服务控制管理器运行的就是它；从终端启动时返回 1。                                                                                                                                                                                                                                  |
| `nagent service uninstall` | `--yes`                                                                                              | 是                 | 停止被控端，并删除它的模块添加的东西：systemd 单元、launchd 任务、计划任务、防火墙规则，以及文件共享的防护规则。共享、账户和模块的数据保留。在 Linux 和 Windows 上，卸载被控端的软件包时会运行它。在 macOS 上它还会删除被控端本身、RustDesk 和软件包的安装记录，并保留绑定和状态，所以之后再安装时会重新找到这些共享。 |

## 全局参数

| 参数        | 位置     | 作用                     |
| ----------- | -------- | ------------------------ |
| `--version` | `nagent` | 打印包版本后退出。       |
| `-h`        | 每一级   | 打印这一级的帮助后退出。 |

`nagent` 不带子命令，或 `nagent service` 不带动作时，打印帮助，返回 2。
