# nagent 命令

被控端的命令行叫 `nagent`，装在中枢管理的每台 Linux、Windows 和 macOS 机器上。子命令按 `nagent --help` 的顺序排列。

## 权限

Linux 和 macOS 上，子命令要以 root 运行；Windows 上，要在管理员终端里运行。权限不够时，打印原因和要运行的那一行，返回 2。`nagent --version` 和 `nagent answer` 任何账户都能运行。

## 子命令

**先确认** 一列是动手前问一次 `[y/N]` 的子命令：`--yes` 跳过提示；回答 no 时打印 `nothing changed`，返回 1；标准输入不是终端又没加 `--yes` 时，打印一行说明，按 no 处理。

| 子命令                     | 参数                                                                | 先确认     | 作用                                                                                                          |
| -------------------------- | ------------------------------------------------------------------- | ---------- | ------------------------------------------------------------------------------------------------------------- |
| `nagent join <link>`       | `<link>` 是 **设备** 页给出的链接，省略时在提示符下粘贴；`--yes`    | 已有绑定时 | 加入链接指向的中枢，新绑定替换旧的；服务没在运行时启动它。                                                    |
| `nagent leave`             | `--yes`                                                             | 是         | 离开中枢，删除绑定，服务照常运行。没有绑定时返回 1。                                                          |
| `nagent status`            |                                                                     | 否         | 打印版本、绑定的中枢、上次连上的地址、服务状态和中枢有没有应答。有绑定且中枢应答时返回 0。                    |
| `nagent sync`              |                                                                     | 否         | 马上把汇报发给中枢；哈希不同时，中枢推送状态。服务没在运行时返回 1。                                          |
| `nagent start`             | `--yes`                                                             | 是         | 经 systemd、Windows 服务管理器或 launchd 启动被控端服务，打印它的状态。                                       |
| `nagent stop`              | `--yes`                                                             | 是         | 停下被控端服务，绑定保留，下次开机它重新启动。                                                                |
| `nagent run`               |                                                                     | 否         | 在前台运行被控端，是 systemd 单元和 macOS LaunchDaemon 的入口。                                               |
| `nagent service run`       |                                                                     | 否         | Windows 服务管理器启动被控端的入口；从终端运行返回 1。                                                        |
| `nagent service uninstall` | `--yes`                                                             | 是         | 停止被控端，删掉它的模块加的单元、任务和防火墙规则；共享、账户和模块数据留下。用法见[卸载](../uninstall.md)。 |
| `nagent answer`            | `--prompt <text>` 是问题；`--answer <keys>` 是回答；`--` 后面是程序 | 否         | 在单独的终端里运行程序，看到问题就输入回答，返回程序的退出码。被控端在 Windows 上自己运行它。                 |
| `nagent step-down`         | `--uid <uid>`、`--gid <gid>`；`--` 后面是程序的完整路径和参数       | 否         | 降到那个账户，再以它运行程序；只有 root 能降权。被控端在 macOS 上自己运行它。失败时返回 126。                 |

## 全局参数

| 参数        | 位置     | 作用                     |
| ----------- | -------- | ------------------------ |
| `--version` | `nagent` | 打印包版本后退出。       |
| `-h`        | 每一级   | 打印这一级的帮助后退出。 |

`nagent` 不带子命令、`nagent service` 不带动作、`answer` 或 `step-down` 的 `--` 后面没有程序时，返回 2。
