# nagent 命令

`nagent` 是被控端的命令行，装在中枢管理的每台 Linux、Windows 和 macOS 机器上。下表的子命令按 `nagent --help` 列出的顺序排列。

## 权限

在 Linux 和 macOS 上，子命令要以 root 运行；在 Windows 上，要在以管理员身份打开的终端里运行。权限不够时，子命令打印原因和要运行的那一行，返回 2。`nagent --version` 和 `nagent answer` 任何账户都能运行。`nagent step-down` 只有 root 能降权，别的账户运行时由系统拒绝。

## 子命令

**先确认** 一列标出动手前问一次 `[y/N]` 的子命令：加 `--yes` 不问；回答 no 时打印 `nothing changed`，返回 1。标准输入不是终端又没加 `--yes` 时，子命令不提问，在 stderr 打印一行提示加 `--yes`，按回答 no 处理。

| 子命令                     | 参数                                                                                                 | 先确认             | 作用                                                                                                                                                                                                                                                |
| -------------------------- | ---------------------------------------------------------------------------------------------------- | ------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nagent join <link>`       | `<link>` 是中枢 **设备**（Devices）页给出的 `neutrino://enroll/` 链接，省略时在提示符下粘贴；`--yes` | 机器已有绑定时才问 | 加入链接指向的中枢，写入绑定，已有的绑定由新的替换；被控端服务没在运行时启动它。                                                                                                                                                                    |
| `nagent leave`             | `--yes`                                                                                              | 是                 | 离开中枢，删除绑定。服务照常运行，之后能用新链接再加入。机器没有绑定时不提问，返回 1。                                                                                                                                                              |
| `nagent status`            |                                                                                                      | 否                 | 打印版本、绑定的中枢、上次连上的地址、服务状态，以及中枢有没有应答。有绑定且中枢应答时返回 0，否则返回 1。                                                                                                                                          |
| `nagent sync`              |                                                                                                      | 否                 | 马上把这台机器的汇报发给中枢；两边的哈希不同时，中枢推送状态。服务没在运行时返回 1。                                                                                                                                                                |
| `nagent start`             | `--yes`                                                                                              | 是                 | 经 systemd、Windows 服务管理器或 launchd 启动被控端服务，打印它的状态。绑定不变。                                                                                                                                                                   |
| `nagent stop`              | `--yes`                                                                                              | 是                 | 停下被控端服务。下次开机它重新启动，绑定保留；服务再次运行之前，中枢显示这台机器离线。                                                                                                                                                              |
| `nagent run`               |                                                                                                      | 否                 | 在前台运行被控端，是 systemd 单元和 macOS LaunchDaemon 启动的入口。                                                                                                                                                                                 |
| `nagent service run`       |                                                                                                      | 否                 | 作为 Windows 服务运行被控端，是 Windows 服务管理器启动的入口；从终端运行时返回 1。                                                                                                                                                                  |
| `nagent service uninstall` | `--yes`                                                                                              | 是                 | 停止被控端，删掉它的模块加上的 systemd 单元、launchd 任务、计划任务、防火墙规则和文件共享的防护规则；共享、账户和模块的数据保留。Linux 和 Windows 上卸载被控端的包时会运行它。macOS 上它还删掉被控端本身、RustDesk 和包的安装记录，绑定和状态留着。 |
| `nagent answer`            | `--prompt <text>` 是问题的文字；`--answer <keys>` 是回车前要输入的内容；`--` 后面是程序和它的参数    | 否                 | 在一个单独的终端里运行程序，看到问题就输入回答，打印程序画出的内容，返回程序的退出码。被控端在 Windows 上以某个账户切回 AI 工具时自己运行它，人不需要运行。                                                                                         |
| `nagent step-down`         | `--uid <uid>`、`--gid <gid>` 是账户的用户和组；`--` 后面是程序的完整路径和参数                       | 否                 | 降到那个账户，再以它运行一个程序。被控端在 macOS 上经 `launchctl asuser` 运行它，人不需要运行。降权或启动失败时返回 126。                                                                                                                           |

## 全局参数

| 参数        | 位置     | 作用                     |
| ----------- | -------- | ------------------------ |
| `--version` | `nagent` | 打印包版本后退出。       |
| `-h`        | 每一级   | 打印这一级的帮助后退出。 |

`nagent` 不带子命令、`nagent service` 不带动作、`answer` 或 `step-down` 的 `--` 后面没有程序时，返回 2。
