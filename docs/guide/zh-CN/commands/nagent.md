# nagent 命令

受管机器上的被控端用 `nagent` 在命令行里控制，机器可以是 Linux、Windows 或 macOS。下表的子命令顺序与 `nagent --help` 的输出一致。

## 权限

在 Linux 和 macOS 上，每个子命令都要以 root 运行；在 Windows 上，要在以管理员身份打开的终端里运行。权限不够时，子命令打印原因和应该运行的那一行，返回 2。只有 `nagent --version` 任何账户都能运行。

## 子命令

**先确认** 一列标出动手前先问一次 `[y/N]` 的子命令：加 `--yes` 就不再问；回答 no 时打印 `nothing changed`，返回 1。标准输入不是终端又没加 `--yes` 时不提问，在 stderr 打印一行提示加 `--yes`，按回答 no 处理。

| 子命令               | 参数                                                                                                  | 先确认             | 作用                                                                                                             |
| -------------------- | ----------------------------------------------------------------------------------------------------- | ------------------ | ---------------------------------------------------------------------------------------------------------------- |
| `nagent join <link>` | `<link>` 是 hub **设备**（Devices）页给出的 `neutrino://enroll/` 链接；省略时在提示符下读入。`--yes`  | 机器已有绑定时才问 | 加入链接指向的 hub，写入绑定；被控端服务没在运行时启动它。                                                       |
| `nagent leave`       |                                                                                                       | 否                 | 离开 hub，删除绑定。服务照常运行，以后可以用新链接再加入。机器没有绑定时返回 1。                                 |
| `nagent status`      |                                                                                                       | 否                 | 打印版本、绑定的 hub、上次连上的地址、服务状态，以及 hub 有没有应答。机器有绑定且 hub 应答时返回 0，否则返回 1。 |
| `nagent sync`        |                                                                                                       | 否                 | 立即把这台机器的汇报发给 hub；两边的哈希不同时，hub 推送状态。服务没在运行时返回 1。                             |
| `nagent start`       | `--yes`                                                                                               | 是                 | 通过 systemd、Windows 服务控制管理器或 launchd 启动被控端服务，打印它的状态。绑定不变。                          |
| `nagent stop`        | `--yes`                                                                                               | 是                 | 停下被控端服务。下次开机它重新启动，绑定保留；服务再次运行之前，hub 显示这台机器离线。                           |
| `nagent run`         |                                                                                                       | 否                 | 在前台运行被控端。systemd 单元和 macOS 的 LaunchDaemon 运行的就是它；控制服务用 `start` 和 `stop`。              |
| `nagent service run` |                                                                                                       | 否                 | 作为 Windows 服务运行被控端。Windows 服务控制管理器运行的就是它；从终端启动时返回 1。                            |
| `nagent rdp start`   | `--user <account>` 指定共享哪个账户的桌面；省略时共享调用 `sudo` 的账户，否则共享屏幕前唯一登录的账户 | 否                 | 以 hub 设定的座位密码共享这台机器的桌面。找不到可共享的账户时，打印带 `--user` 的写法，返回 2。                  |
| `nagent rdp stop`    |                                                                                                       | 否                 | 停止共享桌面。机器本来就没在共享时，打印这一点，返回 0。                                                         |

## 全局参数

| 参数        | 位置     | 作用                     |
| ----------- | -------- | ------------------------ |
| `--version` | `nagent` | 打印包版本后退出。       |
| `-h`        | 每一级   | 打印这一级的帮助后退出。 |

`nagent` 不带子命令，或 `nagent rdp`、`nagent service` 不带动作时，打印帮助，返回 2。
