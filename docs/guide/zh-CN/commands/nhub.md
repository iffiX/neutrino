# nhub 命令

`nhub` 是中枢的命令行，随中枢的安装包装上，Linux、macOS 和 Windows 上同名。下表的子命令按 `nhub --help` 列出的顺序排列。

## 子命令

**root** 一列标出要以 root 运行的子命令，Windows 上对应以管理员身份打开的终端；权限不够时，子命令打印要运行的那一行，返回 2。**先确认** 一列标出动手前显示一次 `[y/N]` 确认提示的子命令：加 `--yes` 不显示提示；回答 no 时什么都不改，返回 1。标准输入不是终端又没加 `--yes` 时，子命令不显示提示，在 stderr 打印一行，说明要加 `--yes`，返回 1。

| 子命令              | 参数                                                                                                                                                                           | root | 先确认 | 作用                                                                                                                                                                                                                 |
| ------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---- | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `nhub setup`        | `--stdin` 从标准输入读一个 JSON 对象作为全部回答；`--json <path>` 从文件读；两者互斥                                                                                           | 是   | 否     | 初始化这台机器，只做一次，用浏览器向导或终端里的问答。                                                                                                                                                               |
| `nhub run`          | `--host`、`--port`、`--reload`、`--interface`；`--only-web`、`--only-xray`、`--only-cliproxyapi`、`--only-dnsmasq`、`--only-supplicant`、`--only-dhcpcd`、`--only-router` 之一 | 否   | 否     | 在前台运行一个中枢进程。每个 `neutrino_hub_*` 单元运行的就是它。                                                                                                                                                     |
| `nhub open`         | `--print` 打印另一台机器要打开的地址，不打开浏览器；`--start-service` 和 `--output <path>` 是 `nhub open` 自己调用的提权步骤                                                   | 否   | 否     | 在浏览器里打开面板；机器还没初始化时打开向导。面板在本机回环上没有应答时，它经 UAC、`osascript` 或 `pkexec` 提权，启动中枢的服务。浏览器始终以当前账户打开。                                                         |
| `nhub start`        | `--interface`；`--yes`；`--only-router`、`--only-xray`、`--only-dnsmasq`、`--only-cliproxyapi`、`--only-relay`、`--only-web`、`--only-supplicant`、`--only-dhcpcd` 之一        | 是   | 是     | 启动中枢已启用的全部单元，路由状态在前，面板在后；或只启动指定的一个。已在运行的单元不动。`--only-supplicant` 和 `--only-dhcpcd` 要配 `--interface`。macOS 和 Windows 上启动中枢唯一的服务，带 `--only-*` 时返回 2。 |
| `nhub stop`         | `--interface`；`--yes`；`--only-web`、`--only-relay`、`--only-cliproxyapi`、`--only-dnsmasq`、`--only-xray`、`--only-router`、`--only-supplicant`、`--only-dhcpcd` 之一        | 是   | 是     | 停下中枢在这台机器上运行的服务，面板在前，路由状态在后，SSH 中继紧跟面板；或只停指定的一个。可选模块和虚拟网引擎照常运行，下次开机全部单元重新启动。macOS 和 Windows 上停下中枢唯一的服务，带 `--only-*` 时返回 2。  |
| `nhub status`       |                                                                                                                                                                                | 否   | 否     | Linux 上每个单元打印一行：装了没有、在不在运行、启用与否。macOS 和 Windows 上打印中枢服务的一行。面板在运行时返回 0，否则返回 1。                                                                                    |
| `nhub service run`  |                                                                                                                                                                                | 是   | 否     | 作为 Windows 服务运行中枢，是 Windows 服务管理器启动的入口。从终端运行时返回 1，在其他系统上返回 2。                                                                                                                 |
| `nhub apply`        | `--only <component>`，取 `router`、`xray`、`dnsmasq`、`cliproxyapi` 或 `overlay`，可重复；`--dry-run` 只打印渲染结果，不写文件也不改系统；`--skip-apply` 写文件但不重启服务    | 是   | 否     | 从 `config/` 渲染每份生成的配置，校验后应用，顺序与面板的收敛步骤相同。                                                                                                                                              |
| `nhub unlock`       |                                                                                                                                                                                | 是   | 否     | 解除面板的登录锁定和 fail2ban 的全部 SSH 封禁。                                                                                                                                                                      |
| `nhub reset`        | `all`、`network` 或 `password`；`--stdin` 从标准输入读新密码；`--yes`                                                                                                          | 是   | 是     | `password` 存入新的面板密码，登出所有会话。`network` 交还网络，不改 `config/`。`all` 交还网络，`config/` 回到示例，清掉密码和这台机器收集的密钥，再停下服务。不带目标时列出三项，返回 2。                            |
| `nhub update`       | `--yes`；`--package <file>` 装指定的包文件                                                                                                                                     | 是   | 是     | 装最新发行版本，由系统在 `nhub` 之外安装，装完后打印结果。安装之后做健康检查，新版本不应答时装回原版本。新版本通过检查后，重装这台机器自己的被控端。                                                                 |
| `nhub vault rekey`  | `--stdin` 从标准输入读新口令                                                                                                                                                   | 是   | 否     | 用新的主口令重新封存保险库的数据密钥。已加密的内容不重新加密。                                                                                                                                                       |
| `nhub scan-secrets` | `--staged`、`--history`、`--no-entropy`、`--no-vendor`、`--quiet`                                                                                                              | 否   | 否     | 检查工作区、暂存区或全部提交里有没有凭据，开发用。                                                                                                                                                                   |

`--only-relay` 指 SSH 中继。`xray` 相关的参数只在完整版里有，国内版的中枢没有代理。

## 全局参数

| 参数        | 位置                 | 作用                                                                     |
| ----------- | -------------------- | ------------------------------------------------------------------------ |
| `--version` | `nhub`               | 打印包版本后退出。                                                       |
| `--dev`     | `nhub`，写在子命令前 | 在工作副本的 `hub_dev_root/` 下运行，不查 root。包装好的中枢上报错退出。 |
| `-h`        | 每一级               | 打印这一级的帮助后退出。                                                 |

## 退出状态

| 退出状态 | 含义                                                                                                      |
| -------- | --------------------------------------------------------------------------------------------------------- |
| 0        | 子命令完成，或无事可做。                                                                                  |
| 1        | `[y/N]` 回答了 no，或某一步失败。                                                                         |
| 2        | 权限不够，打印了要运行的那一行；`nhub` 或 `nhub reset` 没带目标；子命令在这台机器或这种安装方式下做不了。 |
| 130      | 子命令运行中按了 Ctrl-C。                                                                                 |
