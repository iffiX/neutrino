# 概述

这一页讲微子在一台电脑上和在几台机器上各是什么样子，以及你在家外面怎么连回来。

## 一台电脑

最简单的用法只要一台常开的电脑。中枢和被控端都装在这台电脑上：中枢管连接和权限，被控端在这台电脑上装服务、开终端。你的手机和笔记本是客户端。

![你的电脑上装着中枢和被控端，手机和笔记本只连中枢的 8443 端口](/guide/overview_one_computer_zh.svg)

客户端只连中枢的 8443 这一个端口。在家里，它经局域网连过去；在外面，它经一种外部访问连过去。电脑上的终端、AI 会话、编辑器、远程桌面和文件，都经这个端口打开。

## 客户端怎么用到电脑上的服务

客户端在本机的回环地址上开一个端口。连到这个端口的连接经 8443 到达中枢。中枢按这条连接要的服务，把它交给提供服务那台机器的被控端。所以每个服务都走这一个端口，客户端只要知道中枢一个地址。

## 多台机器

家里别的机器也能加进来。每台装一个被控端，用面板生成的链接加入中枢。被控端主动连中枢的 8443，这台机器上开的服务会出现在客户端里。客户端仍然只连中枢，不需要通往每台机器的路由。

![家里的局域网里有中枢所在的电脑、一台服务器和一台台式机，在外面的手机经外部访问连到同一个 8443](/guide/overview_many_machines_zh.svg)

Linux 机器能运行全部模块，Windows 和 Mac 能运行其中大部分，每个系统的对照见[支持的平台](./reference/platforms.md)。给别的机器装被控端的步骤见[一台笔记本管所有机器](./scenarios/one_laptop_every_machine.md)。

## 从外面连回来

离开家以后，客户端经一种外部访问连回中枢，几种可以同时开着。

| 办法     | 要准备什么                                                   | 适合谁                       |
| -------- | ------------------------------------------------------------ | ---------------------------- |
| 直连     | 一个公网地址，家里路由器把 8443 转发到中枢；面板不在 8443 上 | 家里宽带有公网 IPv4 的人     |
| SSH 中继 | 一台有公网地址的 VPS                                         | 有自己的服务器、不想装虚拟网 |
| NetBird  | 一个 NetBird 账号；国内版没有 NetBird                        | 能访问 netbird.io 的人       |
| EasyTier | 一个 EasyTier 控制台账号，或自己填碰头点                     | 在国内、家里没有公网地址的人 |

各自的准备和适用情况，见[选哪种外部访问](./scenarios/choose_a_way_in.md)。

## 三个角色和中枢的几层

| 角色   | 装在哪                                           | 做什么                           |
| ------ | ------------------------------------------------ | -------------------------------- |
| 中枢   | 一台常开的电脑，Linux、macOS 或 Windows          | 发布服务，管连接和权限，提供面板 |
| 被控端 | 每台提供服务的 Linux、Windows 或 Mac             | 装模块，开终端，共享桌面         |
| 客户端 | 你自己的 Linux、Windows、Mac 电脑和 Android 手机 | 打开中枢发布的服务               |

中枢自己分成下面几层。

| 层       | 是什么                                                                                                                                 |
| -------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| 网络模式 | 这台电脑在网络里的角色。服务器模式不接管这台电脑的网络，三个系统都有，第一步用的就是它；路由器只在 Linux 上，旁路网关只在 Linux 完整版 |
| 外部访问 | 从家外面连回中枢的办法，见上一节                                                                                                       |
| 代理     | 按规则把流量交给出口节点，只在完整版                                                                                                   |
| AI 网关  | 一个入口，背后是你的 API 密钥和订阅账号，每个客户端有自己的密钥和用量                                                                  |

每种模式是什么、怎么切换，见[网络](./hub/network.md)。中枢以什么身份运行、密钥存在哪、8443 开出去后谁能连进来，见[安全](./security.md)。
