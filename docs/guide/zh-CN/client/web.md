# 网页

**网页**（Web）面板列出每个加入的 hub 提供的网址，**打开**（Open）在这台电脑的默认浏览器里打开它。

条目按 hub 排列，来自启用了 Gitea 模块的机器，以及 hub 服务页里手动声明的网址。地址下面一行写着 hub、机器和模块，例如 **由 Neutrino:Argon:Gitea 提供**；手动声明的网址在模块处写它自己的名字。面板空着时写 **没有提供网页服务**。

点 **打开**，地址在这台电脑的默认浏览器里打开。hub 那边访问不到的条目画成灰色，按钮不可用。终端里同一件事是 `nclient service web open <ref>`。`--hub` 取那个 hub 的名字，只加入了一个 hub 时可以省略；`<ref>` 是 `nclient service list` 里条目在那个 hub 下的编号，或者条目的 id。
