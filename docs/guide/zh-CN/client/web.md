# 网页

某个 hub 那一组里的 **网页**（Web）面板列出这个 hub 发布的网址，**打开**（Open）在这台电脑的默认浏览器里打开它。

条目来自启用了 Gitea 模块的机器，以及 hub 服务页里手动声明的网址；来源行分别写着由某台机器上的 Gitea 模块发布和手动声明。每个 hub 只往自己那一组里发布。每条显示名称和地址；面板空着时写 **没有发布网页服务**。

点 **打开**，地址在这台电脑的默认浏览器里打开。hub 那边访问不到的条目画成灰色，按钮不可用。终端里同一件事是 `nclient service web open <ref>`。`--hub` 取那个 hub 的名字，只加入了一个 hub 时可以省略；`<ref>` 是 `nclient service list` 里条目在那个 hub 下的编号，或者条目的 id。
