# nclient 命令

`nclient` 是客户端的命令行入口，以普通账户运行；以 root 运行时它返回 `root_refused` 并以 2 退出。没有子命令时打印帮助并返回 2。`service` 的每个动作里，`ref` 是 `service list` 输出里条目的编号，或者条目的 id。

| 子命令                    | 参数                                                                                                                                                                                                                                           | 作用                                                          |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------- |
| `connect [link]`          | `link` 是 hub 客户端页发的 `neutrino://enroll` 链接，省略则提示粘贴；`--yes` 直接替换已有的绑定                                                                                                                                                | 加入链接指向的 hub                                            |
| `disconnect`              | 无                                                                                                                                                                                                                                             | 离开 hub                                                      |
| `status`                  | 无                                                                                                                                                                                                                                             | 这个账户绑在哪个 hub                                          |
| `gui`                     | `--hidden` 只进托盘不显示窗口                                                                                                                                                                                                                  | 运行客户端和它的窗口                                          |
| `quit`                    | 无                                                                                                                                                                                                                                             | 停止正在运行的客户端；没有在运行时返回 `resident_not_running` |
| `service list`            | 无                                                                                                                                                                                                                                             | 按类型列出 hub 发布的每一条                                   |
| `service web open`        | `ref`                                                                                                                                                                                                                                          | 在浏览器里打开一条网页服务                                    |
| `service port forward`    | `ref`；`--local-port LOCAL_PORT` 指定本机端口                                                                                                                                                                                                  | 把一个端口转到本机回环地址                                    |
| `service port unforward`  | `ref`                                                                                                                                                                                                                                          | 关闭那条转发                                                  |
| `service file config`     | `ref`；`--path PATH` 必填；`--username USERNAME`                                                                                                                                                                                               | 保存一个共享的登录信息和路径，并挂载                          |
| `service file mount`      | `ref`                                                                                                                                                                                                                                          | 用保存的登录信息再次挂载                                      |
| `service file unmount`    | `ref`                                                                                                                                                                                                                                          | 卸载；保存的登录信息不动                                      |
| `service ai show`         | 无                                                                                                                                                                                                                                             | 这个账户的工具现在指向哪里                                    |
| `service ai apply`        | `hub` 或 `off`。模型参数有 `--claude-default`、`--claude-opus`、`--claude-sonnet`、`--claude-haiku`、`--codex-model` 和 `--gemini-model`；省略则保持现值，传 `''` 回到网关默认。`--codex-effort` 取 `minimal`、`low`、`medium`、`high` 或 `''` | `hub` 把工具指向网关，`off` 还原                              |
| `service desktop connect` | `ref`                                                                                                                                                                                                                                          | 在一个共享桌面上打开查看器                                    |

顶层参数：`--version` 打印包版本并退出；`-h` 在每一级打印帮助。`service` 不带类型，或类型不带动作时，打印那一级的帮助并返回 2。
