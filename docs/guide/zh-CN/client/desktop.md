# 桌面客户端

桌面客户端是一个窗口加一个托盘图标，装在你自己的 Linux、Windows 或 Mac 电脑上。用好本页之后，你在这个窗口里打开中枢发布的网页，转发端口，让 AI 工具走中枢的网关，挂上共享，开终端，看远程桌面。窗口的每一页都只连中枢的 8443 端口，由中枢接到服务所在的机器。

客户端怎么装、怎么加入中枢，见[安装客户端](../install/client.md)。本页的每个操作在终端里也做得到，命令见 [nclient 命令](../commands/nclient.md)。

## 中枢

窗口标题是 **微子·客户端**（Neutrino client）。左边侧栏从上到下是 **中枢**（Hubs）、**网页**（Web）、**端口**（Ports）、**AI**、**文件**（Files）、**终端**（Terminals）、**远程桌面**（Remote desktops），分隔线下面是 **设置**（Settings）。

右上角的 **↻**（Refresh）刷新每台中枢，中枢的新状态到达之前，每一行写 **刷新中…**（Refreshing…）。连着的中枢马上回一份完整的状态。正在连接或停着的中枢，客户端结束等待，关掉还没拨通的连接，马上重拨。写着 **已被替换**（Replaced by another client）或 **已停用**（Disabled by the hub）的行保持原样。

### 行的状态

**中枢** 页上一行是一台中枢：名字、状态、地址，以及它运行的软件包版本。名字下面的状态行写连接的情况：已连接、连接中，或停下来的原因。连上以后，圆点旁边有两个标签。第一个是通道走的路：

| 标签                               | 通道连的是                                 |
| ---------------------------------- | ------------------------------------------ |
| **已连接 · 局域网**（LAN）         | 中枢在本机所在网络里的地址                 |
| **已连接 · 直连**（Direct）        | 中枢在其他网络上开放的地址，或它的公网地址 |
| **已连接 · NetBird**               | 中枢在 NetBird 网络里的地址                |
| **已连接 · EasyTier**              | 中枢在 EasyTier 网络里的地址               |
| **已连接 · SSH 中继**（SSH Relay） | 一台服务器上的公网端口，服务器归中枢的主人 |

第二个标签是往返时间，例如 **12 ms**。客户端每 20 秒在通道上发一个 `ping` 帧，中枢回 `pong`，两者之间的时间就是这个数。通道换到新连接上时，客户端马上再量一次。

客户端连一台中枢时，同时拨它的全部地址。这些地址包括中枢在每个已连上的虚拟网里的地址、中枢的名字，以及中枢给出的地址列表。先用钉住的证书完成 TLS 的那条连接胜出，其余的马上关掉。

本机的网络一变，客户端马上再拨一轮。网口接上或断开、虚拟网连上、中枢的地址列表变了，都算网络变化；已连上的虚拟网里有节点上线或下线，也算。没连着的中枢，等待马上结束，还在拨的连接也马上关掉。

通道已连着时，新一轮胜出的路更好，通道才换过去。路从好到差依次是局域网、直连、两种虚拟网、SSH 中继；同一级时，握手更快的算更好。

通道没连着时，一轮拨号期间状态行写 **连接中…**（Connecting…）。其余时候写客户端停下来的原因，隔一个 `·` 再写怎样结束：

| 状态行                                                                   | 何时出现                                                            | 怎样结束                                             |
| ------------------------------------------------------------------------ | ------------------------------------------------------------------- | ---------------------------------------------------- |
| **中枢未响应 · 5 秒后重试**（The hub did not answer）                    | 这一轮的地址都没连上                                                | 倒计时到 0、网络变化，或按 **↻**                     |
| **中枢未上虚拟网 · 5 秒后重试**（The hub is not on the virtual network） | 本机已在中枢的虚拟网里，地址仍都没连上                              | 同上                                                 |
| **无网络**（No network）                                                 | 本机没有任何网络                                                    | 网口接上                                             |
| **证书不符 · 60 秒后重试**（Certificate mismatch）                       | `hub_untrusted`，地址上的证书不是链接钉住的那张                     | 中枢重装过的话，选 **离开**（Leave），再用新链接加入 |
| **中枢暂停接纳 · 60 秒后重试**（The hub pauses new devices）             | 第一次加入时中枢返回 `admission_paused`，秒数由中枢定               | 倒计时到 0，客户端再加入一次                         |
| **中枢不认识本机**（The hub does not know this device）                  | `binding_unknown`，中枢的 **客户端**（Clients）页上已没有这个客户端 | 选 **离开**（这一行只剩这个按钮），再用新链接加入    |
| **版本太旧**（Version too old）                                          | `protocol_too_old`，或中枢更旧时的 `protocol_too_new`               | 装新版客户端或升级中枢，再按 **↻**                   |
| **加入被拒 ·** 加原因（Join refused）                                    | 中枢拒收链接里的票据，例如 `ticket_spent`                           | 选 **离开**（这一行只剩这个按钮），再用新链接加入    |
| **已被替换 · 重新连接**                                                  | 另一个客户端顶替本机连上了这台中枢                                  | 选 **重新连接**（Reconnect）                         |
| **已停用**                                                               | 中枢停用了这个客户端                                                | 中枢重新启用它                                       |

倒计时每秒减一，到 0 时这一行变回 **连接中…**。两轮自动重拨之间的等待从 5 秒开始，每失败一轮翻一倍，最长 60 秒。连上一次，或网络变化一次，等待回到 5 秒。

名字前的圆点：

| 圆点       | 含义                                                                                       |
| ---------- | ------------------------------------------------------------------------------------------ |
| 绿色       | 通道开着                                                                                   |
| 黄色、闪动 | 这一行写着 **连接中…** 或 **刷新中…**，或这一行上有操作在进行                              |
| 黄色       | **中枢未响应**、**中枢未上虚拟网**、**无网络**、**中枢暂停接纳**、**已被替换**、**已停用** |
| 红色       | 要你动手才会好：**证书不符**、**中枢不认识本机**、**版本太旧**、**加入被拒**               |

![连着一台中枢的客户端窗口](/guide/zh/client_connected.webp)

### 行上的按钮

| 按钮                      | 何时出现                                                                                            | 作用                                                                  |
| ------------------------- | --------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **面板**（Panel）         | 中枢在 **客户端**（Clients）页给了这台电脑 **免密码进入中枢面板**（Hub panel without the password） | 在浏览器里打开中枢的面板，打开时已经登录                              |
| **重新连接**（Reconnect） | 状态行写着 **已被替换**                                                                             | 把这台中枢从另一个客户端那里要回来，重新连接                          |
| **离开**（Leave）         | 一直都在                                                                                            | 按一次变成 **再按一次离开**（Press again to leave），五秒内再按才离开 |

**面板** 先写 **打开中…**，再经本机的一个转发打开面板。这个转发一直开着，直到你离开这台中枢或退出客户端。中枢不允许时，例如返回 `permission_denied`，错误写在这一行上。

离开是立刻的，中枢有没有应答都一样。这台中枢在本机的东西随之撤掉：转发（含面板那一个）、挂载、查看器，以及别的中枢不用的虚拟网。

终端里，`nclient leave --yes` 不显示确认提示，直接离开；`nclient status --json` 以 JSON 打印每台中枢的状态。

### 虚拟网

中枢发布了 NetBird 或 EasyTier，而且允许这个客户端用虚拟网时，中枢那一行下面多一行 **虚拟网**（Virtual network）。其他情况下没有这一行。

| 这一行写着                                                               | 含义                       | 按钮                   |
| ------------------------------------------------------------------------ | -------------------------- | ---------------------- |
| **未连接**（Not connected）                                              | 本机不在这个网络里         | **连接**（Connect）    |
| **连接中…**（Connecting…），下面写 **正在登录**（Logging in to）加引擎名 | 引擎启动并登录，最长 90 秒 | **取消**（Cancel）     |
| **已连接 ·** 加本机在网络里的地址                                        | 引擎在运行，本机有了地址   | **断开**（Disconnect） |

EasyTier 用控制台模式时，登录之后这一行仍写 **连接中…**，原因行写着本机已登记到控制台，要在那里挂到一个网络上。这一行一直停在这里，直到控制台的主人把本机挂上，或你选 **取消**。控制台那边的操作见 [EasyTier](../hub/easytier.md)。

连接失败时，这一行回到 **未连接**，错误码写在下面，客户端不自动再试。上次退出时虚拟网连着的话，客户端启动时自动连一次。

中枢两种引擎都发布时，按钮旁边有一个选择框，用来选引擎。这一行写着 **未连接** 时才能换。

![中枢那一行上的虚拟网选择框](/guide/zh/client_network_picker.webp)

引擎的守护进程是系统服务，客户端退出后本机仍在网络里。

| 错误码                    | 含义                                                  |
| ------------------------- | ----------------------------------------------------- |
| `overlay_other_network`   | 本机已在另一个 NetBird 网络里，或连着别的中枢的控制台 |
| `overlay_daemon_down`     | 虚拟网的守护进程没在运行，重装客户端                  |
| `bundle_missing`          | 这份安装里没有 NetBird 或 EasyTier，重装客户端        |
| `overlay_join_failed`     | 引擎没让本机加入，码后面是引擎自己的原话              |
| `overlay_no_address`      | 90 秒内引擎没给本机分地址                             |
| `overlay_console_invalid` | 中枢给的 EasyTier 控制台地址，本机的 EasyTier 用不了  |
| `overlay_withdrawn`       | 中枢不再提供这个网络                                  |

### 一台电脑一个客户端

一台电脑同一时间只运行一个人的客户端。一个账户的客户端在运行时，另一个账户的 `nclient gui` 直接退出，不开窗口，不出托盘图标。这个账户的其他 `nclient` 命令打印 `client_held` 的说明，写出正在运行的那个账户，返回 1。那个账户的客户端退出以后，这台电脑就空出来了。

## 转发

转发是客户端为一个条目在 `127.0.0.1` 上开的端口。连到这个端口的每条连接，都经中枢接到服务上。转发开着的行，地址后面多出 `→ 127.0.0.1:` 和端口号。

| 条目                  | 转发开着的时段                       |
| --------------------- | ------------------------------------ |
| **网页** 上的条目     | 从 **打开** 到 **断开**              |
| **端口** 上的条目     | 从 **连接** 到 **断开**              |
| **AI** 上的网关       | 客户端开着，而且工具指向这台中枢     |
| **文件** 上的共享     | Linux 和 macOS 上，从挂载到卸载      |
| **远程桌面** 上的桌面 | 从 **连接** 到查看器关闭             |
| 中枢的面板            | 从第一次按 **面板** 到离开中枢或退出 |

转发开着时，本机的所有程序和所有账户都连得上它。退出客户端，所有转发都关闭。

### 本地端口

**网页** 和 **端口** 页上，行里的 **配置**（Configure）打开 **本地端口**（Local port）的选择：

- **自动**（Auto）：条目在远端用的端口号在本机空闲时用它，否则从 20000 往上找第一个空闲的。客户端记住这个号，以后每次转发都用它。
- **指定**（Fixed）：用你填的号，范围 1024～65535。同一协议的另一个条目已占着这个号时，对话框拒绝保存，原因写出那个号。

同一个号可以 TCP 用一次，UDP 再用一次。条目转发着时 **配置** 变灰，原因写 **先断开，才能改本地端口。**

每次开转发之前，客户端都重新查一遍端口。别的程序占着 **自动** 选的号时，客户端另找一个并记下。别的程序占着 **指定** 的号时，这一行写 `port_taken`，转发不开。

### 转发行上的错误码

| 错误码               | 含义                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------- |
| `connect_failed`     | 中枢或那台机器连不上服务，原因是 `refused`（端口上没有程序监听）、`timeout` 或 `unreachable` |
| `agent_offline`      | 提供这个条目的机器现在没连着中枢                                                             |
| `port_not_published` | 那台机器现在没发布这个端口，例如容器或实例停了                                               |
| `connect_limit`      | 这个客户端经中枢开着的连接到了 256 条，关掉几条再试                                          |
| `permission_denied`  | 中枢不允许这个客户端用这类条目，或不允许用那台机器                                           |
| `service_unknown`    | 中枢已不再发布这个条目                                                                       |
| `port_taken`         | 本机别的程序占着 **指定** 的本地端口，用 **配置** 换一个                                     |

## 网页

**网页** 页列出各中枢发布的网址：Gitea、VS Code、code-server、CloudCLI，以及中枢 **服务**（Services）页上手动声明的网址。每个地址下面写着中枢、机器和模块，例如 **由 hub:server:Gitea 提供**。

| 按钮                   | 作用                                         |
| ---------------------- | -------------------------------------------- |
| **打开**（Open）       | 没有转发时先开转发，再在浏览器里打开这个页面 |
| **配置**（Configure）  | 设定这个转发的本地端口                       |
| **断开**（Disconnect） | 条目转发着时出现，关掉转发                   |

浏览器打开的地址是一个 `.localhost` 下的名字加本地端口，每个实例一个名字，两个实例的登录互不干扰。macOS 上这个名字换成 `127.0.0.1`，因为 Safari 不解析 `.localhost` 下的名字。

VS Code、code-server 和 CloudCLI 的条目带令牌打开。每按一次 **打开**，客户端都向中枢取一个新令牌加在地址后面；code-server 和 CloudCLI 的令牌 60 秒内有效，只能用一次。中枢没给令牌时，这一行写 `web_token_missing`。

中枢连不到的条目变灰，写着 **当前无法访问**（Not reachable now）。

## 端口

**端口** 页列出中枢发布的端口：受管机器上容器的主机端口，以及中枢 **服务** 页上手动声明的 TCP 或 UDP 端口。

- 在条目上选 **连接**（Connect）。

按钮先写 **转发中…**，再变成 **断开**，这一行后面多出 `→ 127.0.0.1:` 和本地端口。本机的程序连这个地址即可。

UDP 条目写成 `host:port/udp`，转发后地址末尾也带 `/udp`。程序把数据报发到这个本地地址，回复也回到那里。手动声明的 UDP 端口不显示健康状态，**连接** 一直能按。

这个客户端的所有流量都走同一条到中枢的 TCP 连接。丢一个包，这条连接上的每条流都等它重发，UDP 的流也一样。所以经中枢转发的 UDP 适合一问一答、量不大的流量，例如 DNS、校时和设备发现。语音、视频和快节奏的游戏，要在虚拟网自己的控制台里设一条直达那台机器的子网路由。

## AI

**AI** 页让本机的 Claude Code、Codex 和 Gemini CLI 用某台中枢的 AI 网关。每台带网关的中枢有一个条目，条目上有 **配置**（Configure）和 **AI 工具使用此网关**（The AI tools use this gateway）开关，同一时间最多开一个。

打开一个条目的开关，条目先写 **切换工具中…**，再写 **工具已指向中枢**，原来开着的那个随之关上。客户端为这个网关开好转发，让三个工具带着本客户端的密钥连这个转发。客户端用自带的 cc-switch 改写三个工具的配置；再按一次开关，三个工具回到原来的配置。

条目下面写着 **只有这个客户端开着时，工具才连得到网关。**（The tools reach the gateway only while this client runs.）用这些工具时，让客户端在托盘里开着。

只有连着的中枢能打开开关，否则客户端返回 `no_exit_hub`。中枢还没给这个客户端发密钥时，返回 `no_endpoint`。

选模型的步骤：

1. 在条目上选 **配置**，打开 **AI 工具配置**（AI tool configuration）。
1. 在 **Claude Code** 下选 **默认模型**（Default model）和 **Opus 档位**、**Sonnet 档位**、**Haiku 档位**（Opus slot、Sonnet slot、Haiku slot）。
1. 在 **Codex** 下选 **模型**（Model）和 **推理强度**（Reasoning effort）。
1. 在 **Gemini** 下选 **模型**。
1. 选 **保存**（Save）。

每一项都能选 **网关默认**（gateway default），列出的模型是那台中枢自己的。开关开着的网关，保存后马上改写工具；其他网关的选择，等打开它的开关时才生效。

这台电脑也装了被控端时，开关和 **配置** 都变灰，条目仍列出地址。原因行写的是 `ai_tools_managed`：这台电脑的 AI 工具改在中枢面板的 **模块**（Modules）页上设，位置在 **全局配置**（Global configuration）里。开关原来开着的话，客户端先关掉它，把工具恢复原样。面板那边的做法见[把一台机器的 AI 工具指向网关](../agent/modules/ai_tools.md)。

## 文件

**文件** 页把中枢发布的 SMB 共享挂到本机：Linux 上挂到家目录下的文件夹，macOS 上成为访达里的一个卷，Windows 上挂到一个盘符。条目来自受管机器上 **File share** 模块的共享，以及中枢 **服务** 页上手动声明的共享。

挂载的步骤：

1. 在条目上选 **配置**（Configure），这一行下面展开一个表单。
1. 填 **共享用户名**（Share username）和 **共享密码**（Share password）。
1. Linux 上，保留或修改 **挂载路径**（Mount path），用 **浏览…**（Browse…）选或新建文件夹。Windows 上选 **盘符**（Drive）。macOS 上没有位置要选。
1. 选 **保存**（Save）。
1. 选 **挂载**（Mount）。按钮先写 **挂载中…**，挂好后变成 **卸载**（Unmount）。

![共享已挂载的文件页](/guide/zh/client_files_mounted.webp)

登录信息存在一个只有你的账户能读的文件里，下次 **挂载** 不用再填。**卸载** 摘掉共享，登录信息留着。

各系统挂载的方式如下。

| 系统    | 挂载方式                                                                                                                |
| ------- | ----------------------------------------------------------------------------------------------------------------------- |
| Linux   | 客户端经 `pkexec` 运行自带的挂载助手，从转发的端口挂载，polkit 弹一次密码框                                             |
| macOS   | 系统从转发上挂载这个卷，和访达的 **连接服务器** 一样；第一次要你确认一次服务器                                          |
| Windows | 文件适配器给提供共享的每台机器一个专用地址，盘符映射到这个地址；共享在本机上时直接挂 `\\127.0.0.1` <!-- scan: allow --> |

macOS 上，密码不对时系统弹出登录框；在那里选 **取消**，这一行写 `mount_not_authorized`。系统十分钟内没挂好时，这一行写 `mount_timed_out`。

Windows 上的适配器是一块名为 `neutrino_files` 的网卡，由 `NeutrinoClientFiles` 服务运行，只把共享的连接送到中枢。这块网卡同一时间只服务一个账户。另一个账户的客户端占着它时，挂载写 `files_adapter_in_use`；那个账户的客户端退出后，你的客户端自己再挂一次。

![文件资源管理器里映射的盘符](/guide/os/win_explorer_mapped.webp)

| 错误码                        | 含义                                                  |
| ----------------------------- | ----------------------------------------------------- |
| `mountpoint_invalid`          | 路径不在家目录下                                      |
| `mountpoint_not_empty`        | 文件夹里有东西                                        |
| `mountpoint_not_drive_letter` | Windows 上选的不是空闲盘符                            |
| `mountpoint_in_use`           | 另一个共享已设成挂在这个位置，不论它来自哪台中枢      |
| `credentials_missing`         | 保存的登录信息丢了，在 **配置** 里重新填              |
| `share_login_rejected`        | 用户名或密码不对，**配置** 自动打开                   |
| `share_access_denied`         | 共享不接受这个登录                                    |
| `share_not_found`             | 主机上没有这个共享名                                  |
| `share_unreachable`           | 主机没有应答，它恢复后客户端自己再挂                  |
| `share_session_conflict`      | Windows 已用另一个账号连着这台服务器，先断开那个连接  |
| `files_adapter_unavailable`   | Windows 上 `NeutrinoClientFiles` 服务缺失、停止或出错 |
| `files_adapter_in_use`        | 文件适配器正归这台电脑上的另一个账户使用              |
| `mount_not_authorized`        | polkit 的授权窗口或 macOS 的登录框关掉了              |
| `mount_tooling_missing`       | Linux 上缺 `mount.cifs`                               |
| `pkexec_missing`              | Linux 上缺 `pkexec`，装上它再按 **挂载**              |

## 终端

**终端** 页在受管机器上开一个 shell，显示在窗口的标签页里。中枢要允许这个客户端打开终端。

1. 在页面上方的机器里选一台，绿色圆点表示它在线。
1. 选 **新终端**（New terminal）。

shell 在新标签页里打开。窗口用自带的 MesloLGS NF 字体，powerlevel10k 提示符的图标照常显示。Ctrl+`+` 和 Ctrl+`-` 调字号。

![客户端里一个持久终端标签页](/guide/zh/client_terminal.webp)

粘贴用右键菜单，或按 Ctrl+Shift+V，macOS 上按 Cmd+V。右键菜单里的 **清屏**（Clear）先给 shell 发 Ctrl+C 再清空屏幕；shell 的输出安静半秒之前，终端里写 **清屏中…**，最长二十秒。

shell 下面一行有两个开关，只有打开这个会话的一方能拨：

- **持久**（Persistent）：没有窗口连着时，机器仍保留这个会话，例如客户端退出之后。
- **共享**（Shared）：对这台机器有终端权限的每个客户端，都能连进这个会话。

保留的会话显示成标签页，选它就连回去，先显示最近的输出。中枢断线又连上后，标签页自动连回各自的会话；会话已不在的标签页写 **已结束**（Ended）。持久或共享的标签页上，**×** 按一次变成 **再按一次结束**（Press again to end），再按一次，机器上的 shell 才结束。面板里同样的会话见[终端](../agent/terminals.md)。

| 错误码              | 含义                                                 |
| ------------------- | ---------------------------------------------------- |
| `permission_denied` | 中枢不允许这个客户端打开终端                         |
| `agent_offline`     | 那台机器现在没连着中枢                               |
| `unknown_terminal`  | 中枢没有提供那台机器的终端                           |
| `session_not_owned` | 会话是别人的，而且没有共享；只能进自己的或共享的会话 |
| `session_unknown`   | 那台机器已不再保留这个会话                           |

## 远程桌面

**远程桌面** 页用客户端自带的 RustDesk 查看器，打开受管机器的屏幕。中枢面板的 **模块** 页上，那台机器的 **Remote desktop** 开关打开后，条目出现。

- 在条目上选 **连接**（Connect）。

按钮写 **连接中…**，查看器打开那台机器的桌面，这一行写 **查看器已打开**（Viewer open）。座位密码由中枢给，随这次连接交给查看器。查看器一关，这个条目的转发也关。

两台机器共用剪贴板。要传文件，在查看器的工具栏里选 **传输文件**（Transfer file）。Mac 的条目下面多一行提示：画面全黑或鼠标不动，是那台 Mac 还没给 RustDesk 开 **屏幕录制** 和 **辅助功能**。

| 现象或错误码                      | 原因                               |
| --------------------------------- | ---------------------------------- |
| 页面写着 **还没有共享的远程桌面** | 没有机器在共享，或共享的机器离线   |
| `rdp_viewer_open`                 | 这个桌面已开着一个查看器，先关掉它 |
| `rdp_not_shared`                  | 那台机器停止了共享                 |
| `rdp_no_desktop`                  | 本机这个会话没有屏幕给查看器用     |
| `rdp_launch_failed`               | 查看器没能启动，码后面是原因       |

## 设置

1. 选侧栏分隔线下面的 **设置**。
1. 在 **客户端设置**（Client settings）里选 **语言**（Language）和 **主题**（Theme）：**跟随系统**（System）、**深色**（Dark）或 **浅色**（Light）。
1. 选 **保存**。

语言和主题只管这个窗口，面板另有自己的设置。**关于**（About）卡片的 **本机**（This machine）下是电脑名字和平台；**携带**（Carried）下是客户端的版本和许可证，以及它自带的每个程序，各带 **源码**（Source）链接。

## 托盘

关闭窗口只把它藏起来，客户端继续运行，中枢都连着，转发都开着。托盘图标在 Windows 任务栏的角落、Linux 顶栏的指示器区、macOS 的菜单栏。图标菜单里的 **打开**（Open）显示窗口，**退出**（Quit）停止客户端。
