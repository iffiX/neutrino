# 窗口

客户端窗口的标题是 **微子·客户端**（Neutrino client），分 **Hub** 和 **服务**（Services）两段。加入的每个 hub 在第一段占一行，在第二段占一组面板，这一页把两段里的每一处都讲一遍。

## Hub 区

一行是一个 hub：名字、当前状态、地址，以及它运行的软件包。每一行上有 **出口**（Exit）单选和 **离开**（Leave），写着 **已被另一个客户端取代** 的行上还多一个 **重新连接**（Reconnect），它们都只作用于这一个 hub。下面常驻 **加入 hub**（Join a hub）那一行，任何 hub 客户端页发的链接都从这里粘进去。

![已加入一个 hub](/guide/zh/client_connected.webp)

| 行里写着                                               | 含义                                                           |
| ------------------------------------------------------ | -------------------------------------------------------------- |
| **已连接**（Connected）                                | 通道开着，这个 hub 的服务在 **服务** 区里                      |
| **正在重新连接 hub**（Reconnecting to the hub）        | 绑定还在，通道断了，客户端自己重连                             |
| **已被 hub 关闭**（Switched off by the hub）           | 这个 hub 的客户端页把它关了，这一组面板的按钮不可用            |
| **已被另一个客户端取代**（Replaced by another client） | 另一个客户端接上了这条绑定，点 **重新连接**（Reconnect）才再连 |

客户端记着每个 hub 的全部地址，hub 推来的状态会更新这份地址表。通道断了之后，客户端逐个地址重连；在 hub 服务的网段上时，先按名字 `hub.neutrino.internal` 找到它。

点 **离开**（Leave）：客户端先告诉这个 hub，再撤掉它这一行和这一组，并撤销它在这台电脑上的挂载、转发和查看器。其余的 hub 照旧。终端里 `nclient join '<link>'` 加入一个 hub，`nclient leave --hub <name>` 离开一个，`<name>` 就是行里的那个名字。

![尚未加入](/guide/zh/client_disconnected.webp)

## 出口 hub

加入的 hub 里有一个是出口，你的 AI 工具指向它的网关。点行上的 **出口**（Exit）单选，出口就换成这个 hub，这一行随即写 **AI 工具指向此 hub**，其余 hub 的 AI 面板写出口是哪一个。

第一个加入的 hub 就是出口，直到你另选一个。离开出口 hub 时，出口改为下一个加入的 hub。只有写着 **已连接** 的行能选中，通道断着的 hub 返回 `no_exit_hub`。[AI 页](./ai.md)写了工具指向网关之后是什么样子。

## 服务区

每组的标题形如 **由 home 发布**（Published by），home 是这个 hub 的名字。标题下面固定画五个面板：**网页**（Web）、**端口**（Ports）、**AI**、**文件**（Files）、**远程桌面**（Remote desktops），没有条目的面板写着没有发布这一类服务。访问不到的条目画成灰色，写 **当前无法访问**（not reachable now）。所属 hub 没连上时，这一组只写那个 hub 的状态。

每条服务下面一行写它由谁发布：

| 来源行写着                        | 条目来自               |
| --------------------------------- | ---------------------- |
| **由某台机器上的 Samba 模块发布** | 那台机器上的一个共享   |
| **由容器某镜像发布**              | 一个容器发布的主机端口 |
| **由 AI 网关发布**                | hub 的 AI 网关         |
| **手动声明**                      | hub 服务页上的一条声明 |
| **由某台机器共享**                | 那台机器的桌面         |

## 设置

![客户端设置](/guide/zh/client_settings_language.webp)

窗口顶部的 **设置**（Settings）打开 **客户端设置**（Client settings）对话框，里面有 **语言**（Language）和 **主题**（Theme）。语言是 English 或简体中文；主题是 **跟随系统**（System）、**深色**（Dark）或 **浅色**（Light），跟随系统取桌面的配色。选好点 **保存**（Save）。语言和主题都是客户端自己的，与面板的无关。

## 托盘

![Windows 托盘菜单](/guide/os/win_tray_flyout.webp)

关闭窗口只是隐藏它，客户端仍在运行，每个 hub 的连接也都还在。托盘图标的菜单有 **打开**（Open）和 **退出**（Quit），退出才停止客户端。

| 系统    | 图标在哪           |
| ------- | ------------------ |
| Windows | 任务栏角落         |
| Linux   | 顶栏的应用指示器区 |
| macOS   | 菜单栏             |

终端里 `nclient gui` 打开窗口，`nclient gui --hidden` 只进托盘不显示窗口，`nclient quit` 停止客户端。

## 拒绝与绑定

hub 拒绝这个客户端时，绑定还在：那一行留着，hub 的名字下面写出错误码，一分钟后客户端再开一次通道。只有一个码会解除绑定，那一行随之消失。

| 行里的码           | 含义                                    | 绑定                       |
| ------------------ | --------------------------------------- | -------------------------- |
| `protocol_too_old` | 客户端的协议号低于 hub 接受的下限       | 保留，装新版的客户端包     |
| `protocol_too_new` | 客户端的协议号高于 hub 的               | 保留，先升级那个 hub       |
| `hub_untrusted`    | 那个地址上的证书不是链接里钉住的那一张  | 保留，hub 重置过就重新加入 |
| `binding_unknown`  | 那个 hub 的客户端页里已经没有这个客户端 | 解除，用新链接重新加入     |

两个协议码都把两个号写出来，客户端自己的和 hub 的，行里因此写明是哪一边旧。包版本不参与这件事：版本不同、协议号相同的客户端和 hub 照常连着。
