# 窗口

客户端窗口的标题是 **微子·客户端**（Neutrino client），左边是侧栏，右边一次显示一页。这一页逐个介绍各页，以及每一行上的按钮。

## 侧栏和页头

侧栏依次是 **中枢**（Hubs）、**网页**（Web）、**端口**（Ports）、**AI**、**文件**（Files）、**终端**（Terminals）和 **远程桌面**（Remote desktops）。侧栏底部写着这台电脑的名字、平台和客户端版本。右边页头写着当前页的名字，右上角是 **↻** 按钮和 **设置**（Settings）。**↻** 让连着的 hub 立刻收到一份报告，断开的 hub 立刻重连一轮。**设置** 打开客户端自己的设置。

## 中枢页

一行是一个 hub：名字、当前状态、地址，以及它运行的软件包。名字前的圆点用颜色表示状态。

| 圆点       | 含义                                                            |
| ---------- | --------------------------------------------------------------- |
| 绿色       | 通道开着                                                        |
| 黄色、转圈 | 正在重连一个连上过的 hub                                        |
| 黄色       | 连不上，但没有东西坏，例如 `hub_unreachable`、`client_disabled` |
| 红色       | 要有人改东西才会好，例如 `hub_untrusted`、`binding_unknown`     |
| 灰色       | 还没连上过                                                      |

hub 发布了虚拟网时，这一行上有 **虚拟网**（Virtual network）按钮，写着状态和本机在虚拟网里的地址。点它加入或离开，详见[虚拟网](./overlay.md)。每行还有 **离开**（Leave）；写着 **已被另一个客户端取代** 的行上多一个 **重新连接**（Reconnect）。下面常驻 **加入 hub**（Join a hub）一行，粘贴任何 hub 客户端页发的链接。

点 **离开**，这一行立刻消失，它在本机上的挂载、转发、查看器都撤销；别的 hub 不用的虚拟网也一起离开。

## 服务页

**网页**、**端口**、**AI**、**文件**、**远程桌面** 每页只有一块面板。面板按加入 hub 的先后，列出每个 hub 这一类的全部条目。每个条目的地址下面写着它来自哪个 hub 的哪台机器，例如 **由 Neutrino:Argon 提供**。0.4.0 之前的 hub 不发机器名，这一处改写那台机器的地址。

暂时访问不到的条目画成灰色，写 **当前无法访问**。没连上的 hub 在面板里占一行灰色，只写它的状态。面板里一个条目都没有时写一行，例如“没有发布端口”。

## AI 页

每个 hub 的 AI 网关是一个条目，条目上有 **AI 工具使用此网关** 开关，同一时间最多开一个。打开一个，它的 hub 成为目标，AI 工具指向这个网关，另一个开关随之关上。关掉正在用的那个，AI 工具恢复原样。只有连着的 hub 能打开；通道断着的，客户端返回 `no_exit_hub`。**配置**（Config）选模型，详见 [AI](./ai.md)。

## 终端页

上方一排列出所有连着的 hub 提供终端的机器，机器在线时圆点是绿的。选中一台，点 **新终端**（New terminal），下方多一个标签页，里面是那台机器的 shell，详见[终端](./terminals.md)。

## 设置

1. 点页头的 **设置**。
1. 在 **客户端设置**（Client settings）对话框里选 **语言**（Language）和 **主题**（Theme）。
1. 点 **保存**（Save）。

语言和主题都是客户端自己的，与面板的无关。

## 托盘

关闭窗口只是隐藏它，客户端仍在运行，每个 hub 的连接都在。托盘图标的菜单有 **打开**（Open）和 **退出**（Quit）。终端里 `nclient gui --hidden` 只进托盘，`nclient quit` 停止客户端。

## 拒绝与绑定

hub 拒绝这个客户端时，绑定还在：那一行留着并写出错误码，一分钟后客户端再开一次通道。只有一个码会解除绑定，那一行随之消失。

| 行里的码           | 含义                                    | 绑定                       |
| ------------------ | --------------------------------------- | -------------------------- |
| `protocol_too_old` | 客户端的协议号低于 hub 接受的下限       | 保留，装新版客户端         |
| `protocol_too_new` | 客户端的协议号高于 hub 的               | 保留，先升级那个 hub       |
| `hub_untrusted`    | 那个地址上的证书不是链接钉住的那一张    | 保留，hub 重置过就重新加入 |
| `binding_unknown`  | 那个 hub 的客户端页里已经没有这个客户端 | 解除，用新链接重新加入     |
