# 窗口

客户端窗口的标题是 **微子·客户端**（Neutrino client）。窗口分 **状态**（Status）和 **服务**（Services）两段：状态卡管连接和断开，服务区是五个面板。语言在设置对话框里改，托盘图标在窗口关掉后仍在。

## 状态卡

![已连接](/guide/zh/client_connected.webp)

| 状态卡写着                                      | 含义                           | 卡上有什么                                       |
| ----------------------------------------------- | ------------------------------ | ------------------------------------------------ |
| **已连接**（Connected）                         | 客户端连着 hub                 | `hub 0.2.0` 这样的版本号，**断开**（Disconnect） |
| **未连接**（Not connected）                     | 还没有加入，或者已经断开       | 一个粘贴链接的输入框，**连接**（Connect）        |
| **正在重新连接 hub**（Reconnecting to the hub） | 绑定还在，客户端暂时连不上 hub | 客户端自己重试，连上后回到已连接                 |

![未连接](/guide/zh/client_disconnected.webp)

加入时把 hub 客户端页发的链接粘进输入框，点 **连接**。点 **断开** 回到未连接，服务区写着 **加入 hub 后这里会出现服务。**hub 停用了这个客户端时，状态卡说明这一点，每个按钮变灰。

## 五个面板与来源行

**服务** 区固定画五个面板，顺序是 **网页**（Web）、**端口**（Ports）、**AI**、**文件**（Files）、**远程桌面**（Remote desktops），没有条目的面板写着没有发布这一类服务。每条服务下面一行写它由谁发布：某台机器上的 Samba 或 Gitea 模块、某个容器镜像、AI 网关、手动声明，或者某台机器自己共享的桌面。访问不到的条目画成灰色，写 **当前无法访问**。

| 面板                             | 按钮                                             |
| -------------------------------- | ------------------------------------------------ |
| [网页](./web.md)                 | **打开**（Open）                                 |
| [端口](./ports.md)               | **连接**、**断开**                               |
| [AI](./ai.md)                    | **配置**（Config）、**应用**（Apply）            |
| [文件](./files.md)               | **配置**、**挂载**（Mount）、**卸载**（Unmount） |
| [远程桌面](./remote-desktops.md) | **连接**                                         |

## 设置

![客户端设置](/guide/zh/client_settings_language.webp)

窗口顶部的 **设置**（Settings）打开 **客户端设置**（Client settings）对话框，里面只有 **语言**（Language）：English 或简体中文。选好点 **保存**（Save）。这个语言是客户端自己的，与面板的语言无关。

## 托盘

![Windows 托盘菜单](/guide/os/win_tray_flyout.webp)

关闭窗口只是隐藏它，客户端仍在运行。托盘图标的菜单有 **打开**（Open）和 **退出**（Quit），退出才停止客户端。

| 系统    | 图标在哪           |
| ------- | ------------------ |
| Windows | 任务栏角落         |
| Linux   | 顶栏的应用指示器区 |
| macOS   | 菜单栏             |

终端里 `nclient gui` 打开窗口，`nclient gui --hidden` 只进托盘不显示窗口，`nclient quit` 停止客户端。

## 版本不一致时

客户端比 hub 新时，它返回 `client_newer_than_hub`，说明先升级 hub，并自己解绑；hub 升级后粘一条新链接。客户端比 hub 旧时，hub 照常接纳；窗口顶部写着客户端的版本，状态卡写着 hub 的版本，两者不同就装新的客户端包，绑定不变。
