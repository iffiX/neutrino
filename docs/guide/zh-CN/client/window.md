# 窗口

客户端窗口的标题是 **微子·客户端**（Neutrino client），顶部一排标签，一次只显示其中一个。这一页逐个介绍各个标签，以及每一行上的按钮。

## 顶栏

顶栏写着这台电脑的名字、平台和客户端版本。标签依次是 **Hub**（Hubs）、**网页**（Web）、**文件**（Files）、**端口**（Ports）、**远程桌面**（Remote desktops）、**AI** 和 **终端**（Terminals）。**↻** 按钮让连着的 hub 立刻收到一份报告，断开的 hub 立刻重连一轮。**设置**（Settings）打开客户端自己的设置。

## Hub 标签

一行是一个 hub：名字、当前状态、地址，以及它运行的软件包。名字前的圆点用颜色表示状态。

| 圆点       | 含义                                                            |
| ---------- | --------------------------------------------------------------- |
| 绿色       | 通道开着                                                        |
| 黄色、转圈 | 正在重连一个连上过的 hub                                        |
| 黄色       | 连不上，但没有东西坏，例如 `hub_unreachable`、`client_disabled` |
| 红色       | 要有人改东西才会好，例如 `hub_untrusted`、`binding_unknown`     |
| 灰色       | 还没连上过                                                      |

hub 发布了虚拟网时，这一行上有 **虚拟网**（Virtual network）按钮，写着状态和本机在虚拟网里的地址。点它加入或离开，详见[虚拟网](./overlay.md)。每行还有 **目标**（Target）单选和 **离开**（Leave）；写着 **已被另一个客户端取代** 的行上多一个 **重新连接**（Reconnect）。下面常驻 **加入 hub**（Join a hub）一行，粘贴任何 hub 客户端页发的链接。

点 **离开**，这一行立刻消失，它在本机上的挂载、转发、查看器都撤销；别的 hub 不用的虚拟网也一起离开。

## 目标 hub

加入的 hub 里有一个是目标，你的 AI 工具指向它的网关。点 **目标** 单选即换成这个 hub。只有连着的 hub 能选，通道断着的返回 `no_exit_hub`。[AI 页](./ai.md)写了工具指向网关之后的样子。

## 服务标签

**网页**、**文件**、**端口**、**远程桌面**、**AI** 这几个标签里，每个 hub 占一栏，窗口够宽时两栏并排。一栏列出这个 hub 这一类的条目；没有条目时写一行，例如“没有发布端口”。暂时访问不到的条目画成灰色，写 **当前无法访问**。hub 没连上时，这一栏只写它的状态。

## 终端标签

每个 hub 一栏，列出它提供终端的机器。点 **打开终端**（Open terminal），本机的终端程序打开那台机器的 shell，详见[终端](./terminals.md)。机器离线时按钮是灰的。

## 设置

1. 点顶栏的 **设置**。
1. 在 **客户端设置**（Client settings）对话框里选 **语言**（Language）和 **主题**（Theme）。
1. 点 **保存**（Save）。

语言和主题都是客户端自己的，与面板的无关。

## 托盘

关闭窗口只是隐藏它，客户端仍在运行，每个 hub 的连接都在。托盘图标的菜单有 **打开**（Open）和 **退出**（Quit）。终端里 `nclient gui --hidden` 只进托盘，`nclient quit` 停止客户端。

## 拒绝与绑定

hub 拒绝这个客户端时，绑定还在：那一行留着并写出错误码，一分钟后客户端再开一次通道。只有一个码会解除绑定，那一行随之消失。

| 行里的码           | 含义                                    | 绑定                       |
| ------------------ | --------------------------------------- | -------------------------- |
| `protocol_too_old` | 客户端的协议号低于 hub 接受的下限       | 保留，装新版客户端         |
| `protocol_too_new` | 客户端的协议号高于 hub 的               | 保留，先升级那个 hub       |
| `hub_untrusted`    | 那个地址上的证书不是链接钉住的那一张    | 保留，hub 重置过就重新加入 |
| `binding_unknown`  | 那个 hub 的客户端页里已经没有这个客户端 | 解除，用新链接重新加入     |
