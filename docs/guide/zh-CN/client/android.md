# Android 应用

Android 应用是装在手机上的客户端。加入中枢之后，中枢发布的网页、端口、AI 网关、共享、终端和远程桌面，都能在手机上打开。应用的每一屏都只连中枢的 8443 端口，由中枢接到服务所在的机器，所以手机在家在外用法相同。

应用怎么装、怎么扫码加入中枢，见[安装客户端](../install/client.md)。

## 中枢

竖屏时，屏幕底部一排按钮依次打开 **中枢**（Hubs）、**网页**（Web）、**端口**（Ports）、**AI**、**文件**（Files）、**终端**（Terminals）、**远程桌面**（Remote desktops）和 **设置**（Settings）。横屏时，以及宽度至少 720 dp 的平板上，这一排换成左边的侧栏。

**中枢** 屏上一行是一台中枢：名字、状态、地址和它运行的软件包版本。连上以后，状态写出通道走的路，例如 **已连接 · 局域网**（Connected · LAN），旁边的标签是手机和中枢之间的往返时间，例如 **35 ms**。应用每 20 秒量一次这个时间。

**已连接 · 直连**（Direct）表示手机从外面直接连上了中枢开放的地址，见[打开直连](../hub/overlay.md#打开直连)。**已连接 · SSH 中继**（SSH Relay）表示手机连的是一台服务器上的公网端口，这台服务器归中枢的主人。SSH 中继的设置见 [SSH 中继](../hub/relay.md)。

### 离开与重新连接

一行上的 **离开**（Leave）按一次变成 **再按一次离开**（Press again to leave），五秒内再按，手机才离开这台中枢。手机删掉这台中枢的链接和密钥，它在手机上的转发和共享随之结束。

一行写着 **已被另一个客户端取代**（Replaced by another client）时，这一行上多一个 **重新连接**（Reconnect）。选它，手机把这台中枢要回来。

### 面板

中枢在 **客户端**（Clients）页给了这部手机 **免密码进入中枢面板**（Hub panel without the password）时，这一行上有 **面板**（Panel）。选它，中枢的面板经手机上的一个转发，在手机浏览器里打开，打开时已经登录。中枢不允许时，例如返回 `permission_denied`，错误写在这一行上。

### 虚拟网

中枢发布了 NetBird 或 EasyTier，而且允许这部手机用虚拟网时，中枢那一行下面多一行 **虚拟网**（Virtual network）。要加入这个网络：

1. 在这一行上选 **连接**（Connect）。
1. 第一次连接时，Android 弹出 VPN 连接请求，在里面选 **确定**。

这一行先写 **连接中…**（Connecting…），下面写 **正在登录**（Logging in to）加引擎名，**取消**（Cancel）能停下它。引擎拿到地址后，这一行写 **已连接 ·** 加手机在网络里的地址，按钮变成 **断开**（Disconnect）。失败时这一行回到 **未连接**（Not connected），错误码写在下面。

![中枢行和虚拟网行都已连接](/guide/zh/app_hub.webp)

EasyTier 用控制台模式时，登录之后这一行仍写 **连接中…**，下面一行说手机已登记到控制台，等着在控制台里挂到一个网络上。控制台的主人把手机挂上之后，这一行才变成 **已连接**。

![虚拟网行在等控制台挂载](/guide/zh/app_hub_console_waiting.webp)

手机同一时间只在一台中枢的网络里。一台中枢的网络没断开时，其他中枢的 **连接** 变灰，原因写 `overlay_other_network`；先在那台中枢的虚拟网行上选 **断开**，这里的 **连接** 才能按。中枢两种引擎都发布时，按钮旁边有一个选择框，这一行写着 **未连接** 时能换引擎。

## 转发

转发是应用为一个条目在手机 `127.0.0.1` 上开的端口，连到它的每条连接都经中枢接到服务上。所有转发和所有中枢连接都在应用的一个前台服务里运行，切到别的应用时照常工作。这个服务的通知写着已连接几台中枢。

**网页** 和 **端口** 屏上，行里的 **配置**（Configure）设定 **本地端口**（Local port）：

- **自动**（Auto）：条目自己的端口空闲时用它，否则从 20000 往上找一个。
- **指定**（Fixed）：用你填的号，范围 1024～65535。

同一个号可以 TCP 用一次，UDP 再用一次。条目转发着时 **配置** 变灰。

| 错误码               | 含义                                                                                         |
| -------------------- | -------------------------------------------------------------------------------------------- |
| `connect_failed`     | 中枢或那台机器连不上服务，原因是 `refused`（端口上没有程序监听）、`timeout` 或 `unreachable` |
| `agent_offline`      | 提供这个条目的机器现在没连着中枢                                                             |
| `port_not_published` | 那台机器现在没发布这个端口                                                                   |
| `connect_limit`      | 这部手机经中枢开着的连接到了 256 条，关掉几条再试                                            |
| `permission_denied`  | 中枢不允许这部手机用这类条目，或不允许用那台机器                                             |
| `service_unknown`    | 中枢已不再发布这个条目                                                                       |

## 网页

**网页** 屏列出各中枢发布的网址：Gitea、VS Code、code-server、CloudCLI，以及中枢 **服务**（Services）页上声明的网址。

在一行上选 **打开**（Open）。应用为这个条目开好转发，在手机浏览器里打开 `127.0.0.1` 上的页面。VS Code、code-server 和 CloudCLI 的条目，每按一次 **打开** 都向中枢取一个新令牌。**断开** 关掉转发。

## 端口

**端口** 屏列出中枢发布的每个端口，地址写的是服务在中枢网络上的位置。

1. 在条目上选 **连接**（Connect）。这一行后面多出 `→ 127.0.0.1:` 和本地端口，按钮变成 **断开**。
1. 选 **复制**（Copy），把这个回环地址粘进手机上要用它的应用。

UDP 条目写成 `host:port/udp`，**复制** 复制的地址不带 `/udp`。手机上的应用把数据报发到这个地址，回复也回到那里。所有流量都走同一条到中枢的 TCP 连接，所以经中枢转发的 UDP 适合 DNS、校时这类量小的一问一答。

## AI

**AI** 屏上，每个运行 AI 网关的中枢有一行。

1. 选 **连接**（Connect），网关转发到手机上。
1. 从两行地址里选一行，按它的 **复制**（Copy）。
1. 按 **此客户端的密钥**（This client's key）右边的 **复制**。
1. 把地址和密钥填进手机上支持 OpenAI 接口的应用。

两行地址的区别：

| 标签                                                                     | 地址                     |
| ------------------------------------------------------------------------ | ------------------------ |
| **应用自己会加 /v1 时用这个**（For apps that add /v1 themselves）        | 回环地址，末尾不带 `/v1` |
| **应用要求地址带 /v1 时用这个**（For apps that want /v1 in the address） | 同一个地址，末尾加 `/v1` |

密钥默认藏着，点输入框里的眼睛按钮显示。这一行下面写着 **只有这个客户端开着时，工具才连得到网关。** 意思是应用开着这个转发时，回环地址才连得上。中枢的保险库锁着、取不到这部手机的密钥时，这一行写 `vault_locked`。

## 文件

**文件** 屏把中枢发布的每个共享，变成 Android “文件”应用里的一个位置。还没存密码的共享，行上带 **未存密码**（Password not saved）。

1. 在共享上选 **在“文件”中打开**（Open in Files）。
1. 选或填 **共享用户名**（Share username），再填 **共享密码**（Share password）。
1. 保持勾选 **记住**（Remember），密码存进 Android Keystore；不勾选的话，应用进程退出后密码就没了。
1. 选 **连接**（Connect）。应用先用这组登录试连共享，成功后在“文件”里打开它。

![“文件”应用里作为一个位置的共享](/guide/zh/app_files_provider.webp)

在“文件”应用的侧栏里，这个位置以共享名命名，下面一行写着中枢和机器。里面的文件能打开、写入、新建和删除，视频边读边放。中枢断线时，这个位置在“文件”里再留 60 秒，标着正在重新连接。

没存密码的共享在“文件”里打不开，“文件”提示先到应用的文件屏输入密码，这时照上面的步骤重新填。

行上的 **忘掉密码**（Forget password）按一次变成 **再按一次以忘掉**，再按一次，存着的密码才删掉。

## 终端

**终端** 屏在受管机器上开一个 shell。中枢要允许这部手机打开终端。

1. 在上方的机器里选一台，绿色圆点表示它在线。
1. 选 **新终端**（New terminal）。

![带按键行的终端](/guide/zh/app_terminal.webp)

键盘上方一行补上手机键盘缺的键：Esc、Tab、Ctrl、Shift、Alt 和四个方向键。修饰键按一下亮起，作用在下一个键上。在 shell 上长按，弹出 **复制**、**粘贴** 和 **清屏**（Clear）。**清屏** 先发 Ctrl+C 再清空屏幕，shell 的输出安静半秒之前，终端里写 **清屏中…**。

**持久**（Persistent）开关打开后，手机不连着时机器仍保留这个会话。应用再启动时，持久的标签页回来，先写 **已断开，正在等待中枢**，连上后接回会话。它的 **×** 按一次变成 **再按一次结束**，再按一次，机器上的 shell 才结束。

## 远程桌面

**远程桌面** 屏打开受管机器共享出来的桌面。中枢面板的 **模块**（Modules）页上，那台机器的 **Remote desktop** 开关打开后，条目出现。

1. 可选：在条目上选 **配置**（Configure），在 **画面**（Picture）对话框里选 **编码**（Codec）和 **画质**（Quality），再选 **保存**。
1. 选 **连接**（Connect）。

查看器占满整个屏幕，系统的状态栏从屏幕边缘划出来。

![手机查看器里的电脑桌面](/guide/zh/app_rdp_viewer.webp)

右上角一直有三个圆按钮：

| 按钮                   | 作用                                                           |
| ---------------------- | -------------------------------------------------------------- |
| **键盘**（Keyboard）   | 弹出或收起手机键盘                                             |
| **特殊键**（Keys）     | 显示按键条：Esc、Tab、Ctrl、Shift、Alt、Win、**粘贴** 和方向键 |
| **断开**（Disconnect） | 结束这次远程桌面                                               |

键盘弹出时画面大小不变，键盘盖住画面的下半部分。用两指拖动和缩放，去看键盘盖住的地方。

## 设置

在 **设置** 屏上选 **语言**（Language）和 **主题**（Theme），再选 **保存**（Save）。**关于**（About）卡片列出手机的名字和平台、应用的版本和 AGPL-3.0 许可证，以及应用携带的每个核心。
