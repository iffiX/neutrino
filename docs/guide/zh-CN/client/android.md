# Android 应用

手机装上 Android 应用，用 hub 客户端页上建的客户端链接，就能加入这个 hub。hub 的虚拟网、网页、端口、AI 网关、共享和终端随后都能在手机上打开。链接怎么建、每个客户端能用什么，见[客户端](../hub/clients.md)。

## 安装应用

开始之前，确认手机满足下列条件：

- Android 8.0 或更新版本。
- 64 位 ARM 处理器。发布页上只有 `arm64-v8a` 的 apk。
- 能访问 hub 的 8443 端口。

安装的步骤：

1. 在手机上从发布页下载 `neutrino-client-0.5.0-android.apk`。
1. 打开这个文件。Android 提示时，允许浏览器或文件管理器安装应用。
1. 选 **安装**，装好后打开 **微子**。

每个发布的 apk 都用项目自己的密钥签名。已装的应用，只能用同一把密钥签名的 apk 升级。要核对下载的 apk，在装有 Android SDK 构建工具的电脑上运行：

```bash
apksigner verify --print-certs neutrino-client-0.5.0-android.apk
```

```text
Signer #1 certificate SHA-256 digest: 0e20b8b4542f329c4d3ed91632f3ea90730cb99472c46c31585780d046ee612d
...
```

::: warning
摘要对不上，就删掉这个 apk。发布流程在附上文件之前，核对的也是这个摘要。
:::

## 加入 hub

开始之前，先在 hub 的面板里建一条客户端链接：打开 **客户端**（Clients），选 **新建客户端链接**（New client link），填手机的名字，再选 **创建链接**（Create link）。通知里以文字显示链接，旁边有 **复制**（Copy），五分钟内有效。面板不生成这条链接的二维码。把链接发到手机上，或者自己用工具把它做成二维码。

加入的步骤：

1. 在应用的 **中枢**（Hubs）页上，选 **加入 hub**（Join a hub）。
1. 选 **允许使用相机**（Allow the camera），Android 弹出权限请求时选允许。
1. 把相机对准装着这条链接的二维码。应用读到二维码就立刻加入。

![加入 hub 页上的二维码扫描框](/guide/zh/app_join_scan.webp)

要粘贴的话，把链接粘进 **或**（or）下面的输入框，选 **加入**（Join）。粘的是 hub **设备**（Devices）页发的链接时，应用返回 `link_not_for_client`；链接过期或已用过时，返回 `enroll_refused`。

要再加入一个 hub，用那个 hub 的链接再走一遍 **加入 hub**。每个 hub 各记各的手机名字，各发布各的服务。

## 中枢

**中枢** 页上一行是一个 hub，写着名字、状态、地址和它运行的软件包。竖屏时，底部一排按钮打开 **中枢**、**网页**（Web）、**端口**（Ports）、**AI**、**文件**（Files）、**终端**（Terminals）、**远程桌面**（Remote desktops）和 **设置**（Settings）。横屏且窗口够宽时，换成左边的侧栏。

### 离开与重新连接

一行上的 **离开**（Leave）先弹出确认，写明 hub 的名字，并说明手机会忘掉它的链接和密钥。再选 **离开** 就移除这个 hub，选 **取消**（Cancel）则保留。写着 **已被另一个客户端取代**（Replaced by another client）的行上，还有 **重新连接**（Reconnect）。

### 虚拟网

hub 发布了虚拟网时，这一行上有一个标签。选它就加入，再选一次就离开。第一次加入时，Android 弹出 VPN 连接请求。选 **确定** 后，应用在 Android 的 VPN 服务里运行 NetBird 或 EasyTier。

![带虚拟网标签的 hub 行](/guide/zh/app_hub.webp)

标签先写 **加入中…**（joining…），加入后写 **已加入**（on）、NetBird 或 EasyTier，以及手机在这个网络里的地址。每个页面顶栏都写着 **虚拟网**（Virtual network）和这个地址，没加入时写 **未加入**（off）。加入失败时，标签写 **失败**（failed），错误码写在下面。

手机同一时间只在一个 hub 的网络里。打开第二个 hub 的标签，第一个 hub 的标签随之关上。

hub 发布了不止一个网络时，标签旁边多一个选择框，显示正在用的 NetBird 或 EasyTier。选另一个，手机就换到那个网络。hub 的通道断开满 30 秒时，应用把手机换到这个 hub 的下一个网络。

## 网页

**网页** 页列出各个 hub 发布的网址。选一行，地址在手机浏览器里打开。

VS Code 条目只能从桌面客户端经那台电脑的 localhost 打开。手机上这一行是灰的，带 **仅桌面**（Desktop only）标记，选了也不打开。

## 端口

**端口** 页列出 hub 发布的每个端口，写着地址和端口号。手机不做转发，手机上的程序直接连这个地址。选 **复制**（Copy）复制地址和端口。

## 文件

**文件** 页把 hub 发布的每个共享，变成 Android “文件”应用里的一个位置。还没存密码的一行，带 **未存密码**（Password not saved）标记。

1. 在 **文件** 页的共享上，选 **在“文件”中打开**（Open in Files）。
1. 选或填 **共享用户名**（Share username），再填 **共享密码**（Share password）。
1. 保持勾选 **记住**（Remember），密码存进 Android Keystore。不勾选，应用只在这次运行期间记着它。
1. 选 **连接**（Connect）。应用先用这组登录信息试连共享，成功后在“文件”里打开它。

![“文件”应用里作为一个位置的共享](/guide/zh/app_files_provider.webp)

在“文件”里，这个位置以共享名命名，下面一行写着 hub 和机器。你可以在里面打开、写入、新建和删除文件，视频边读边放。没存密码的共享打不开，“文件”里会提示先到应用的文件页输入密码。主机没有应答时，返回 `share_unreachable`。

## 终端

**终端** 页在受管机器上开一个 shell。hub 的客户端页要允许这台手机打开终端。

1. 在上方的机器标签里选中一台。绿色圆点表示机器在线。
1. 选 **新终端**（New terminal）。

![带按键行的终端](/guide/zh/app_terminal.webp)

shell 在一个标签页里打开，标签名是机器名加一个序号。下面一行补上手机键盘缺的键：**Esc**、**Tab**、**Ctrl**、四个方向键和 **粘贴**（Paste）。**Ctrl** 按下后一直亮着，作用在你敲的下一个键上。**粘贴** 把剪贴板里的文字发给 shell。

shell 下面的 **持久**（Persistent）开关打开后，手机不在时机器仍保留这个会话。应用再次启动时，持久标签页会回来，写着 **已断开，hub 恢复后会重新连上。** 它的 **×** 先弹出确认：选 **结束**（End），机器上的 shell 退出；选 **取消**，会话保留。面板里同样的会话见[终端](../agent/terminals.md)。

## 设置

在 **设置** 页上选 **语言**（Language）和 **主题**（Theme），再选 **保存**（Save）。**关于**（About）里有应用版本、AGPL-3.0 许可，以及应用携带的核心。
