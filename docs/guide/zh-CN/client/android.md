# Android 应用

手机装上 Android 应用，用中枢客户端页上建的客户端链接，就能加入这台中枢。中枢的网页、端口、AI 网关、共享、终端和远程桌面随后都能在手机上打开。链接怎么建、每个客户端能用什么，见[客户端](../hub/clients.md)。

每一页都经中枢连到服务。应用在手机的回环地址 `127.0.0.1` 上监听，每条连接都转给中枢的 8443 端口，由中枢接到服务上。所以手机只要连得上中枢这一个端口，在家在外都一样。

## 安装应用

开始之前，确认手机满足下列条件：

- Android 8.0 或更新版本。
- 64 位 ARM 处理器。发布页上只有 `arm64-v8a` 的 apk。
- 能访问中枢的 8443 端口：在局域网里直接访问，在外面经[外部访问](../hub/overlay.md)里的任意一种办法访问。

安装的步骤：

1. 在手机上从发布页下载 `neutrino-client-0.5.0-android.apk`。
1. 打开这个文件。Android 提示时，允许浏览器或文件管理器安装应用。
1. 选 **安装**，装好后打开 **微子**。

国内版的 apk 在 Gitee 的发布页上，里面没有 NetBird 核心。

每个发布的 apk 都用项目自己的密钥签名。已装的应用，只能用同一把密钥签名的 apk 升级。要核对下载的 apk，在装有 Android SDK 构建工具的电脑上运行：

```bash
apksigner verify --print-certs neutrino-client-0.5.0-android.apk
```

```text
Signer #1 certificate SHA-256 digest: 0e20b8b4542f329c4d3ed91632f3ea90730cb99472c46c31585780d046ee612d
...
```

37 及更新的构建工具把这一行打成 `V2 Signer: certificate SHA-256 digest: …`，摘要相同。

::: warning
摘要对不上，就删掉这个 apk。发布流程在附上文件之前，核对的也是这个摘要。
:::

## 加入中枢

开始之前，先在中枢的面板里建一条客户端链接：打开 **客户端**（Clients），选 **新建客户端链接**（New client link），填手机的名字，再选 **创建链接**（Create link）。通知里显示链接和 **复制**（Copy）按钮，旁边是这条链接的二维码。链接三十分钟内有效，中枢中途重启也照样有效。

加入的步骤：

1. 在应用的 **中枢**（Hubs）页上，选 **加入中枢**（Join a hub）。
1. 选 **允许使用相机**（Allow the camera），Android 弹出权限请求时选允许。
1. 把相机对准中枢客户端页上的二维码。应用读到二维码就立刻加入。

![加入中枢页上的二维码扫描框](/guide/zh/app_join_scan.webp)

要粘贴的话，把链接粘进 **或**（or）下面的输入框，选 **加入**（Join）。粘的是中枢 **设备**（Devices）页发的链接时，输入框下面写 `link_not_for_client`。

中枢的一行马上出现。在外面用手机流量时，链接里的地址还没有一个连得上，这一行就写 **已加入，尚未连上中枢**（Joined; the hub has not been reached yet）。链接已用过或已过期时，这一行变成 **未连上**（Not connected），写着 `ticket_spent`；离开这台中枢，再扫一条新链接。中枢上失败的加入太多时，这一行写 `admission_paused`，过了码里给的秒数，应用再自己加入。

要再加入一台中枢，用那台中枢的链接再走一遍 **加入中枢**。每台中枢各记各的手机名字，各发布各的服务。

## 中枢

**中枢** 页上一行是一台中枢，写着名字、状态、地址和它运行的软件包。竖屏时，底部一排按钮打开 **中枢**、**网页**（Web）、**端口**（Ports）、**AI**、**文件**（Files）、**终端**（Terminals）、**远程桌面**（Remote desktops）和 **设置**（Settings）。横屏时，以及宽度至少 720 dp 的平板上，换成左边的侧栏。

通道开着时，状态写出这次是从哪条路连上中枢的：**已连接 · 局域网**、**已连接 · 直连**、**已连接 · NetBird**、**已连接 · EasyTier** 或 **已连接 · 中继**。直连表示手机从中枢所在的所有网络之外、经中枢开放的地址连上了中枢的 8443 端口，见[打开直连](../hub/overlay.md#打开直连)。本应用不认识的方式只写 **已连接**。中继表示手机连的是一台服务器的公网端口，那台服务器由中枢的主人自己架设，见[中继](../hub/relay.md)。

### 离开与重新连接

一行上的 **离开**（Leave）按一次变成 **再按一次离开**（Press again to leave），五秒内再按才移除这台中枢。手机忘掉它的链接和密钥，这台中枢在手机上的转发和共享随之结束。写着 **已被另一个客户端取代**（Replaced by another client）的行上，还有 **重新连接**（Reconnect）。

### 面板

中枢的客户端页允许 **免密码进入中枢面板**（Hub panel without the password）时，这一行上有 **面板**（Panel）。选它，中枢的面板经手机上的一个转发在浏览器里打开，打开时已经登录。这个开关默认是关的，要有人为这部手机打开；被拒绝时，例如 `permission_denied`，错误显示在这一行上。只要应用连得上中枢，面板就打得开，所以面板自己的端口只开在局域网里就够了。

### 虚拟网

应用的各页只用到中枢的 8443 端口，虚拟网只是从外面连回来的办法之一。中枢发布了 NetBird 或 EasyTier 时，这一行下面有一行 **虚拟网**（Virtual network），带 **连接**（Connect）按钮。

![带虚拟网一行的中枢](/guide/zh/app_hub.webp)

1. 选 **连接**。第一次连接时，Android 弹出 VPN 连接请求。
1. 在请求里选 **确定**，应用才能在 Android 的 VPN 服务里运行 NetBird 或 EasyTier。

这一行先写 **连接中…**，下面写 **正在登录** 加引擎名；登录后写 **正在等待中枢应答**，并计秒。中枢能经这个网络连上时，这一行写 **已连接 ·** 加手机的地址，按钮变成 **断开**（Disconnect）。连接还在进行时，**取消**（Cancel）可以停下它。失败时这一行回到 **未连接**，错误码写在下面。

手机同一时间只在一台中枢的网络里。一台中枢的网络开着时，另一台中枢的 **连接** 变灰，原因写 `overlay_other_network`。中枢两种引擎都发布时，按钮旁边有一个选择框，用来选引擎；只有这一行写着 **未连接** 时才能换。

## 转发

转发是应用为一个条目在手机 `127.0.0.1` 上开的端口。应用的一个前台服务管着所有转发和所有中枢连接，切到别的应用时它们照常运行；它的通知写着 **已连接** 几台中枢。转发开着的行，后面多出 `→ 127.0.0.1:` 和端口号。

**网页** 和 **端口** 页上，行里的 **配置**（Configure）设定 **本地端口**（Local port）：**自动**（Auto）在条目自己的端口在它的协议上空闲时用它，否则从 20000 往上找一个；**指定**（Fixed）用你填的号，范围 1024～65535。同一个号可以 TCP 用一次、UDP 再用一次。条目转发着时 **配置** 变灰。

转发连不到服务时，这一行写出错误码：

| 错误码               | 含义                                                                                                |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| `connect_failed`     | 中枢或那台机器连不上服务，原因是三者之一：`refused`（端口上没有程序监听）、`timeout`、`unreachable` |
| `agent_offline`      | 提供这个条目的机器现在没有连到中枢                                                                  |
| `port_not_published` | 那台机器现在没有发布这个端口                                                                        |
| `connect_limit`      | 这台手机经中枢开着的连接已到 256 条，关掉几条再试                                                   |
| `permission_denied`  | 中枢的客户端页不允许这台手机用这类条目，或不允许用那台机器                                          |
| `service_unknown`    | 中枢已不再发布这个条目                                                                              |

## 网页

**网页** 页列出各个中枢发布的网址：Gitea、VS Code、code-server、CloudCLI，以及中枢 **服务** 页上声明的网址。

在一行上选 **打开**（Open）。应用为这个条目建好转发，在手机浏览器里打开 `127.0.0.1` 上的页面。VS Code、code-server 和 CloudCLI 的条目，每按一次 **打开** 都向中枢取一个新令牌。**断开** 关掉转发。

## 端口

**端口** 页列出中枢发布的每个端口，写着那台机器的地址和端口号，供参考。

1. 在条目上选 **连接**（Connect）。这一行后面多出 `→ 127.0.0.1:` 和本地端口，按钮变成 **断开**。
1. 选 **复制**（Copy）复制这个回环地址，粘进手机上要用这个端口的应用。

UDP 条目写成 `host:port/udp`，连接后写 `→ 127.0.0.1:` 加本地端口和 `/udp`；**复制** 复制的地址不带 `/udp`。手机上的应用把数据报发到这个本地地址，回复也回到它那里。手动声明的 UDP 端口不显示健康状态，**连接** 一直可用。

应用发出的一切都走同一条到中枢的 TCP 连接。所以丢一个包，这条连接上的每条流都要等它重发，UDP 的流也一样。经中枢转发的 UDP 端口，适合一问一答、量不大的流量：DNS、校时、设备发现、小型游戏服务器。语音、视频和快节奏的游戏要有一条直达那台机器的路，这条路由你在虚拟网自己的控制台（NetBird 或 EasyTier 的）里设成子网路由。

## AI

**AI** 页上，每个运行 AI 网关的中枢占一行。选 **连接**，网关就转发到手机上；**断开** 旁边的 **复制** 复制它的回环地址。这一行下面是 **此客户端的密钥**（This client's key），藏在眼睛按钮后面，带一个 **复制**。

把地址和密钥填进手机上支持 OpenAI 兼容接口的应用。这一行下面写着 **只有这个客户端开着时，工具才连得到网关。** 意思是应用开着这个转发时，回环地址才连得上。 中枢打不开这台手机的密钥时，这一行写出 `vault_locked`。

## 文件

**文件** 页把中枢发布的每个共享，变成 Android “文件”应用里的一个位置。应用经中枢连到共享，所以只要中枢那一行写着 **已连接**，共享就打得开。还没存密码的一行，带 **未存密码**（Password not saved）标记。

1. 在 **文件** 页的共享上，选 **在“文件”中打开**（Open in Files）。
1. 选或填 **共享用户名**（Share username），再填 **共享密码**（Share password）。
1. 保持勾选 **记住**（Remember），密码存进 Android Keystore。不勾选，应用只在这次运行期间记着它。
1. 选 **连接**（Connect）。应用先用这组登录信息试连共享，成功后在“文件”里打开它。

![“文件”应用里作为一个位置的共享](/guide/zh/app_files_provider.webp)

在“文件”里，这个位置以共享名命名，下面一行写着中枢和机器。你可以在里面打开、写入、新建和删除文件，视频边读边放。没存密码的共享打不开，“文件”里会提示先到应用的文件页输入密码。主机没有应答时，返回 `share_unreachable`。行上的 **忘掉密码**（Forget password）按一次变成 **再按一次以忘掉**，再按才删掉存着的密码。

## 终端

**终端** 页在受管机器上开一个 shell。中枢的客户端页要允许这台手机打开终端。

1. 在上方的机器标签里选中一台。绿色圆点表示机器在线。
1. 选 **新终端**（New terminal）。

![带按键行的终端](/guide/zh/app_terminal.webp)

shell 在一个标签页里打开，标签名是机器名加一个序号。键盘上方一行补上手机键盘缺的键：**Esc**、**Tab**、**Ctrl**、**Shift**、**Alt** 和四个方向键。修饰键按下后一直亮着，作用在你敲的下一个键上。在 shell 上长按，弹出 **复制**、**粘贴** 和 **清屏**。**清屏** 先发 Ctrl+C 再清空屏幕；shell 的输出安静半秒之前，终端里写 **清屏中…**。

shell 下面的 **持久**（Persistent）开关打开后，手机不在时机器仍保留这个会话。应用再次启动时，持久标签页会回来，写着 **已断开，正在等待中枢**。它的 **×** 按一次变成 **再按一次结束**，再按一次，机器上的 shell 才结束。面板里同样的会话见[终端](../agent/terminals.md)。

## 远程桌面

**远程桌面** 页打开受管机器用 `sudo nagent rdp start` 共享出来的桌面。

1. 可选：在条目上选 **配置**，选好 **编码**（Codec）和 **画质**（Quality），再选 **保存**。
1. 选 **连接**。查看器占满整个屏幕。

画面右上角一直有三个圆按钮：第一个弹出键盘；第二个显示按键条，上面有 Esc、Tab、Ctrl、Shift、Alt、Win、**粘贴** 和方向键；第三个结束会话。键盘挡住的那部分画面，用两指拖动和缩放去看。

## 设置

在 **设置** 页上选 **语言**（Language）和 **主题**（Theme），再选 **保存**（Save）。**关于**（About）里有应用版本、AGPL-3.0 许可，以及应用携带的核心。
