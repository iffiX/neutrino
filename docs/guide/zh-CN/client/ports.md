# 端口

**端口**（Ports）面板把某个 hub 提供的一个端口转到本机回环地址。本机的任何程序连 `127.0.0.1` 上的这个端口，就等于连上了那台机器上的服务。断开在同一个按钮上。

## 条目从哪来

条目按 hub 排列，来自受管机器上容器的主机端口，以及 hub 服务页里手动声明的 TCP 端口。每条显示名称、主机和端口号，下面一行写着 hub、机器和模块，例如 **由 Neutrino:Argon:whoami:latest 提供**：容器在模块处写镜像名，手动声明的端口写它自己的名字。面板空着时写 **没有提供端口**。

## 连接

![端口转发](/guide/zh/client_port_forwarding.webp)

1. 在条目上点 **连接**（Connect）。

客户端在本机监听 `127.0.0.1:<port>`，其中 `<port>` 是条目自己的端口号，然后把连接经 hub 转到那台机器。本机这个端口已经有别的程序或者另一个 hub 的转发占着时，客户端换一个空闲端口，行里写出实际监听的地址。

终端里同一件事是 `nclient service port forward <ref>`，`--local-port` 指定本机端口。`--hub` 取那个 hub 的名字，只加入了一个 hub 时可以省略；`<ref>` 是 `nclient service list` 里条目在那个 hub 下的编号，或者条目的 id。

## 断开

点 **断开**（Disconnect），或者运行 `nclient service port unforward <ref>`，监听关闭。离开一个 hub 时，它发布的转发全部关闭。转发以你的账户在本机回环地址上监听，这台电脑上的其他账户和程序同样能连它，直到你断开或退出客户端。
