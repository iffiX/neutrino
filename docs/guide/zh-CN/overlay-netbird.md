# 用 NetBird 组网

NetBird 借别人的管理面，在公网上给你组一张私网。中枢作为一个节点加入，把家里的网段通告出去，人在外面就能按局域网地址访问家里的机器。

同一时间只有一张虚拟网，选了 NetBird，这台机器就从 EasyTier 上下来了，反过来也一样。NetBird 的管理面是 NetBird 的，不是你的，中枢连不上它就加入不了；想要一张完全没有管理面的网，请看[《用 EasyTier 组网》](./overlay-easytier.md)。局域网路由只在有接口处于 `lan` 角色时才存在，服务器形态的中枢一个都没有，那一栏本来就是空的。这台机器是否在虚拟网上应答，在「网络」页的「开放范围」里定，不在这一页。NetBird 的状态还是留在厂商自己的 `/var/lib/netbird` 里，中枢不给它搬家。

## 开始之前

- 一个 NetBird 账号，以及一个开着控制台的浏览器。这一页上有一个「打开控制台」按钮。
- 中枢能连上管理面。连不上时，状态标记是「管理面不可达」，解法在代理页。
- 这台机器当前在哪张虚拟网上。切换过去会把另一张停掉。

![虚拟网页上的三选一](/guide/zh/overlay_chooser.webp)

## 选 NetBird

**1. 打开「虚拟网」页。**

预期：最上面是「组网方式」，三个选项，无、NetBird、EasyTier，各带一句说明。NetBird 那句是「借 NetBird 的管理面，在公网上组一张私网。」

**2. 选中 NetBird，点「应用组网方式」。**

预期：提示是「切换这台机器所在的虚拟网。」；另一个引擎正在跑时，确认框里会写「{title} 会停止，从外面进入这台机器的通路将关闭。」应用之后没装的会装上，chooser 下面那一段换成 NetBird 自己的。

引擎没装时这一段写「NetBird 尚未安装。在上面应用组网方式即可装上。」，装了还没起来时写「NetBird 还没有运行。」

## 用 setup key 加入

页面上按顺序给了三步，照着做：

1. 在控制台里打开 Networks，点击 Add Network。
2. 在新建的网络里，于 Routing Peers 下点击 Add，选择 Install NetBird。
3. 复制它显示的 setup key，粘贴到下面。

**把 setup key 粘进来，管理面地址留空就是用 netbird.io，点「加入」。**

预期：按钮变成「加入中…」，随后状态标记变成「已连接」，下面的「这台网关在虚拟网中的身份」显示出虚拟网地址、名称和管理面；地址还没发下来时那里写「分配中…」。

![填 setup key 的加入表单](/guide/zh/overlay_netbird_join.webp)

![加入之后的身份与状态](/guide/zh/overlay_netbird_connected.webp)

::: warning
加入这一步要中枢直接连上 NetBird 的管理面。被墙挡住时它连不上，标记会停在「管理面不可达」，这一页上其它操作都不会有反应。

在代理页打开「让这台网关自己的流量也走代理」，等出口通了再回来点一次「加入」。

:::

## 通告局域网路由

**1. 看「局域网路由」里列出的网段，每一条旁边有「复制」。**

预期：处于 `lan` 角色的接口，一个网段一行。一个都没有时这一栏写「没有接口处于 LAN 角色。」

**2. 在控制台的 Networks 里，把每个网段加成这张网络的一个 Resource，再给它配一条访问控制策略。**

预期：外面的节点可以直接用局域网地址访问家里那台机器，而不是只能连到中枢自己。

## 节点表

**看「节点」这一栏。**

预期：一个节点一行，带名称、虚拟网地址、最近一次握手「{duration}前」，有丢包时还带「丢包 {share}%」。一个节点都没有时写「还没有节点。在另一台设备上用 NetBird 应用登录。」

![节点表](/guide/zh/overlay_netbird_peers.webp)

## 重新注册

**在「这台网关在虚拟网中的身份」里点「重新注册」，粘一把新的 setup key，确认。**

预期：确认框里写「重新注册会让这台网关在网络上换一个新身份。之后请在控制台里删掉旧的节点条目。」

旧的那条节点记录会一直留在控制台里，直到你自己去删掉它。
