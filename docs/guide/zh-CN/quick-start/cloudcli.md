# 在手机上接着家里的 AI 会话

手机上看和回家里电脑上的 Claude Code 会话，靠的是 CloudCLI，一个浏览器里的会话网页。这一页在面板里给你在电脑上的账户开一个 CloudCLI，再在手机上打开它。会话用你账户自己的 Claude Code 登录；要改走中枢的 AI 网关，见[AI 工具共用中枢的网关](./ai_gateway.md)。

你要先做完[第零步](../quick-start.md)，电脑上你自己的账户里也要装着 Claude Code。第零步装中枢时，这台电脑上也装好了被控端，所以面板的机器列表里有它。

## 开一个 CloudCLI

1. 在面板侧栏打开 **模块**。
1. 在 **选择机器** 里选你的电脑。
1. 在 **模块配置** 里选 **CloudCLI** 标签。没有这个标签时，用标签行末尾的 **+** 加上它。
1. 选择 **安装**。
1. 选择 **配置**。
1. 在 **实例** 下选择 **添加实例**。
1. 在 **账户** 里填你在电脑上的账户名，就是终端里 `whoami` 打印的名字；Windows 上取反斜杠后面那一段。
1. 选择 **应用 CloudCLI**。

电脑是 Windows 时，应用之前还要选这个账户的登录信息，那一栏的标题是账户名加 **的 Windows 登录**。登录信息先存在[凭据](../hub/credentials.md)页。

应用时，电脑为这个账户下载 Node 和 npm 包，实例一行读 **安装中**，要等几分钟。实例一行读 **运行中** 时，CloudCLI 就开好了。

![CloudCLI 标签，一个实例在运行](/guide/zh/cloudcli_panel.webp)

装不上时，见故障排查的[模块页上的错误](../reference/troubleshooting.md#模块页上的错误)。

## 在手机上打开

1. 在手机上打开 **微子**，进入 **网页** 页。
1. 在 **CloudCLI** 加你账户名的那一行，选择 **打开**。

   ![手机网页页上的 CloudCLI 一行](/guide/zh/app_web_cloudcli.webp)

手机浏览器打开 CloudCLI，已经登录，列出电脑上这个账户的 Claude Code 会话，你在终端里用过的会话也在里面。<!-- 待核: 终端里还开着的会话，在手机上接着回话时两边各显示什么，没核到。 -->选一个会话，就能看它的记录，在下面的输入框里接着回话。

![手机浏览器里的 CloudCLI 会话](/guide/zh/app_cloudcli_session.webp)

## 在外面再打开一次

1. 关掉手机的 Wi-Fi。
1. 在 **网页** 页的同一行，再选择一次 **打开**。

同一个会话页面经 EasyTier 打开。打不开时，见故障排查的[客户端的某一页连不到服务](../reference/troubleshooting.md#客户端的某一页连不到服务)。
