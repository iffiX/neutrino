# Terminals

A root shell on any online managed machine is one pick and one button on the **Terminals** page.

![The Terminals page with a shell open on a machine](/guide/en/terminals.webp)

1. Under **Which machine**, pick a machine that is online.
1. Select **New terminal**. A tab opens under **Shells** with a root shell on that machine.

Keystrokes go straight to the machine, Escape included, and the × on a tab closes that shell. A tab survives a visit to another panel page and comes back as you left it. A tab that reads **This session closed** belongs to a machine that stopped answering. The drawer of a device on [the Devices page](./devices.md) has a **Terminal** button that opens the same shell.
