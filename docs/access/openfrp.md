# OpenFrp

OpenFrp 是第三方隧道服务。中枢运行 frpc 连接它的节点，节点把一个公网端口转发到中枢的连接端口。设备和中枢之间的内容已加密，节点无法读取。

| -------------- | ------------------------------- |
| 带宽           | 12 Mb                           |
| 免费服务器     | 高峰期常超载                    |
| 读取日期       | 2026-10-30，以 OpenFrp 官网为准 |

## 注册账号

1. 打开 [OpenFrp](https://www.openfrp.net/)，注册一个账号。

   <div class="pic-holder">图：OpenFrp 的注册页</div>

1. 在网站上完成实人验证。

   <div class="pic-holder">图：OpenFrp 的实人验证页</div>

## 在面板上登录

1. 在面板左侧栏点 **外部访问**，打开 **OpenFrp** 卡片的开关，再按 **应用外部访问**。下面会出现 **状态**，显示 **未登录**。

   ![状态一节显示未登录](/guide/zh/access_openfrp_01_status.webp)

1. 在 **账户** 一节按 **登录**，浏览器会打开一个新标签页。**账户** 下面一直显示 **使用 OpenFrp OPENAPI** 和 **此项目由社区开发，OpenFrp 官方不负责除节点问题以外的技术支持** 两行文字，这是 OpenFrp 的条款要求。

   ![账户一节，登录按钮标红](/guide/zh/access_openfrp_02_login.webp)

1. 在标签页里登录 OpenFrp，并在 5 分钟内确认。这时面板显示 **到 OpenFrp 的页面上确认登录。** 如果标签页已关闭，按 **重新打开登录页**。

   <div class="pic-holder">图：OpenFrp 的确认页，账户名打码</div>

1. 成功后，**登录** 变成 **退出登录**，状态变成 **已启用，未连接**。

   <div class="pic-holder">图：账户一节，退出登录按钮</div>

登录最多保持 30 天。过期后，面板显示 **登录已过期。隧道照常运行，要换隧道得重新登录。**

## 创建隧道

1. 确认连接端口。它在面板 **网络** 页的 **端口** 一节，默认是 8443。

1. 登录后，面板会显示 **隧道** 一节。列表为空时，按 **打开 OpenFrp 控制台**。

   <div class="pic-holder">图：隧道一节，列表空着</div>

1. 在 OpenFrp 的控制台新建隧道。类型选 TCP，本地端口填连接端口，本地 IP 保持默认。然后关闭自动 TLS，选择一个节点，再保存。

   <div class="pic-holder">图：OpenFrp 新建隧道的表单</div>

1. 回到面板，在 **隧道** 一节按 **刷新**。列表只显示可用的隧道，每行显示隧道名、节点、**地区** 和 **延迟**。

   <div class="pic-holder">图：隧道列表，有一条隧道</div>

1. 选中这条隧道，再按 **应用隧道**。

   <div class="pic-holder">图：选中隧道，应用隧道按钮</div>

1. 等待状态变成 **已连上**，一分钟内会有结果。

   <div class="pic-holder">图：状态显示已连上</div>

各状态的含义如下。

| 状态                     | 含义                                              |
| ------------------------ | ------------------------------------------------- |
| **未登录**               | 你还没有登录 OpenFrp                              |
| **保险库已锁定**         | 中枢无法读取登录信息                              |
| **已启用，未连接**       | 你已登录，还没有选择隧道                          |
| **连接中**               | 第一次检查还没有完成，一分钟内有结果              |
| **已连上**               | 从外部网络能连接到这台中枢                        |
| **本机端口已有程序在用** | 另一个程序占用了中枢为 frpc 预留的本机端口        |
| **取不到隧道配置**       | 隧道已删除、登录已失效，或 OpenFrp 没有返回配置   |
| **节点拒绝了隧道**       | 公网端口已有其他隧道在用，或隧道已在 OpenFrp 关闭 |
| **对外端口不通**         | 隧道在运行，但从外部网络无法连接                  |
| **节点登录失败**         | 节点不接受这个账户                                |
| **连不上节点**           | 无法连接节点，或连接已断开                        |

## 验证连接

已加入的设备会自动获取这个地址，你不用重新加入。关闭手机的 Wi-Fi，用移动网络打开客户端。如果中枢这一行显示 **已连接 · OpenFrp**，就说明配置成功。

![中枢那一行显示已连接和 OpenFrp](/guide/zh/access_openfrp_09_client_connected.webp)

## 后续维护

- **更换隧道或关闭卡片：** 通过这条隧道连接的客户端会断开。如果还打开了其他外部访问，客户端会自动重新连接。
- **修改连接端口：** 修改 **网络** 页的连接端口后，到 OpenFrp 控制台修改本地端口，再按 **刷新** 和 **应用隧道**。
- **暂停使用：** 关闭卡片的 **启用**，账户和隧道都会保留。
- **不再使用这个账户：** 按 **退出登录**。
