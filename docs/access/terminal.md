# 终端命令

你可以在命令行和脚本里打开其他系统的终端并运行命令，结果和在那个系统上运行时相同。

这些命令只在电脑客户端上提供。开始之前，确认满足下面的条件。

- 客户端正在运行。
- 你已经给这台电脑打开 **终端** 权限。
- 那个系统的 **终端** 标签已经启用账户。

如果要启用账户，打开那个系统的页面，选择 **终端** 标签，勾选账户，再按 **应用终端设置**。账户后面显示 **可用** 时，你就可以使用终端命令。

![终端标签，勾选账户后应用终端设置按钮标红](/guide/zh/access_terminal_05_tick.webp)

## 运行一条命令

`nclient terminal exec` 运行完命令后立即返回。把 `my-computer` 换成你的系统在面板上的名称，`--` 后面是要运行的命令。

```bash
nclient terminal exec my-computer -- uname -sr
```

输出和退出码都原样返回，所以脚本可以判断命令是否成功。

```text
Linux 5.15.0-198-generic
```

退出码 125 表示拒绝运行，比如那个系统没有启用账户。126 表示找不到这个系统，这时命令会列出可用的系统。其他退出码都来自运行的命令。

`exec` 不占用会话，其他窗口看不到它的输入。

## 打开一个终端

下面的命令打开一个新终端，显示在你当前的窗口里。退出 shell 后，终端结束。

```bash
nclient terminal open my-computer
```

如果要查看有哪些会话，运行下面的命令。

```bash
nclient terminal list my-computer
```

```text
会话        账户   开了多久  持久  共享  在看
91c99b07  lab  5s    否   否   1
```

如果要重新连接一个仍在运行的会话，运行下面的命令。`<会话>` 填写列表里的前几位，如果匹配到两个，命令会列出候选。按 `Ctrl+]` 离开后，会话继续运行。

```bash
nclient terminal attach my-computer <会话>
```

如果要在关闭窗口后保留一个会话，运行下面的命令。

```bash
nclient terminal set my-computer <会话> --persist on
```

## 其他选项

| 选项                                    | 作用                                                     |
| --------------------------------------- | -------------------------------------------------------- |
| `--account <账户>`                      | 用 `open`、`exec` 时选择账户，不写时使用第一个启用的账户 |
| `--tty`                                 | 给 `exec` 分配一个终端，`top`、`vim` 这类全屏程序需要它  |
| `--hub <中枢>`                          | 两台中枢有同名系统时，指定其中一台                       |
| `terminal set <系统> <会话> --share on` | 让有权限的客户端都能连接这个会话                         |
| `terminal stop <系统> <会话>`           | 结束会话和里面的程序                                     |

每一级命令都可以加 `-h` 查看帮助，全部命令见 [nclient 命令](/reference/nclient)。
