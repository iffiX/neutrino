# 外部访问：选择一种方式

外部访问是你不在同一个局域网时连接中枢的方式。你开启其中一种即可。

手机和电脑连接同一个 Wi-Fi 或路由器时，不需要开启外部访问。你不在这个网络时，按你已有的条件选择一种：

| 你已有的条件                       | 开启的方式                                                   |
| ---------------------------------- | ------------------------------------------------------------ |
| 宽带有公网地址                     | [直连](/access/direct)                                       |
| 一台自己的 VPS                     | [SSH 中继](/access/vps)                                      |
| 都没有，要把链接发给外部网络的访客 | [SakuraFrp](/access/sakurafrp) 或 [OpenFrp](/access/openfrp) |
| 都没有，只有自己使用               | [EasyTier](/access/easytier) 或 [NetBird](/access/netbird)   |

SakuraFrp、OpenFrp、EasyTier 和 NetBird 都有免费额度，可以同时开启。其中只有 SakuraFrp 的实名认证要 1 元。

如果你要把分享链接发给对方，先开启外部访问再生成链接，因为已生成的链接不会使用后来开启的线路。

## 各种方式的要求

| 方式                           | 要准备的东西                                      | 外部网络的访客能否打开分享链接 |
| ------------------------------ | ------------------------------------------------- | ------------------------------ |
| 局域网                         | 不需要准备                                        | 不能                           |
| [NetBird](/access/netbird)     | 一个账号，一个可以重复使用的 setup key            | 不能                           |
| [EasyTier](/access/easytier)   | 一个控制台账号；或者不使用账号，自己填写引导节点  | 不能                           |
| [SSH 中继](/access/vps)        | 一台你自己的 VPS，并且你能修改它的 SSH 设置       | 能                             |
| [直连](/access/direct)         | 公网地址，路由器已设置端口转发                    | 能，你要填写 **公网地址**      |
| [SakuraFrp](/access/sakurafrp) | 一个账号，实名认证要 1 元，在它的网站创建一条隧道 | 能                             |
| [OpenFrp](/access/openfrp)     | 一个账号，实人验证，在它的网站创建一条隧道        | 能                             |

iPhone 的 App 没有虚拟网那一行。如果你使用 EasyTier 或 NetBird，要在手机上安装它们自己的 App。

## 开启外部访问

六种方式的开启方法相同，下面以直连为例。

1. 在面板左侧栏点 **外部访问**。页面上有六张卡片，每张右上角有一个 **启用** 开关，这时全部关闭。

   ![外部访问页，左侧栏的外部访问标红](/guide/zh/access_ways_in_01_page.webp "点 外部访问")
   ![组网方式一节的六张卡片](/guide/zh/access_ways_in_02_cards.webp "六张卡片")

1. 打开你选择的卡片的开关，再按 **应用外部访问**，改动这时才生效。

   ![直连卡片的开关标红](/guide/zh/access_direct_01_switch.webp "打开开关")
   ![开关已打开，应用外部访问按钮标红](/guide/zh/access_direct_02_apply.webp "按 应用外部访问")

1. 卡片会显示 **使用中**，下面出现它的设置。然后按这种方式自己的页面继续填写，上面的表里有每种方式的链接。

如果卡片显示 **这个系统没有对应的版本**，这张卡片无法打开。

如果你要查看已打开卡片的设置，按卡片本身。如果你要关闭一种方式，关闭它的 **启用** 开关，再按 **应用外部访问**，已填写的设置都会保留。这时黄色提示说明这种方式会停止，以及有几台在线客户端正在使用它。

![关闭直连后的黄色提示，应用外部访问按钮标红](/guide/zh/access_ways_in_03_leave.webp)

## 同时开启多种方式

你可以同时开启多种方式。连接时和网络变化时，客户端同时尝试每一条线路，使用最先连接成功的那一条。一条线路不通时，客户端可以使用其他线路。

中枢可以同时开启 EasyTier 和 NetBird，你在客户端的虚拟网那一行选择一个。

智能路由只对客户端生效。一个分享链接只带一个地址，这个地址在生成时确定。如果你要让分享使用后来开启的线路，重新分享一次，见[应用分享](/share/web_share)。

## 免费额度

免费账号的限制如下。

| 服务       | 带宽和流量                     | 数量                      | 其他限制                           |
| ---------- | ------------------------------ | ------------------------- | ---------------------------------- |
| SakuraFrp  | 10 Mibps，每月 5 GiB           | 2 条隧道                  | 实名认证要 1 元                    |
| OpenFrp    | 12 Mb                          | 以官网为准                | 要实人验证，免费服务器高峰期常超载 |
| EasyTier   | 官方控制台每月 1 GB 中转流量   | 最多 20 台设备            | 提供全部功能                       |
| NetBird 云 | 以官网为准                     | 最多 5 个用户、100 台设备 | 以官网为准                         |
| 读取日期   | 2026-10-30，以各服务的官网为准 |                           |                                    |

中枢只使用一条隧道。你使用哪种服务，就受这种服务的额度限制。如果你要把链接发给外部网络的访客，又没有公网地址和 VPS，至少要开启 SakuraFrp 或 OpenFrp。
