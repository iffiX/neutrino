# SakuraFrp

SakuraFrp 是第三方隧道服务。中枢运行 frpc 连接它的节点，节点把一个公网端口转发到中枢的连接端口。设备和中枢之间的内容已加密，节点无法读取。

<Facts systems="Linux,Windows,macOS" editions="国际版,国内版" since="0.6.0" />

| 免费账号的额度 | 数值                              |
| -------------- | --------------------------------- |
| 隧道           | 2 条，中枢使用 1 条               |
| 带宽           | 10 Mibps                          |
| 流量           | 每月 5 GiB                        |
| 读取日期       | 2026-10-30，以 SakuraFrp 官网为准 |

## 注册账号

1. 打开 [SakuraFrp](https://www.natfrp.com/)，注册一个账号。

   <div class="pic-holder">图：SakuraFrp 的注册页</div>

1. 在网站上完成实名认证，费用是 1 元。

   <div class="pic-holder">图：SakuraFrp 的实名认证页</div>

1. 在网站上复制你的 **访问密钥**。

   <div class="pic-holder">图：网站上的访问密钥，已打码</div>

## 保存访问密钥

1. 在面板左侧栏点 **外部访问**，打开 **SakuraFrp** 卡片的开关，再按 **应用外部访问**。下面会出现 **状态**，显示 **未登录**。

   ![状态一节显示未登录](/guide/zh/access_sakurafrp_01_status.webp)

1. 在 **账户** 一节，把密钥粘贴到 **访问密钥**，再按 **保存访问密钥**。中枢会向 SakuraFrp 核对密钥，核对通过后状态变成 **已启用，未连接**。

   ![访问密钥输入框标红](/guide/zh/access_sakurafrp_02_key.webp "粘贴密钥")
   ![密钥已填写，保存访问密钥按钮标红](/guide/zh/access_sakurafrp_03_save.webp "按 保存访问密钥")

## 创建隧道

1. 确认连接端口。它在面板 **网络** 页的 **端口** 一节，默认是 8443。

1. 保存密钥后，面板会显示 **隧道** 一节。列表为空时，按 **打开 SakuraFrp 控制台**。

   <div class="pic-holder">图：隧道一节，列表空着</div>

1. 在 SakuraFrp 的控制台新建隧道。类型选 TCP，本地端口填连接端口，本地 IP 保持默认。然后选择一个没有开启强制访问认证的节点，再保存。

   <div class="pic-holder">图：SakuraFrp 新建隧道的表单</div>

1. 回到面板，在 **隧道** 一节按 **刷新**。列表只显示可用的隧道，每行显示隧道名、节点、**地区** 和 **延迟**。

   <div class="pic-holder">图：隧道列表，有一条隧道</div>

1. 选中这条隧道，再按 **应用隧道**。

   <div class="pic-holder">图：选中隧道，应用隧道按钮</div>

1. 等待状态变成 **已连上**，一分钟内会有结果。

   <div class="pic-holder">图：状态显示已连上</div>

各状态的含义如下。

| 状态                     | 含义                                                |
| ------------------------ | --------------------------------------------------- |
| **未登录**               | 中枢没有保存访问密钥                                |
| **保险库已锁定**         | 中枢无法读取密钥                                    |
| **已启用，未连接**       | 密钥已保存，还没有选择隧道                          |
| **连接中**               | 第一次检查还没有完成，一分钟内有结果                |
| **已连上**               | 从外部网络能连接到这台中枢                          |
| **本机端口已有程序在用** | 另一个程序占用了中枢为 frpc 预留的本机端口          |
| **取不到隧道配置**       | 隧道已删除、密钥已失效，或 SakuraFrp 没有返回配置   |
| **节点拒绝了隧道**       | 公网端口已有其他隧道在用，或隧道已在 SakuraFrp 关闭 |
| **对外端口不通**         | 隧道在运行，但从外部网络无法连接                    |
| **节点登录失败**         | 节点不接受这个账户                                  |
| **连不上节点**           | 无法连接节点，或连接已断开                          |

## 验证连接

已加入的设备会自动获取这个地址，你不用重新加入。关闭手机的 Wi-Fi，用移动网络打开客户端。如果中枢这一行显示 **已连接 · SakuraFrp**，就说明配置成功。

![中枢那一行显示已连接和 SakuraFrp](/guide/zh/access_sakurafrp_09_client_connected.webp)

## 后续维护

- **更换隧道或关闭卡片：** 通过这条隧道连接的客户端会断开。如果还打开了其他外部访问，客户端会自动重新连接。
- **修改连接端口：** 改了 **网络** 页的连接端口后，到 SakuraFrp 控制台修改本地端口，再按 **刷新** 和 **应用隧道**。
- **暂停使用：** 关闭卡片的 **启用**，账户和隧道都会保留。
- **不再使用这个账户：** 按 **忘记访问密钥**。
