# SSH

SSH is the standard way to sign in to a computer remotely. Every system includes an SSH server, and the hub sets up its keys for you.

<Facts systems="Linux,Windows,macOS" editions="国际版,国内版" since="0.6.0" />

The SSH server of Neutrino Hub and the system's sshd run independently of each other. The SSH server accepts only keys the hub generates, and it rejects passwords.

## Supported systems

| System  | Architecture         | First Neutrino Hub version |
| ------- | -------------------- | -------------------------- |
| Linux   | amd64, arm64         | 0.6.0                      |
| Windows | amd64                | 0.6.0                      |
| macOS   | Apple silicon, Intel | 0.6.0                      |

## Install

The SSH server is already installed, so you only enable an account:

1. Open the panel in a browser, sign in, and select the system to connect to in the lower half of the sidebar. Check that **Available accounts** lists your account. If it does not, add it first with the steps in [Add an account](/en/deploy/on_a_machine#add-an-account).
1. In the list of the **Module configuration** area, select **SSH server**. This tab is always present, so you do not add it.

   ![The module list with the SSH server row boxed in red](/guide/en/deploy_ssh_01_tab.webp)

1. The tab shows **stopped**. Under **Enabled accounts**, select your account, then select **Apply SSH server**.

   ![The Enabled accounts field with the lab row boxed in red](/guide/en/deploy_ssh_02_tick_account.webp "Select lab")
   ![lab selected, with the Apply SSH server button boxed in red](/guide/en/deploy_ssh_03_apply.webp "Select Apply SSH server")

1. The tab shows **running**, and the account's row also shows **running** with this account's host key fingerprint. You can connect now.

   ![The lab row showing running and the host key](/guide/en/deploy_ssh_04_applied.webp)

If the Windows account has never signed in, you cannot enable it here. Sign in as this account on the computer one time, then select **Apply SSH server** again.

## Use

Only the computer client can use SSH, and on a phone you can use [Terminal](/en/deploy/terminal). Before you start, add your computer to the hub, as [Join the hub](/en/access/join) describes, and keep the client running.

In a terminal, run the following command, with `my-computer` replaced by your system's name:

```bash
nclient ssh open my-computer
```

To run a single command, add `--` and the command after it:

```bash
nclient ssh open my-computer -- uname -sr
```

To let tools such as ssh, scp, git and VS Code connect directly by the name `my-computer.nt`, run the following command one time:

```bash
nclient ssh config install
```

```text
added Include ~/.ssh/neutrino_config to ~/.ssh/config
```

For how these tools connect, see [SSH connections](/en/access/ssh).

## Share

SSH cannot generate a link with [App share](/en/share/web_share), because App share works only for apps with a web page.

To let someone else connect, have them install the computer client and join the hub. Then turn on the **SSH** permission for their device, as [Clients](/en/hub/clients) describes.

## Risks and limits

The person connecting can do anything this account can do, so give the **SSH** permission only to devices you trust.

Each enabled account has its own host key, which the client fetches automatically. Deselecting an account deletes its host key, and selecting it again generates a new host key.

## Settings

Apart from selecting accounts, the following settings can stay at their defaults:

| Setting               | Where                                                        | Purpose                                                                           |
| --------------------- | ------------------------------------------------------------ | --------------------------------------------------------------------------------- |
| **Enabled accounts**  | **SSH server** tab                                           | Each selected account runs one instance; the first is the default                 |
| **Shell**             | Account form in **Available accounts**                       | The shell used after signing in, shared with Terminal                             |
| **SSH key · account** | **Generated by the hub** section of the **Credentials** page | Select **Rotate** to change the key; the client fetches the new key automatically |

## Uninstall

The SSH server cannot be uninstalled, and it has no data to keep. If you no longer use it, deselect the accounts, then select **Apply SSH server**.

If you cannot connect, see [Troubleshooting](/en/reference/troubleshooting).
