# Panel menu map

The sidebar on the left of the panel has two groups. The **Hub** group holds fixed pages, and the **Agents** group holds one entry for each system that joined the hub.

## Agents group

Each system that joined the hub has one entry, which shows its name. Select it to open that system's page, where you install apps. The steps are in [Install apps on a system](/en/deploy/on_a_machine).

![A system's page, with my-computer marked red in the sidebar](/guide/en/reference_panel_menu_11_machine.webp)

From top to bottom, the page has these parts: **Monitor**, **Modules** and **The agent**.

| Part          | Content                                                                        |
| ------------- | ------------------------------------------------------------------------------ |
| **Monitor**   | Uptime, load, disks, temperature, CPU and memory charts, and the process table |
| **Modules**   | **Available accounts** and **Module configuration**                            |
| **The agent** | Version, **Update agent** and **Reinstall**                                    |

## Narrow screens and old names

On narrow and portrait screens, such as a phone's browser, the sidebar becomes a row of icons at the bottom. The row holds only the pages of the **Hub** group. To open a system's page, select the **Agents** icon first.

![The panel at phone width, with the bottom row of icons marked red](/guide/en/reference_panel_menu_12_phone.webp)

For readers who used 0.5, the **Devices** page is now **Agents**. The **Terminals**, **Files** and **Modules** pages are removed, and their content is on each system's page.

**Sign out** at the bottom of the sidebar is a button that signs you out, and it opens no page.
