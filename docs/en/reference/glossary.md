# Glossary

Every term that the manual and the panel use is in the following tables, with its Chinese name, the name the English interface shows, and its meaning.

## Basic terms

| Chinese  | English interface          | Meaning                                                                                         |
| -------- | -------------------------- | ----------------------------------------------------------------------------------------------- |
| 中枢     | Hub                        | The main program, installed on a computer that stays on                                         |
| 面板     | Panel                      | The hub's web management interface, where you install apps and manage devices                   |
| 客户端   | Clients                    | The program on phones and laptops that opens apps                                               |
| 被控端   | Agents                     | The program on a computer that runs apps, through which the hub manages that system             |
| 模块     | Modules                    | The panel's name for apps                                                                       |
| 系统页   | machine page               | Each system's own page, where you install apps                                                  |
| 保险库   | vault                      | The encrypted file where the hub keeps keys and passwords                                       |
| 虚拟网   | Virtual network            | A private network that NetBird or EasyTier builds                                               |
| 运行账户 | Not shown in the interface | The system account that runs an app. Visitors also use this account                             |
| 智能路由 | Not shown in the interface | The client feature that tries every route at the same time and uses the first one that connects |

## Install and credentials

| Chinese    | English interface    | Meaning                                                                                                                         |
| ---------- | -------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 微子·中枢  | Neutrino Hub         | The full product name                                                                                                           |
| 设置向导   | setup wizard         | The page that opens first after you install the hub                                                                             |
| 保险库口令 | Vault passphrase     | The passphrase that opens the vault, which restoring a backup also requires                                                     |
| 凭据       | Credentials          | The SSH keys, logins and tokens kept in the vault                                                                               |
| 中枢生成的 | Generated by the hub | A section of the Credentials page with the SMB passwords, remote desktop passwords and SSH keys                                 |
| 中枢密钥   | hub key              | The key devices use to verify the hub. Its public key is in the join link. On a mismatch, the client shows **Hub key mismatch** |

## Network

| Chinese    | English interface | Meaning                                                                            |
| ---------- | ----------------- | ---------------------------------------------------------------------------------- |
| 形态、模式 | Shape, Mode       | The role of the hub's computer in the network                                      |
| 服务器     | Server            | The mode that forwards no traffic, available on all three systems                  |
| 路由器     | Router            | The mode that takes over the interfaces and provides a network, on Linux only      |
| 单臂路由   | One-arm router    | The router mode on a single network cable                                          |
| 旁路网关   | Side gateway      | The mode that forwards traffic for devices that set this computer as their gateway |
| 开放范围   | Exposure          | The setting for which subnets have hosts that can connect to the hub's own ports   |
| 连接端口   | Connection port   | The port devices use to connect to the hub, 8443 by default and changeable         |
| 代理       | Proxy             | The feature that forwards traffic to exit servers by rules                         |
| 出口服务器 | Exit nodes        | The servers the proxy forwards traffic to                                          |

## Access

| Chinese              | English interface         | Meaning                                                                                   |
| -------------------- | ------------------------- | ----------------------------------------------------------------------------------------- |
| 外部访问             | Access                    | The ways to connect to the hub from outside its LAN. The panel has six cards for them     |
| 直连                 | Direct                    | Connecting to the hub directly through a public address and port forwarding on the router |
| SSH 中继             | SSH relay                 | Connecting to the hub through a public port on a server of your own                       |
| SakuraFrp、OpenFrp   | SakuraFrp, OpenFrp        | Two third-party tunnel services that give the connection port a public address            |
| 隧道                 | Tunnel                    | A forwarding route that a provider offers                                                 |
| 控制台               | Console                   | The official web management interface of NetBird or EasyTier                              |
| setup key            | setup key                 | The join key that the NetBird console generates                                           |
| 引导节点             | Bootstrap peers           | In EasyTier manual mode, the addresses of systems already in the virtual network          |
| 子网路由、局域网路由 | Subnet routes, LAN routes | Routes through the virtual network to devices that have no agent installed                |

## Systems and apps

| Chinese       | English interface  | Meaning                                                                                    |
| ------------- | ------------------ | ------------------------------------------------------------------------------------------ |
| 可用账户      | Available accounts | The system accounts on this system that the hub can use                                    |
| 添加模块      | Add module         | The dialog on a system's page. Selecting an app there adds a tab only and installs nothing |
| 应用          | Apps               | A program published on a system. The client and the Services page both use this name       |
| 入口          | Entries            | An app's web page or port                                                                  |
| 声明应用      | Declare app        | The dialog on the Services page that adds an existing web page, port or share              |
| 运行设置      | Run settings       | The account the containers belong to, and the CPU, memory and disk of the virtual machine  |
| Podman 虚拟机 | Podman machine     | The Linux virtual machine of one account on Windows or macOS, where the containers run     |
| 主目录共享    | Home shares        | One share per account, sharing that account's home folder                                  |
| 文件夹共享    | Folder shares      | A share of any path, with a choice of the accounts that can use it                         |
| 持久          | Persistent         | The terminal session keeps running after the window closes                                 |

## Devices and sharing

| Chinese        | English interface   | Meaning                                                                                        |
| -------------- | ------------------- | ---------------------------------------------------------------------------------------------- |
| 用链接添加     | Add by link         | The button on the Agents page that generates a join link for a system                          |
| 用 SSH 添加    | Add over SSH        | The button on the Agents page with which the hub installs the agent on a Linux system over SSH |
| 新建客户端链接 | New client link     | The button on the Clients page. Each link joins one device and is valid for 30 minutes         |
| 权限           | Permissions         | What a client can use, with one switch per permission                                          |
| 默认权限       | Default permissions | The permissions of every client without permissions of its own                                 |
| 应用分享       | App shares          | The feature that shares one app with a person who has no client                                |
| 有效期         | Expires             | How long an app share lasts: 1 day, 7 days, 30 days, or until revoked                          |
| 站点           | Site                | The website of the share page, which can also be a site you deploy yourself                    |
| 撤销           | Revoke              | Ends an app share immediately                                                                  |
| 转发           | forward             | A port the client opens on its own computer that connects to an entry on a system              |
