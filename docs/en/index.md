# Neutrino Hub

Deploy apps in one click and use them anywhere.

Neutrino Hub is a panel for deploying apps plus secure routing for reaching them from outside. It installs on the Windows, macOS or Linux computer you already own.

The manual is in Chinese for now.

- [Live demo](https://neutrinohub.net/demo/)
