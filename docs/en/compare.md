# Comparison with other tools

You can pick a tool from the following table by the job you want done. If you want to install software on your own computer and use it from other devices, choose Neutrino Hub.

Neutrino Hub is open source and free. You turn on access from outside yourself, and some of the access methods are free. The hub must run on a computer that stays on.

## Differences

| Your job                                                 | Tools            | How these tools do it                                                                | How Neutrino Hub does it                                                                                  |
| -------------------------------------------------------- | ---------------- | ------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------------- |
| Manage websites and databases on a server                | 1Panel, BT Panel | They manage websites and databases on Linux servers                                  | It installs on the Windows, macOS or Linux system you already have and manages the software you work with |
| Keep media and photos at home on a dedicated file device | fnOS, Synology   | You switch to their system or buy their device, and media and photos come first      | You keep your system and buy no device                                                                    |
| Replace a computer's whole system to build a home cloud  | Cosmos, Olares   | They rely on a domain or replace the whole system, as a home cloud for many people   | It works without a domain, keeps your system, and serves the few computers of one person                  |
| Only link devices into one network                       | Tailscale        | They handle only the connection, and you install and configure the software yourself | It installs the software and connects it in the same step                                                 |
| Fix a relative's computer and see its screen             | Sunlogin, ToDesk | They offer only remote desktop, and a share covers the whole desktop                 | Remote desktop is one of its apps, and a share covers one app                                             |

For an item-by-item comparison, see the table on the [home page](/en/).
