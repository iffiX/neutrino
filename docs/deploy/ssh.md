# SSH

SSH 是远程登录电脑的通用方式。每个系统都自带 SSH 服务器，你不用自己配置密钥。

<Facts systems="Linux,Windows,macOS" editions="国际版,国内版" since="0.6.0" />

微子·中枢自带的 SSH 服务器和系统的 sshd 互不影响。它只接受中枢生成的密钥，不接受密码。

## 支持的系统

| 系统    | 架构              | 开始支持的微子·中枢版本 |
| ------- | ----------------- | ----------------------- |
| Linux   | amd64、arm64      | 0.6.0                   |
| Windows | amd64             | 0.6.0                   |
| macOS   | Apple 芯片、Intel | 0.6.0                   |

## 安装

SSH 服务器不需要单独安装，你只要启用账户。

1. 在浏览器里打开面板并登录，再到左侧栏的下半部分，点你要连接的系统。确认 **可用账户** 里有你的账户。如果没有，先按[添加账户](/deploy/on_a_machine#添加账户)的步骤添加它。
1. 在 **模块配置** 区域的列表里，点 **SSH 服务器**。这个标签一直存在，不用另外添加。

   ![模块列表，SSH 服务器这一行标红](/guide/zh/deploy_ssh_01_tab.webp)

1. 标签显示 **已停止**。在 **启用的账户** 里勾选你的账户，再按 **应用 SSH 服务器**。

   ![启用的账户一栏，lab 这一行标红](/guide/zh/deploy_ssh_02_tick_account.webp "勾选 lab")
   ![勾选了 lab，应用 SSH 服务器按钮标红](/guide/zh/deploy_ssh_03_apply.webp "按 应用 SSH 服务器")

1. 标签变成 **运行中**，账户那一行也显示 **运行中** 和这个账户的主机密钥指纹，这时你可以连接。

   ![lab 这一行显示运行中和主机密钥](/guide/zh/deploy_ssh_04_applied.webp)

如果 Windows 账户从未登录过，这里无法启用。你要先用这个账户在电脑上登录一次，再按一次 **应用 SSH 服务器**。

## 使用

只有电脑客户端能使用 SSH，手机上可以使用[终端](/deploy/terminal)。开始之前，你要先把电脑加入中枢，见[加入中枢](/access/join)，并保持客户端运行。

在终端里运行下面的命令，把 `my-computer` 换成你的系统名称。

```bash
nclient ssh open my-computer
```

如果只运行一条命令，在后面加上 `--` 和这条命令。

```bash
nclient ssh open my-computer -- uname -sr
```

如果要让 ssh、scp、git、VS Code 这些软件直接用 `my-computer.nt` 这个名称连接，先运行一次下面的命令。

```bash
nclient ssh config install
```

```text
已在 ~/.ssh/config 里加上 Include ~/.ssh/neutrino_config
```

这些软件的连接方法见 [SSH 连接](/access/ssh)。

## 分享

SSH 不能用[应用分享](/share/web_share)生成链接，应用分享只能分享带网页的应用。

如果你要让别人连接，让对方安装电脑客户端并加入中枢，再给对方的设备打开 **SSH** 权限，见[客户端](/hub/clients)。

## 注意

连接的人能做这个账户能做的一切，所以 **SSH** 权限只给你信任的设备。

每个启用的账户有自己的主机密钥，客户端会自动获取。取消勾选一个账户会删除它的主机密钥，再次勾选时会生成新的主机密钥。

## 设置

除了勾选账户，下面的设置保持默认即可。

| 设置                | 位置                              | 作用                                         |
| ------------------- | --------------------------------- | -------------------------------------------- |
| **启用的账户**      | **SSH 服务器** 标签               | 每个勾选的账户运行一个实例，第一个是默认账户 |
| **默认 shell**      | **可用账户** 的账户表单           | 登录后使用的 shell，和终端共用               |
| **SSH 密钥 · 账户** | **凭据** 页的 **中枢生成的** 一节 | 按 **轮换** 更换密钥，客户端会自动获取新密钥 |

## 卸载

SSH 服务器不能卸载，也没有要保留的数据。如果你不再使用，取消勾选账户，再按 **应用 SSH 服务器**。

如果你无法连接，查看[故障排查](/reference/troubleshooting)。
