# 和其他工具比较

你可以按要做的事，从下表选择工具。如果你要在自己的电脑上安装软件，再从其他设备使用，可以选择微子·中枢。

微子·中枢开源免费。外部访问要你自己开启，其中有免费的方式。中枢要运行在一台能一直开机的电脑上。

## 不同点

| 你要做的事                         | 工具           | 这些工具的做法                                     | 微子·中枢的做法                                               |
| ---------------------------------- | -------------- | -------------------------------------------------- | ------------------------------------------------------------- |
| 管理服务器上的网站和数据库         | 1Panel、宝塔   | 管理 Linux 服务器上的网站和数据库                  | 安装在你已有的 Windows、macOS 或 Linux 上，管理你工作用的软件 |
| 在家里保存影音和相册，专门存放文件 | 飞牛、群晖     | 更换成它们的系统或购买它们的设备，以影音和相册为主 | 不更换系统，不购买设备                                        |
| 更换整台电脑的系统，搭建家庭云     | Cosmos、Olares | 依靠域名或更换整台电脑的系统，面向多人的家庭云     | 不需要域名，不更换系统，面向一个人的几台电脑                  |
| 只把设备连成一个网络               | Tailscale      | 只负责连接，软件要你自己安装和配置                 | 安装软件和连接一起完成                                        |
| 帮家人修电脑，查看屏幕             | 向日葵、ToDesk | 只提供远程桌面，分享时只能分享整个桌面             | 远程桌面是其中一个应用，分享时只分享一个应用                  |

逐项比较见[首页](/)的对比表。
