# 微子·中枢是什么

微子·中枢是开源、自托管的应用部署面板和外部访问路由。你把它安装在自己的 Windows、macOS 或 Linux 电脑上，不需要域名，也不需要额外的服务器。

你在网页面板上把应用部署到加入中枢的系统，再从手机、另一台电脑或浏览器使用这些应用。

中枢提供一个网页面板，并监听一个连接端口，默认是 8443。每个加入中枢的系统上运行一个被控端，负责安装和运行应用。你在手机和电脑上安装客户端后，客户端的所有连接都经过这个端口，用 Noise 协议加密，再由中枢按权限转发给应用。

连接的具体过程见[工作原理](/how_it_works)，防护机制见[安全模型](/share/security)。

## 解决的问题

开发工具、论文编辑器和笔记软件通常运行在一台电脑上。要从手机继续使用，或者分享给别人，通常要配置运行环境、开放端口、购买域名和服务器，还要自己处理安全问题。

微子·中枢用一个面板完成这几件事：部署应用、用手机扫码连接、用链接分享应用。设备通过你生成的一次性链接加入，所以你不用配置账号系统或单点登录。微子·中枢不提供公共服务器，设备和访客的连接都只到你自己的中枢。

## 核心概念

| 概念     | 是什么                                                                                                                                               |
| -------- | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| 中枢     | 安装在你的电脑上的主程序。它运行面板，保管凭据，检查权限，并转发每一条连接。安装中枢的电脑也是第一个系统。                                           |
| 系统     | 加入中枢的一台电脑。系统上运行被控端，被控端主动连接中枢，所以这台电脑不用为它开放端口。                                                             |
| 应用     | 部署在系统上的软件，面板上叫模块。它可以是一键安装的应用，也可以是你声明的服务或容器。                                                               |
| 客户端   | 你用来连接中枢的程序，包括桌面客户端（Windows、macOS、Linux）和手机 App（Android、iOS）。它列出你有权限使用的应用，并在本机打开一个地址转发过去。    |
| 外部访问 | 你不在同一个局域网时连接中枢的方式，包括 NetBird、EasyTier、SSH 中继、直连、SakuraFrp 和 OpenFrp。你可以同时打开多种，客户端使用最先连接成功的一种。 |
| 应用分享 | 用链接把一个网页应用分享给别人的功能。对方用浏览器打开链接，不用安装任何软件。                                                                       |

## 职责划分

| 微子·中枢负责                        | 你负责                                               |
| ------------------------------------ | ---------------------------------------------------- |
| 下载应用并核对校验值，安装和运行应用 | 准备一台能一直开机的电脑                             |
| 加密每条连接，按权限放行             | 决定把加入链接和分享链接发给谁                       |
| 在面板上显示每个应用的状态和日志     | 记好保险库口令，定期下载备份                         |
| 自动选择最快的下载来源和连接线路     | 选择一种外部访问，准备它需要的账号、VPS 或路由器设置 |
| 分享到期或撤销时断开连接             | 管理应用自己的账号、数据和版本                       |
