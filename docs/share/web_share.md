# 应用分享

应用分享是用链接把带网页的应用分享给别人的功能。对方用浏览器打开链接就能使用你电脑上的应用，不用安装任何软件。

<Facts systems="Linux,Windows,macOS" editions="国际版,国内版" since="0.6.0" />

应用分享只能分享带网页的应用，比如 code-server、思源笔记、Gitea，或者你在容器里运行的网站。终端、文件共享、远程桌面、SSH、端口入口、AI 网关和面板都不能分享。

生成链接之前，你要先打开[直连](/access/direct)、[SakuraFrp](/access/sakurafrp)、[OpenFrp](/access/openfrp) 或 [SSH 中继](/access/vps)中的一种，让外部网络能连接中枢。如果一种都没有打开，中枢不生成链接，面板显示 **先打开一种公网可达的外部访问：直连、SakuraFrp、OpenFrp 或 SSH 中继。** 只打开 EasyTier 或 NetBird 也不能生成链接。如果你不确定选择哪一种，见[外部访问：选择一种方式](/access/ways_in)。

## 生成链接

下面以 code-server 为例，其他应用的步骤相同。你要先安装并运行这个应用，见[在一个系统上安装应用](/deploy/on_a_machine)。

1. 在面板左侧栏点 **服务**。**应用** 区域每个应用一行，能分享的应用右边有 **分享**。在你要分享的那一行按 **分享**。

   ![服务页，code-server 这一行的分享按钮标红](/guide/zh/share_web_share_01_services_share.webp)

1. 弹窗打开后，在 **名称** 里填写便于你自己识别的名称，对方看不到这个名称。**应用** 已经预先选好。黄色提示说明，对方会以 lab 这个账户的身份使用这个应用。这个提示不会禁用 **生成链接**，由你决定是否发送链接。在 **有效期** 里选择链接的有效时间，可选 **1 天**、**7 天**、**30 天** 或 **直到撤销**，默认是 7 天。

   ![分享弹窗，名称一栏标红，下面有黄色提示](/guide/zh/share_web_share_02_dialog_name.webp "填写名称")
   ![有效期一栏标红，7 天处于选中状态](/guide/zh/share_web_share_03_dialog_expires.webp "选择有效期")

1. **站点** 保持默认的 `https://share.neutrinohub.net`。如果要使用自己部署的页面，选择 **其他站点**，做法见 [share.neutrinohub.net 的作用](#share-neutrinohub-net-的作用)。选好后按 **生成链接**。按 **复制**，把链接发给对方。如果对方使用手机，也可以让对方扫描下面的二维码。

   ![弹窗填好了，生成链接按钮标红](/guide/zh/share_web_share_06_dialog_generate.webp "按 生成链接")
   ![弹窗显示链接和二维码，复制按钮标红](/guide/zh/share_web_share_07_dialog_link.webp "按 复制")

1. 发送后，按 **完成** 关闭弹窗。

链接只显示这一次，中枢之后无法读取。如果关闭弹窗后还要发给别人，你只能撤销这条链接，再生成一条。同一条链接不限人数，也不限打开次数。

另一个入口是 **客户端** 页右上角的 **新建应用分享链接**，打开的是同一个弹窗。从这里打开时，你要在 **应用** 里选择应用。列表里是每个能分享的应用和它所在的系统。

![客户端页，新建应用分享链接按钮标红](/guide/zh/share_web_share_08_clients_new.webp "按 新建应用分享链接")
![应用一栏展开了，code-server 这一行标红](/guide/zh/share_web_share_09_clients_pick_app.webp "选择应用")

## 访客的身份

每个应用的访客身份不同，你要在生成链接之前确认。

| 应用                                            | 访客的身份             | 说明                                                                    |
| ----------------------------------------------- | ---------------------- | ----------------------------------------------------------------------- |
| code-server、VS Code、思源笔记、Codeg、CloudCLI | 运行这个应用的账户     | 不显示登录页，访客能做这个账户在应用里能做的一切                        |
| Hermes WebUI                                    | 账户 hermeswebui       | 不显示登录页，访客和你共用对话、记忆和工作区                            |
| Ayakaleaf                                       | 这条链接专用的访客账户 | 访客只能看到你邀请这个账户加入的项目，见 [Ayakaleaf](/deploy/ayakaleaf) |
| Gitea                                           | 未登录                 | 访客看到 Gitea 自己的登录页，账号在 Gitea 里创建                        |
| 容器、声明的应用                                | 未登录                 | 原样打开，如果有登录页，访客会看到登录页                                |

code-server 里有这个账户的终端，所以访客能访问这个账户能访问的所有文件。这类链接只发给你信任的人。

## 访客看到的页面

访客打开链接后，整个窗口显示这个应用，访客看不到中枢和系统的名称。Chrome、Firefox、Safari 都能打开，手机上也一样。

![访客的浏览器里打开了 code-server](/guide/zh/share_web_share_12_visitor_app.webp)

## share.neutrinohub.net 的作用

这个网站看不到你和访客之间的内容。它只提供一个不到 40 KB 的静态客户端，也就是访客浏览器加载的页面。网站上不运行任何程序，也不保存任何数据。

页面加载后，访客的浏览器直接连接你的中枢，不连接微子·中枢的其他服务器。所有连接都已加密，加密的两端是访客的浏览器和你的中枢。经过 SakuraFrp、OpenFrp 或 SSH 中继时也一样，这些线路和这个网站都看不到内容。

链接里 `#` 后面才是中枢的地址和分享的信息。浏览器不会把 `#` 后面的内容发给网站，所以网站也不知道访客打开的是谁的应用。

如果你不想依赖这个网站，可以自行部署。

1. 在微子·中枢的代码仓库里运行打包脚本。脚本把页面整理到一个文件夹里，不需要联网。

   ```bash
   python3 packaging/build/build_share_page.py --output-dir dist/share_page/
   ```

1. 把这个文件夹部署到任何一个 https 静态网站上。网站的根目录就是分享页，链接写成 `https://你的网站地址/#…`。Cloudflare Pages 和 EdgeOne Pages 可以直接使用，因为文件夹里已经包含它们的设置文件。部署到其他网站时，你要自己设置下面两条规则。

   - 文件 `/__neutrino/sw.js` 要带一个响应头，写成 `Service-Worker-Allowed: /`。
   - 找不到文件的地址都返回 `index.html`。

1. 以后生成链接时，在 **站点** 里选择 **其他站点**，然后在下面填写你的网站地址，地址要以 `https://` 开头。

   ![站点一栏的列表，其他站点这一行标红](/guide/zh/share_web_share_04_dialog_site.webp "选择 其他站点")
   ![站点选了其他站点，地址一栏标红](/guide/zh/share_web_share_05_dialog_other_site.webp "填写网站地址")

## 链接使用的地址

每条链接只包含一个地址，这个地址在生成时确定，之后不会改变。中枢按下面的顺序选择第一个已打开的外部访问：直连的公网地址、SakuraFrp、OpenFrp、SSH 中继。如果一种都没有打开，或者只打开了 EasyTier 或 NetBird，中枢不生成链接。

旧链接只包含生成时的地址，所以无法使用后来才打开的外部访问，公网地址变化后也无法使用。这两种情况都要重新生成链接。

## 查看和撤销

所有分享都列在 **客户端** 页下面的 **应用分享** 区域。每条分享占一行，显示名称、应用和系统、到期时间、状态、在线人数和 **撤销**。**在线 1** 表示现在有一个页面打开。面板只显示在线人数，没有访客名单。

![应用分享区域，有一条分享，显示可用和在线 1](/guide/zh/share_web_share_13_list_online.webp)

各状态的含义如下。

| 状态         | 含义                                           |
| ------------ | ---------------------------------------------- |
| **可用**     | 访客能打开链接                                 |
| **准备中**   | 系统正在创建访客账户，只有 Ayakaleaf 会用到    |
| **暂不可用** | 系统离线或者应用已停止，恢复后链接可以继续使用 |
| **失败**     | 访客账户创建失败，下面显示原因                 |

![应用停止后，这一条显示暂不可用](/guide/zh/share_web_share_15_list_unavailable.webp)

如果要提前结束一条分享，按下面的步骤操作。

1. 按这一行的 **撤销**。

   ![应用分享这一行，撤销按钮标红](/guide/zh/share_web_share_16_revoke.webp)

1. 弹窗说明，打开的页面都会关闭。确认后按 **撤销**。

   ![撤销的弹窗，撤销按钮标红](/guide/zh/share_web_share_17_revoke_dialog.webp)

访客的页面会立即变成 **这个链接已失效。** 这一行也从面板上消失。到期后，链接会在一分钟内断开，这一行也会消失。

下面这些操作也会结束分享：卸载这个应用、忘记这个系统、删除声明的应用。还原备份会结束所有分享，弹窗会说明这一点。应用只是停止时，分享不会结束。

如果链接打不开，查看[故障排查](/reference/troubleshooting)。
