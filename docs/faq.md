# 常见问题

你可以按下面的分组查找问题，需要细节时打开回答里的链接。

## 和其他工具的区别

### 和 1Panel、宝塔有什么区别

1Panel 和宝塔管理 Linux 服务器上的网站和数据库。微子·中枢管理你的 Windows、macOS、Linux 电脑上的工作软件，还提供 6 种外部访问：NetBird、EasyTier、SSH 中继、直连、SakuraFrp 和 OpenFrp。完整比较见[和其他工具比较](/compare)。

### 和向日葵、ToDesk 有什么区别

向日葵和 ToDesk 是远程桌面软件。在微子·中枢里，远程桌面是其中一个应用，此外还有编辑器、AI 编程工具、终端和文件。你在手机上能使用应用、文件、终端和桌面。

### 和 Claude 自带的远程、各种 agent 聚合工具有什么区别

Codeg、CloudCLI、Hermes WebUI 这类 agent 聚合工具是微子·中枢部署的应用。微子·中枢负责安装它们，并让你从其他设备连接它们。Claude 自带的远程是 Anthropic 提供的功能，不在微子·中枢的应用列表里，微子·中枢不安装也不管理它。

### 和 Tailscale 有什么区别

Tailscale 只负责把设备连成一个网络，上面的软件要你自己部署和配置。微子·中枢同时提供应用部署、外部访问和应用分享，使用它也不用注册账号。

## 准备工作

### 要买服务器或域名吗

你不需要购买服务器或域名，中枢安装在你已有的电脑上。在同一个局域网里，你不需要额外准备。你不在同一个局域网时，要开启一种外部访问，其中有免费的方式，见[外部访问：选择一种方式](/access/ways_in)。

### 电脑要一直开机吗

中枢所在的电脑要一直开机，关机后手机和分享链接都无法连接。其他系统在同一个局域网里时，你可以在面板上唤醒它们，见[被控端](/hub/agents)。

### 手机支持哪些系统

手机支持 Android 8.0 或更新的版本，以及 iOS 16 或更新的版本。在 iPhone 上，你要自行签名安装，步骤见 [iOS 应用](/access/ios)。

### 访客要安装什么

访客不需要安装任何软件，用浏览器打开分享链接就能使用这个应用，见[应用分享](/share/web_share)。

## 安全和开源

### 安全吗，要注册吗

微子·中枢不需要注册。加入链接和分享链接都由你在面板上生成，只有持有链接的人才能访问。所有连接都经过中枢的一个端口，设备和中枢之间的内容已加密。详情见[安全模型](/share/security)。

### 微子·中枢能看到我的数据吗

微子·中枢不提供公共服务器，设备和访客的连接都只到你自己的中枢。分享站 share.neutrinohub.net 只提供静态页面。中枢连接哪些外部地址，见[数据和外连](/hub/what_it_holds)。

### 要花钱吗，用什么许可证

微子·中枢开源免费。中枢、被控端和桌面客户端使用 MIT 许可证，Android 和 iOS 应用使用 AGPL-3.0 许可证。第三方线路的费用由各服务商决定。
